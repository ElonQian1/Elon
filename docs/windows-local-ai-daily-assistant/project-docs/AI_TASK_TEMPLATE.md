# AI Task Template

最后更新：2026-07-09

把任务交给 AI 时，建议使用下面模板。

```md
## 任务目标

请完成：

## 当前阶段

- [ ] 只改文档
- [ ] UI 假数据原型
- [ ] 本地采集
- [ ] AI 分析
- [ ] 数据库
- [ ] 打包发布

## 隐私影响

- 是否会截图：
- 是否会上传到云端 AI：
- 是否会写入 SQLite：
- 是否会删除数据：
- 是否会后台常驻：

## 约束

- 不要做员工监控。
- 不要记录键盘输入。
- 不要默认保存截图原图。
- 不要接真实 AI，除非任务明确要求。
- 不要提交 API key、截图、数据库或日志。
- 修改前先说明风险。

## 必读文件

1. `AGENTS.md`
2. `AI_RULES.md`
3. `AI_PROJECT.md`
4. `AI_ARCHITECTURE.md`
5. `AI_INDEX.md`
6. 与任务相关的 `docs/*.md`

## 希望 AI 先输出

1. 相关文件列表。
2. 为什么这些文件相关。
3. 修改计划。
4. 隐私风险判断。
5. 验证命令。

## 最终回复

- 本次完成了什么。
- 是否触碰截图/上传/数据库/后台常驻。
- 验证结果。
- 未完成事项和风险。
```
