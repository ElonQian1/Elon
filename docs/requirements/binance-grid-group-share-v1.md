# 币安网格群聊分享

## 已接受范围

Win 与主 APK 从本人当前币安会话显式读取一条网格，预览后发送到用户选择的群聊。复用群分享快照的成员鉴权、撤回、事务和幂等能力。卡片展示合约、方向、杠杆、区间、格数和采集时间，点击进入只读详情；收益、持仓和参数分区展示。未知字段明确标注未读取，不能由网格利润推算总收益率或真实持仓。

2026-10-01 用户明确变更：Win 与 APK 新分享全部公开已读取的金额和数量，预览中明确提示，不再提供隐藏金额开关；默认不附加个人说明。历史隐藏快照保持原样，读取端继续尊重其公开边界；重新读取后可发布关联的公开新版本。服务端使用独立字段白名单再验证。Cookie、账户标识、策略私有 ID、会话令牌、页面文本、任意 URL 和请求路径均不得进入分享。AI 只能获得同一份公开快照。

分享是不可变历史快照。本人手动更新时生成关联的新快照和新群消息；旧快照保持不变并提示已有更新。版本关系必须同群同分享者，禁止任意接续、循环和并发分叉。接收者打开详情不触发币安请求。

引用讨论和询问群 AI 都进入现有草稿/选区确认流程，由用户点击发送。实际生产群分享必须由用户选择群及确认公开字段。当前任务不得向未指定群自动发送真实持仓。

## 验收

1. Win/APK 显式读取、空列表/登录失败、选择、全量金融字段预览及发送路径可用；切换账号或目标使未发送草稿失效。
2. 群成员可读，非成员/跨群/撤回不可读；重复请求不会重复发消息，重试不同内容拒绝。
3. 新分享的参数、金额、数量和未知值在请求、存储、卡片及 AI 上下文语义一致；旧隐藏快照不可补写，私有身份和凭证始终排除。
4. 更新创建新版本，不改写旧快照；非所有者及陈旧版本接续拒绝。
5. 双端卡片、只读详情、快照引用、AI 确认入口兼容。读取与交易完全分离。
6. 记录代码、测试、构建、部署及真机验收状态；保留手机当前子账户，无网格时如实记录非空实测缺口。
7. APK 卡片、选择器和详情及移动 PWA 的分享卡片与详情遵循移动设计 V2：本地代币 Logo、方向标签、带正负号的语义盈亏色、真实区间位置、分区数据；浅深主题、放大字体与触控目标可用。缺少收益率时优先展示已读取的总盈亏或网格利润并标明口径，不显示误导性空白大指标。

## 模块与兼容

扩展既有 `elon.ai_conversation_share.v1` 容器，增加 `provider=binance` 的专用 `grid` 文档，旧 ChatGPT 分享不改变。网格协议独立 `yilong.grid_share.v1`，只接受固定类型及字段。Win 位于 `features/grid-share`，Android 位于 `grid/share`；宿主读取继续复用已有只读适配器。PWA 使用独立的富卡片与分区详情，按相同字段、金额边界和指标口径渲染，不依赖 Win React 组件；不提供不存在的本地币安读取能力。

验证重点：字段泄漏、来源切换、撤回/跨群、重复点击与重试、版本并发、公开内容的 AI 展开、卡片小屏与键盘访问。原型数字仅用于合成测试，不作为生产默认值。
