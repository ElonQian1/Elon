# Android 外链阅读性能交付记录（2026-09-21）

此文件为交付证据，不定义产品需求。范围为主项目 APK 外链阅读器；负责人为本任务。

## 已确认的问题与处理

- Activity 的 `onLoading(true)` 启动十秒提示后，紧接着的 `onStatus` 会取消它。提示现由独立导航状态管理。
- `onPageFinished` 曾直接标记加载完成，无法反映微信 `#js_content` 仍被隐藏的情况。现分别记录下载完成、正文可见和下一帧就绪。
- 每次页面完成都启动无法取消的回读循环，成功后仍最多重复十二次。现每次导航只有一条任务，成功停止，换页/关闭使旧回调失效，无回调也在二十秒内结束。
- 元数据适配器按进程缓存；持久化移出 UI 线程。保留原有身份校验、预览缓存、浮窗、全屏视频、画中画和打开原文能力。

## 诊断合同

- `ui_state.external_reader` 返回存活会话的当前快照；`trace_recent` 按 `phase=external_reader_performance` 读取持久化里程碑。
- 记录 WebView 版本、创建时间、DNS/连接/首字节、FCP/LCP、DOM/下载完成、正文可见、脚本长任务和错误数量。
- 网页数据按字段白名单过滤；资源只保留域名、类型和耗时。没有正文、标题、Cookie、完整 URL、查询参数或 console 文本。
- 页面性能观察通常在正文可见且下载完成后结束，首次观察上限三十秒；晚完成或恢复页面可补充短观察。网页观察器四十五秒自动释放。
- 微信检测只读取正文容器及最多八层祖先样式，不修改网站 CSS、User-Agent 或网络路由。其他站点使用通用绘制信号。

## 验证入口

- JVM：`:app:testDebugUnitTest --tests "com.elon.app.sociallinks.*"`，覆盖导航状态、超时、回调失效、任务停止、隐私过滤和原有会话行为。
- 浏览器：`node scripts/test-social-link-performance.mjs`；`node scripts/test-social-link-read-adapter.mjs`。使用合成页面，不把 fixture 结果当作线上网站验收。
- 手机：`scripts/test-social-link-reader-device.ps1`。只通过语义节点打开指定群和文章、刷新/关闭/回到聊天/打开原文；`metrics` 仅返回性能字段。

## 测量边界

此前旧 APK 的原生无障碍树检测约 3.57 秒、6.44 秒出现两篇微信正文；Chrome FCP 分别约 2.04 秒、1.47 秒。两种测量口径不同，不可直接据此计算提速百分比。

网页脚本初始隐藏微信正文是已观察到的机制，尚不能单凭该机制判定所有白屏的唯一原因。第三方网络、网页变化和系统 WebView 版本仍会影响加载表现。

两篇当次测量均未出现十秒慢加载提示或主文档加载失败；第三方资源仍有部分失败记录，未阻止正文可见。两篇分别记录约 786 ms、468 ms 的网页长任务总时长，不能据此认定历史白屏的唯一原因。

返回聊天再打开第一篇时，会话 ID 与导航 ID 均保持不变，确认未重新加载；关闭后 MCP 会话列表清空。语义验收另确认刷新、打开原文和关闭入口可用。卡片读回作者后描述会变化，验收定位已改用给定的公开标题前缀。

当次实机结果受缓存、网站内容和网络影响，不能与此前无障碍树检测耗时直接计算提速比例，也不代表所有外部站点的慢加载均已消失。
