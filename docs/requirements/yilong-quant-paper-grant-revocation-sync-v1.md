# 一龙量化 Paper 单次授权撤销公开同步 V1

## 目标

将 `yilong-quant` 已验证的 Paper 单次授权持久撤销能力同步到一龙主项目的官方项目目录、加入前公开预览和协作文档。用户应能在项目广场准确理解：量化页面可以结束当前五分钟 Paper 授权；该授权即使在量化服务重启后也会继续被拒绝；这不是退出仓位、提取真实资产或撤销主项目账号会话。

## 范围

- 以量化仓库 `.elon/project-landing.json` 为内容真源，同步官方目录中“一龙量化交易”的净化首页快照。
- 更新官方目录合同测试，固定 V8 的单授权撤销说明、Paper-only 边界和计划中客户端状态。
- 更新主项目量化接入文档和 AI 导航，记录量化仓库实现提交及双方责任边界。
- 随 Server 构建发布新的官方目录快照，并对公开预览接口执行匿名只读核验。

## 非目标

- 不修改主项目 Paper grant 的载荷、签名、有效期、scope、签发接口或一键启动协议。
- 不让主项目读取或写入量化撤销数据库，不在主项目保存 grant、participant、仓位或交易所凭据。
- 不部署量化 Web 客户端，不开放 sandbox/live 交易，不接收或移动真实资金。
- 不发行真实代币、不证明付款、KYC、钱包所有权或投资准入，也不承诺固定或保本收益。

## 安全与兼容边界

- 单次撤销由量化服务在验签后按已验证的 `grant_id` 执行；主项目仍只负责短期签发和 exact-origin 内存传递。
- 公开预览继续只投影白名单字段，不返回资源 URL、grant、participant、账户、密钥、仓位或撤销记录。
- 既有 V1 schema、项目列表、加入流程、ERP 项目安装和 Paper launch 接口保持兼容。
- 量化仓库未部署或主项目签名配置未就绪时，入口继续失败关闭。

## 验收标准

1. 官方目录中的量化首页快照与量化仓库 V8 真源一致，首条最近更新说明单个授权跨重启撤销且不保存 token 或 participant。
2. 量化功能亮点和 Paper 入口说明明确同时支持密钥级撤销与当前授权撤销，不把撤销描述为退出仓位或真实提现。
3. 官方目录合同测试固定 V8 文案，并继续验证预览不会暴露 URL、grant、participant、账户、密钥或仓位。
4. 主项目接入文档记录量化实现提交、数据归属和主项目签发契约不变；AI 入口可快速找到本需求。
5. Server 定向测试、文档/源码门禁、发布和线上匿名只读预览核验通过。

## 回滚

回滚 Server 到上一已验证版本即可恢复 V7 的官方目录快照。此同步不修改数据库、签发契约或用户状态，不需要数据迁移；量化服务中的单次授权撤销能力保持独立有效。
