# 一龙主项目设计入口 V2

基础规范只在 [双 APK 移动设计系统 V2](design/mobile-design-system-v2.md) 维护，来源见 [官方依据](design/mobile-design-sources.md)。旧轨道金属、强制深色、钛色渐变、胶囊导航及继承旧页面的要求停止适用。规范接入不代表页面已经改造，主线是否采用以合并状态为准。

## 用户任务

一龙是移动端 AI 协作与项目工作工具。围绕发起对话、管理项目、理解进度、处理审批和查看结果组织界面。AI 文本回答、正在执行的任务、待审批操作、已交付结果必须区分，不做成同一种成功卡片。

一级入口按任务评估；AI 对话、项目、消息/协作、我的是候选分组，不是已经实现的导航。项目广场可在项目发现上下文组织。迁移前记录全部既有能力的旧→新路径，不凭模板删除功能，也不要求保留原位置。

## 页面模式

主 APK 外观默认值按用户 2026-09-29 的明确选择调整为深色；未保存选择或无效值采用深色，已明确选定的浅色、深色或跟随系统继续保留。设置 → 外观可以随时切换。此项是主 APK 的产品默认值扩展，不恢复旧强制深色规范，不改变量化或 PWA 的默认策略；所有原生页面与项目查看面板仍须完整支持浅深主题。

| 页面 | 首要内容 | 交互和恢复 |
|---|---|---|
| AI 对话 | 当前对象、模式、消息与输入 | 长中文、代码和附件可读；代码横向滚动局限于代码区；保留草稿与发送状态 |
| 项目列表 | 项目身份、关键状态、继续工作 | 搜索筛选可发现，保留列表位置，不为每个项目堆按钮 |
| 项目详情 | 目标、阶段、下一步 | 文档、版本、成员、历史分层，不把全部能力平铺首屏 |
| 任务与结果 | 执行中、待本人决定、失败、可交付 | 可查变更、日志、产物；失效审批禁用；错误有恢复路径 |
| 消息与协作 | 对象、未读、摘要、时间 | 尊重阅读位置，不让刷新反复跳动 |
| 账号与设置 | 身份与安全入口 | 一龙账号、登录方式、第三方会话分别表达，不混成一个已登录状态 |

## 不变的业务边界

权限、授权复用、敏感操作确认和会话传输遵守原合同。不得为 UI 验收重发生产消息、扩大权限、清除登录、导出凭据或修改后台执行。审批展示对象、范围、后果、细节入口和明确动作；普通信息不滥用确认弹窗。

## 实施和验证

主项目消息页采用[双端消息界面打磨](requirements/mobile-conversation-polish-20260929.md)的层级与 token 2.2：中性表面承载内容，蓝色用于明确操作；类别和头像不占用大面积强调色。PWA 输入组件的几何、图标和焦点须随共享色源一起验收，不能以换色或语义对齐代替页面质量。

先建 Material 3 主题/组件与代表流程，再推广导航、列表、详情、聊天和设置。新组件优先 Compose，旧 View/WebView 按互操作边界渐进迁移；不为 skill 更换整个产品技术栈。

软键盘出现后输入、发送、错误和重要操作仍可到达。流式回答、附件传输、后台任务分别有状态。浅深主题、长中文、字体放大、离线、部分数据、错误恢复都进入母版。

APK/PWA 遵守 [语义对齐规则](../.github/instructions/apk-web-ui-sync.instructions.md)，不强制每次修改同一 HTML，不机械复制几何。系统级重构先取得真实原生运行证据，再进入受控正式发布；编译、截图、交互、性能、装机分别报告。
