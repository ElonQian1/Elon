# Win 浏览器研究 MCP V1 需求

## 用户结果

在一龙 Win 内复用 WebView2 宿主，建立可以由 AI 通过 MCP 读取的网页研究工作台。首个对象是用户授权的币安 U 本位合约网格：研究本人策略列表、详情、创建参数、修改与结束流程，不研究推荐或跟单。用户不需要反复导出、传递摘要；网页实际加载的资源与观察到的业务请求直接进入本机研究库。

该需求替代继续扩展 Chrome 手动摘要交接的方向；既有 Chrome 观察工具保留为过渡工具，其工件与登录页不作修改。本需求尚未实现，不表示已接入币安或获得可执行接口。

## 范围

1. 复用现有 owner/provider 隔离、WebView 生命周期、原始响应保存与项目绑定 MCP 传输；研究域单独建模，不把币安伪装成聊天厂商，不扩大现有 ChatGPT/Google 的生产命令。通用内核只认识研究会话、资源、请求、内容与证据；不得包含网格字段、币安路径或某网站业务判断。
2. 以当前文档实际加载或执行的 HTML、JavaScript 和相关资源建立清单。保存来源、内容哈希、时间、版本和字节定位；按需读取内容并索引，源映射存在时辅助定位，不假设公开 source map。
3. 自动旁路记录目标页面实际发生的相关请求、响应和发起代码线索。保留完整业务路径、字段及业务值，不能再次把未知接口尾段和集合字段删除。读取范围、缺失、截断及失效必须明确。
4. 原始业务材料按账户、站点、文档代次和研究会话在本机隔离保存；AI 默认取索引和命中片段，可以按需读取授权业务内容。Cookie、Authorization、会话/CSRF 令牌、密码与签名凭据继续由浏览器管理，不进入研究库、索引、诊断日志、Git、公开团队资产投影或任何 MCP 返回；各资料中的凭据定向排除并标注处理范围，非凭据业务字段和值保留。
5. MCP 提供会话状态、资源清单、文本搜索、按范围读取、请求清单、指定样本读取和证据关联；默认有界、可分页、可取消。只解析资料，不执行第三方 JavaScript，也不把页面内容作为代理指令。
6. 静态接口候选必须绑定资源哈希与位置；现场请求绑定研究会话与请求 ID。明确区分代码候选、实际观察和业务结果，不能由 HTTP 200、字符串匹配或前端按钮推导服务端成功。
7. 通过版本化站点清单登记入口、允许的导航域、资源/CDN 域、API 域与登录范围。新增普通网站不要求修改或重新编译内核；无专属适配器也能采集、搜索和读取资料。网格语义、业务成功判断及复杂协议解码只进入可选站点适配器。
8. 使用宿主能力接口隔离 WebView2 实现与研究领域；以后增加其他受支持浏览器时保留同一内容模型和 MCP 合同。第一批只交付 WebView2，不宣称已经自动接管 Chrome。

## 验收

- 同一已登录研究会话内，从网页加载到 MCP 搜索、读取指定资源和样本形成真实闭环，无人工导出步骤；另行验证 Win 首次币安登录兼容性。
- 已保存 JS 不变时复用内容哈希与索引；AI 查询仅返回命中窗口与定位，不把整个 bundle 默认放入上下文。
- 币安网格列表至少取得一条可定位到实际请求的接口路径、请求参数与响应业务结构；创建、修改、结束各自有独立证据状态，未观察保持未验证。
- 跨 owner、站点、文档或过期会话访问被拒绝；中断、导航、超额、资源不可读与宿主离线有可查询状态。
- 本地保留与 AI 输出分开验证；原始业务值可按授权读取，登录凭据不进入常规日志、源码库和公共接口。
- Rust、MCP、索引行为与 WebView2 现场验收分别记录。仅文档、编译或离线测试均不能宣称实际研究工具可用。
- 使用同一内核与 MCP 在币安和一个无交易的异构测试网站验收；后者只增加站点清单，能检索 JS、读取请求和恢复研究会话，不要求复制采集、存储或 MCP 代码。

## 不在本批范围

不重新启动或关闭用户已登录 Chrome，不复制 Chrome Profile；Win WebView2 使用自身 Profile，必要的首次登录或站点验证由用户完成。不会声称无人参与可以跳过身份验证。

本批不提供真实下单、仓位修改、结束网格、任意请求重放或任意脚本执行接口。可以分析这些操作的前端代码、准备合同和离线回归；真实交易由用户在官方界面执行，本工具观察其结果。量化 APK、OKX 适配器和团队资产公开合同不在本批迁移。

架构与复用依据见 [Win 浏览器研究架构](../decisions/win-browser-research-mcp-v1.md)。
