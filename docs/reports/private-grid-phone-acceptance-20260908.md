# 结果

本次本人手机实际打通 Win → 私人云端 → 量化 APK 的只读链路。
手机显示 24 条真实记录，列表、参数、新快照刷新、过期标识、1 条完整详情
以及撤销后立即清除内容均已验收。24 条并不代表 24 个正在运行的策略。
云端当前只有 1 条含详情响应，其他记录明确按已有列表字段展示。

入口连通由主 APK MCP 核验。主 APK MCP 没有量化原生页控件能力，
页面验收使用量化仓新增的有界 Instrumentation 探针，只返回状态、数量、
参数标签计数和工具指纹，没有导出完整 UI 树、私人显示值或登录凭据。
不能把这次检查称作量化 APK 已有完整 MCP 接口。

# 修复和安装

实测先发现服务器生成授权、手机却拒绝返回结果。手机比服务器慢约一秒，
原主 APK 和量化 APK 都严格比较毫秒时间上界，造成合法授权被拒绝。
两边新增回归用例均在修复前失败，修复后允许未来上界最多 5 秒时钟偏差。
已过期授权码仍拒绝，量化凭据受服务器 TTL、绝对到期时间与本机单调时钟
共同限制，最长持续有效时间仍为 900 秒。
