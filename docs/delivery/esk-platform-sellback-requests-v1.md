## 构建环境记录

首次 Android 验证在 Java 本地回环初始化阶段失败，未编译或执行测试；
外层脚本曾输出 passed，实际失败日志已按失败处理，没有计入通过证据。
仅为本轮子进程指定独立套接字临时目录，并设置标准 wrapper 退出码选项后，
Selector 探针及实际 Kotlin 编译恢复。未修改全局 JVM 配置、发布工作流或应用连接保护。
目录设置依据 [Oracle JVM 网络属性](https://docs.oracle.com/en/java/javase/16/core/networking-properties.html)，
本机恢复结论来自实际探针与构建，不推定所有 Windows 环境具有相同原因。
