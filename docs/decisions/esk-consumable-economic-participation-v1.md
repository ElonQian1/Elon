# ESK 可消费经济参与权 V1

## 决定

ESK 采用一个资产承载三类产品效用的有意设计：支付一龙 AI、代理等服务，参与协议治理，以及按未来利润分配快照参与团队已批准的可分配利润。持有人用 ESK 支付或转让后，余额减少，之后快照中的治理和利润分配权重也随之减少；这是产品机制，不是需要用第二种权益币修复的缺陷。

ESK 是市场定价资产。首次销售可以把 `1 ESK = 1 USDT` 作为该批次的参考成交价，但不得据此生成永久锚定、储备担保、固定净值或无条件按面值赎回承诺。团队量化账户的资产和盈亏不直接重估 ESK，也不构成 ESK 的一比一储备。

## 单币不等于单账本

ESK 只有一个余额真源，但相关经济事实必须分开记录：

1. 服务目录、报价、发票和交付回执记录用户买了什么服务；
2. ESK 追加式账本记录支付、转让、锁定、解锁和销毁等余额变化；
3. 利润分配账本记录不可变资格快照、可分配利润来源、排除余额和逐账户金额；
4. 量化子项目使用独立 `QSHARE` 份额账本和 NAV，不把 ESK 余额当作基金净值或申购份额。

支付 ESK 时，服务会计与资产变动必须用同一个幂等业务引用关联，但不能用修改余额字段代替订单、收入或交付事实。进入协议金库、回收账户、未解锁团队账户或销毁地址的 ESK 默认不参与利润分配；重新纳入必须由新版本政策和可审计快照明确批准。

## 利润与量化边界

量化策略账户经交易所对账后的资产变化只进入 `QSHARE` NAV。量化管理费、业绩费或其他已实现费用可以在独立会计确认后成为团队收入；只有再经审批标记为 `distributable_profit` 的部分，才能按某次 ESK 资格快照分配。

以下资金不得成为 ESK 持有人利润池：用户量化本金、待处理申购、待赎回金额、尚未对账的 USDT 转账、未实现且未确认的交易所余额，以及为特定兑付义务隔离的储备。

## 权利表述

当前 ESK 表达的是团队产品约定下的经济参与权，不自动等于任何司法辖区中的公司法股权、股份登记、债权、存款、保本产品或固定收益。只有未来把 ESK 与具体法律实体、股东名册、章程及适用协议正式绑定后，界面和文档才可使用“公司股份”或“法定股权”。

这项表述边界不改变产品选择：默认不再另发一枚“团队权益币”。如果未来要拆分 ESK 的服务效用、治理或经济参与权，必须新增 ADR、迁移计划、用户影响说明和双账核对，不能由代理自行重命名或静默拆币。

## 对既有决策的影响

本决定扩展 `docs/decisions/esk-asset-naming-v1.md`，并仅针对 ESK 覆盖 `docs/open-commerce/decision-register.md` 中“不用一个代币同时代表多类权利”的旧一般结论。API Token、算力贡献、商户数据权、`QSHARE`、客户本金和法定公司股权仍是不同事实，不因 ESK 的产品组合而合并。
