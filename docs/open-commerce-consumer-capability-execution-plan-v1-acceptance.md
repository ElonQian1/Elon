# 消费者能力执行计划 V1 验收

状态：`implementation_uncompiled`

## 已形成代码

- 只读复核公开目录、拟调用输入、App 所有权、封禁和授权状态。
- 公开/受限与 query/action 组合映射为六种稳定 readiness。
- 动作能力返回准备、用户明确确认、确认和调用四个步骤。
- 现有 Grant 和待审批申请只读回显，不自动推进状态。
- 计划按下一次调用的次数、单位价格和币种检查全部有效 Grant，并返回选中 Grant 与稳定预算原因。

## 最终统一回归

- 公开查询、公开动作、受限查询和受限动作。
- 默认 MCP 身份、自有开发者 App、非本人 App 和被封 App。
- 有效 Grant、无 Grant、待审批、过期或撤销 Grant。
- 单张和多张 Grant 下的次数耗尽、金额不足、零价调用、币种不匹配、最新耗尽但旧授权可用。
- 全部 Grant 不可用时首次续额申请与已有续额申请两种下一步。
- 合法/非法输入 Schema，以及规划前后数据库无新增副作用记录。
- 计划步骤与动作确认、调用工具实际要求一致。

本批按快速实现策略只完成 Rust 格式化、静态差异和文件规模检查；未执行 Cargo 编译、MCP 调用、数据库或端到端验证。
