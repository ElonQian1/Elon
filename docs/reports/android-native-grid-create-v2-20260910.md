# 量化原生创建命令首批证据

权威需求为 `docs/requirements/android-exchange-session-host-v2.md`。主 APK 新增固定 V2 创建命令，量化新页面拥有表单及最终人工确认；正常创建不需要打开主创建 Activity。主服务内部仍使用现有 Binance WebView、领域参数校验、固定私有适配器与在途日志。

`BinanceCreateCommands` 负责独占创建槽、调用生命周期、恢复、准备和查询；`BinanceCreatePermit` 将一次性许可绑定到操作、当前账号/文档、草稿摘要和随机准备标识。Provider 继续校验真实 UID、量化包名和正式证书，不提供任意 URL、脚本或凭据导出。旧创建 Activity 保持兼容，新调用者仅可进入主登录 Activity，不能借新身份跳入旧交易页。

主测试覆盖一次性许可、错账号/文档/摘要/标识、过期与重放，以及既有创建/宿主合同。量化侧 164 项 Release 和 9 项 MCP 测试通过；MCP 不提供创建提交或金融确认动作。公开目录经 PC 已有代理可以读取，PC/服务器直连超时，不能据此声称手机网络或新链路已成功。

本批未执行真实交易，未打开主创建页验收，未安装手机或重启 Win/Chrome。APK 发布与设备验收分别记录在外部交付回执；源代码和单元测试不能证明真实跨 APK、会话冷恢复或用户创建已通过。

后续仍需：量化原生修改/追加/结束 UI 和固定命令、手机公开行情连通、内部 WebView 冷启动及进程回收验收、跨进程草稿恢复、完整费用与风险、多交易所真实能力验证。完整 V2 功能保持待续，不因创建首批而标记全部完成。
