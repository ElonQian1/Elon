# 开放商业消费者价格币种筛选 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 可选价格币种请求字段和三位字母规范化。
- 存在价格上限时的兼容默认 CNY。
- 币种优先、微单位价格随后比较的候选过滤。
- 条件响应回显、匹配原因、请求指纹和排序凭证载荷。
- PC 独立价格筛选组件和规范化结果标志。

## 统一回归必须验证

- 无价格条件、只有币种、只有上限和两者同时存在。
- 小写、前后空白、非三位、数字和非 ASCII 输入。
- CNY 上限不会命中相同微单位的 USD、EUR 或其他币种。
- 价格等于上限、低于上限和超过上限。
- 条件与来源、声明期、能力键和五种排序器组合。
- PC 默认 CNY、禁用状态、档案带入、结果标志和窄屏布局。

## 未完成

- 本批所有编译、接口、兼容性、凭证、浏览器和 UI 验证。
- ISO 4217 完整目录、汇率换算、多币种预算和支付结算。
- 商户报价真实性、税费、折扣和最终成交金额验证。
