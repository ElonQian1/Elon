# ADR：ERP 蓝图与独立商户实例 V1

- 状态：已接受
- 日期：2026-08-01

## 背景

小商户希望得到适合自己的 ERP 界面和功能，但订单、库存、会员、营销、审计等底层能力高度重复。若每次由 AI 从零开发，成本高且难以统一修复；若所有商户共用一个可任意修改的系统，又会混淆数据所有权和定制边界。

平台已经具备项目、PC 工作区、Matter、开放商业商户节点与能力契约，因此不应再建立第二套项目系统。

## 决策

1. 蓝图和商户实例均引用现有 `projects` 记录。
2. 官方蓝图由维护者登记，蓝图版本以不可变发布清单描述，不复制商户数据。
3. 创建实例时建立新的独立项目，并固定蓝图版本；V1 只登记继承关系，不自动复制或执行源码。
4. 公共能力放在模块目录中；行业差异使用插件；视觉差异使用主题；单店专有逻辑使用私有扩展命名空间。
5. 数据库、密钥和客户数据始终留在商户项目或受控运行环境，平台只保存治理元数据。

## 结果

AI 可以知道哪些轮子已经存在，也能在不覆盖商户私有代码的情况下规划升级。真实代码复制、Git 合并和部署继续由既有项目开发与发布流程完成，不由蓝图服务暗中执行。
