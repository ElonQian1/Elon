# 消费者可携带数据包 V4 验收

## 当前实现

- 新导出可携带关系所引用商户的有效身份指纹声明。
- V1/V2/V3 包保留导入兼容，旧版携带 V4 字段时失败关闭。
- 只有来源运营方签名已验证的导入包会生成指纹精确匹配候选。
- 普通完整性导入仍只能手工检索和确认。
- 关系映射保存指纹匹配状态和匹配键，但仍由消费者确认、目标商户重新审批。

## 验证状态

根据当前快速开发策略，本批次未运行 Rust 编译、PC 构建、TypeScript 检查、迁移检查、V1-V4 摘要兼容测试、签名匹配测试或完整回归。当前状态为 `implementation_uncompiled`，不能声称 V4 可运行或兼容性已验证。

## 后续统一验证

- V1/V2/V3 已存包解析后重序列化仍与原摘要一致。
- V4 商户声明去重、数量上限、关系引用和摘要格式失败关闭。
- 未签名包、已撤销运营方信任键、已撤销商户键和未发布商户不产生候选。
- 多指纹、多候选、人工改选、映射撤销和重新授权范围子集。
- 导出、导入和映射审计不包含私钥、原始调用输入或消费者联系方式。
