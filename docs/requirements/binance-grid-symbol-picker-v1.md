# 合约网格选币 V1

主APK创建表单增加独立可浏览选币页，量化APK沿用现有创建入口即可使用。搜索支持币种、完整合约和带分隔符输入；提供全部、自选、最近选择、交易所返回的分类，以及名称、24小时成交额、涨跌幅排序。列表只接收已验证TRADING、USDT保证金/报价、PERPETUAL合约；交易所合约可交易不代表账户一定能创建网格，最终仍由原准备/确认合同核验。

分类来自官方exchangeInfo的underlyingSubType，不硬编码币种赛道关系。24小时行情来自公开ticker接口，未知或过期数据不当零；行情失败不遮蔽已获取的合约列表。不增加推荐、收益评分或自动交易。

收藏与最近选择只在本机保存有界合约代码；最近选择不声称已经交易。切换币种清空原价格类参数和杠杆，保留用户其余设置，废弃既有准备结果。支持加载、失败、无搜索结果、自选为空以及手动输入回退。

模块计划：BinanceSymbolCatalog纯筛选/排序约150行；BinanceSymbolPicker原生界面约230行；BinanceSymbolTicker公开行情解析约100行；现有市场、创建表单、行情面板仅接线。对应领域测试，不扩大主Activity或私有交易协议。

验收：精确搜索排序、分类缺失/异常、收藏最近上限、过期行情、合约排除和换币清理测试；Android生产构建；正式发布与可选页面/像素验收分报。读取合约时不等待单币行情结束，关闭页面丢弃迟到回调。当前FAPI网络可达性独立记录，不用静态假列表冒充实时合约。
