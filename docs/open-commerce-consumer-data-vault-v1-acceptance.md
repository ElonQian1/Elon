# 开放商业消费者客户端加密数据保险箱 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 客户端使用固定 PBKDF2-SHA256 和 AES-256-GCM 参数加解密自由文本。
- 密文通过附加认证数据绑定记录 ID 与修订号，明文信封再次校验相同绑定。
- 服务端按用户和项目隔离保存密文，列表只返回最小元数据。
- 创建、读取、更新、下载密文和显式删除 API 及 PC 操作入口。
- 更新和删除使用修订号乐观并发，服务端限制条目数与密文大小。
- 审计不包含标签、明文、口令或派生密钥。

## 统一回归必须验证

- V162 全新迁移、既有数据库升级、100 项上限和 1 MiB 密文上限。
- 跨用户、跨项目读取更新删除隔离及不存在条目的统一错误边界。
- 错误算法、迭代次数、盐、随机数、Base64、时间、记录 ID 和修订号。
- 正确口令往返、错误口令、密文篡改、跨记录替换和跨修订替换。
- 并发更新、旧修订删除、创建重复 ID 和删除后的读取。
- Chromium Web Crypto、TypeScript、Rust、HTTP 权限、PC 解锁编辑和密文下载。
- 请求、响应、审计和服务端日志不出现口令或明文。
