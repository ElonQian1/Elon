# 开放商业消费者可携带数据离线加密归档 V1 验收

## 当前实现

- PC 导出可选择口令，在浏览器内生成 PBKDF2-SHA256 + AES-256-GCM 加密归档。
- PC 导入识别加密归档并在本机解密，普通 JSON 继续保持兼容。
- SDK 提供同协议的异步加密与解密函数。
- 每包使用独立随机盐与 Nonce，并用固定协议 AAD 和明文 SHA-256 双重约束。
- 口令不进入现有后端请求、数据库或审计字段。

## 验证状态

根据当前快速开发策略，本批次未运行 PC 构建、TypeScript 检查、SDK ESM 加载、加解密往返、跨端互操作或完整回归。当前状态为 `implementation_uncompiled`，不能声称可运行或通过安全验收。

## 后续统一验证

- Node SDK 自身加解密往返及错误口令拒绝。
- PC 浏览器自身往返，以及 Node 加密/PC 解密、PC 加密/Node 解密。
