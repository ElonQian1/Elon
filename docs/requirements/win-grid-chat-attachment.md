# Win 网格对话附件

用户在一龙 Win 的 ChatGPT 聊天中点击“附带网格”，读取本人币安官网会话的网格列表，
明确选择一个网格后读取详情。输入框旁展示可展开、可移除的快照；点击发送才把快照和问题
交给当前 ChatGPT 会话。后续追问不自动读取或再次附带。不得从同币种推断唯一策略。

## 合同

- 复用 ExchangeWebObservation 和官方会话发送器；不增加交易、创建或修改策略动作。
- 仅显式读取期间执行有界轮询；打开聊天、编辑问题、发送与切换会话均不读取币安。
- 快照绑定本机 owner、ChatGPT 会话、币安页面文档、账号证明和策略 ID；换目标丢弃旧附件。
- 序号和时间证明读到新观察；缺少证明、账号变化、窗口关闭、超时均失败，不用旧缓存冒充。
- 只投影所选网格的允许字段。保留十进制字符串；未知字段为 null，不把初始货值当保证金。
- 发送内容不含币安账号 ID、Cookie、token、钱包、其他策略或任意网页文本。
- 附件只存在当前页面内存；完整发送记录遵循现有聊天历史存储策略。
- 复用发送队列、回执对账与不确定发送不重放机制；失败恢复的完整草稿不重复添加附件。
- 显示采集时间和字段缺失；过期快照需要重新点击读取，发送按钮本身不刷新。

## 验收条件

1. 普通聊天零币安读取；点击入口后选择同币种不同方向/杠杆/ID 的正确网格。
2. 新观察必须通过文档、账号、序号、时间和策略校验；非法/未知数据不得猜测。
3. 移除、会话切换、取消、失败或迟到读取不产生隐藏附件。
4. 用户发送时仅附带一次；不隐式刷新、不重复发送，不暴露认证信息及其他账户数据。
5. 类型检查、针对性回归、生产构建通过；发布 PC 与所需 Win 宿主，分别记录现场证据。
