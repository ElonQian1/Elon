# 币安主子账户隔离与手机会话改进：本批交付

范围依据 [正式需求](../requirements/android-binance-host-read-v1.md)。Win 保留用户已登录的子账户，手机继续使用其原有主账户登录资料；本批没有重启 Win/Chrome、复制网站凭据或执行金融操作。

## 实现与证据

- Win 认证基础信息响应已独立确认子账户；当次网格响应为空，不推断主账户、全部历史或持仓为空。固定 GET 合同和证据哈希见 [身份研究](binance-subaccount-identity-20260908.md)。
- 手机适配器使用精确认证 UID 验证列表与详情，允许身份已确认的空列表；父子关联不替代 UID 相等。旧列表、旧详情、失败和身份响应按代次隔离。
- 主端报告账户类型、有效授权数与详情数；量化只在收到精确撤销回执后显示撤销确认，详情超时提供重试。权限合同仍为 `yilong.binance_host_read.v1`，没有任意接口或交易透传。
- 桥接在页面首次显示与加载完成时均可绑定，重复绑定不重复投递缓存。MCP 新增固定页面阶段、加载百分比、绑定布尔值和来源类别，避免整页导出。
- Release 编译、13 项原生状态测试、19 项适配器断言及 10 项异步会话测试通过。量化 Debug/Release 各 99 项测试和远端 Android CI run `34181808049` 通过。
