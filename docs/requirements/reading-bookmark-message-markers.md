# 聊天气泡旁的私人书签标记

用户要求书签跳转后能直观看出标记在哪条消息。基于已发布的群聊、好友阅读书签，
APK、PWA 和 Windows 前端在原始标记消息气泡旁显示 🔖，读屏说明包含书签名称。
同一消息有多个书签时合并为一个图标，保留各书签名称。标记仅属于当前账号和会话。

从继续阅读跳转到不同消息时，对当前续读目标显示 🔖，说明为续读位置；原始标记不移动。
删除目标降级到附近消息时说明为续读定位，不冒充原始书签。普通阅读和回最新只保留固定标记。
添加、重命名、删除、撤销、翻页和消息视图复用后及时刷新；切换会话、账号及关闭后清理。
图标不进入正文、复制、引用、发送或 AI 上下文，不阻碍消息操作，也不改变数据库或分页协议。

验收：三端创建及跳转显示对应消息图标；删除/撤销、独立续读及账号会话隔离；
左右气泡、长消息、附件和窄屏不遮挡；有界列表仍正常翻页。保留现有书签进度测试。
APK 构建与运行组件证据、PWA/Win 浏览器证据、正式发布与装机分别记录。

实现范围：Android reading 组件和适配器薄接线；共享 Web 书签 UI/CSS 及 React 气泡定位属性。
自有 AI/项目页面后续接入范围不变。
