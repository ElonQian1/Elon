# 开放商业消费者运营方签名信任 V1 验收

## 当前实现

- 用户可按消费者项目登记、查看和撤销来源运营方 RSA 公钥，私钥不进入平台。
- SDK 可计算公钥 `key_id`、生成固定协议消息、签署完整导出包并在来源侧验证签名。
- 服务端验证来源标签、Key ID、算法、有效信任记录和 RSA-SHA256 签名；失败不保存可信状态。
- 未签名导入仍保留 `integrity_verified_source_untrusted`，签名通过后使用 `trusted_operator_signature_verified`。
- 同一信封可以从未信任快照升级签名证明，但数据包内容和摘要保持不变。
- 撤销只影响后续信任，不篡改历史导入和审计记录。
