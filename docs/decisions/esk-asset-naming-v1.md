# ESK 主项目资产命名与真源边界 V1

## 决定

主项目面向用户的新代币名称固定为 `ESK`。历史 `NET` 只是未发行候选名，新代码和新界面不再把 NET 当作未来主项目代币名称。既有 NET Paper Schema 和量化模拟仓位在独立迁移前保持历史语义，不自动改写，也不产生 ESK。

ESK 的唯一余额真源位于一龙主项目。量化交易、算力、代理服务和 RWA 产品只能通过版本化授权或资产证明消费余额，不能各自创建一份 ESK 余额。

## 分阶段事实

1. `paper`：主项目追加式登记模拟余额，用户演练查看和卖回申请；未上链、未移动资金。
2. `platform_recorded`：未来经独立审批后登记真实平台负债或权利；其法律条款、储备和兑付规则必须另立决定。
3. `onchain`：未来部署并验证合约后才可展示网络、package/contract ID、treasury 和交易摘要。

后一个阶段不能由前一阶段的数据库记录自动推出。页面必须展示当前实际阶段。

## 不合并的账本

- AI 模型的输入/输出 Token 用量不是 ESK。
- 人民币预存计费余额不是 ESK。
- 节点积分和节点人民币收益不是 ESK。
- 量化内部份额、NAV 和退出金额不是 ESK。
- Sui 链下投影包不是链上 ESK。

任何兑换、奖励或锁定关系都必须通过单独的双分录或锁定合同建立，不能通过改字段名称完成。

## 为什么保留 Paper 门禁

用户信任项目可以支持产品冷启动，但不能证明链上部署、资产权利或兑付已经发生。尤其当发行方同时承诺官方卖回时，系统会从普通积分展示进入发行、兑换和结算边界；因此 V1 先完成准确账户、幂等登记、占用和申请审计，真实发行与支付保持关闭。
