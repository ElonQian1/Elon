# Win 官方 AI WebView 收起防死锁 V1

## 用户问题

ChatGPT 或 Google 官方页以内嵌标签显示后，点击返回原生聊天会让“一龙工作台”
黑屏并进入未响应状态，导致无法继续发送和验收原生富内容。

## 根因

隐藏路径在前端命令尚未返回时同步把正在运行的 WebView2 从主窗口换到隐藏宿主。
Tauri Windows 运行时的 `reparent` 会等待 UI 消息循环完成；官网页面正在加载或流式
生成时，该等待可能和 WebView2 消息处理互相阻塞。

## 目标

- 收起主窗口中的官网页时不执行 WebView2 换父窗口。
- 后台页保持完整桌面视口、同一 Profile、Cookie、DOM、流式观察器和发送能力。
- 以超过最大允许嵌入尺寸的固定坐标停放，窗口最大化、DPI 或 resize 后不会重新露出。
- 已经属于独立宿主的网页留在原宿主，不做无意义的再次换父。
- 原生聊天立即恢复焦点，并可继续显示与同步富内容。

## 验收标准

1. 隐藏命令代码段不包含 `reparent`。
2. 主窗口子 WebView 保持原尺寸，停放到固定 `(20000, 20000)` 后继续显示运行。
3. PC 浏览器合同、Rust 定向测试、Win AI 验证和生产构建通过。
4. 真实 Win 客户端打开官网页后返回聊天，不黑屏、不未响应。
5. 新建会话发送“比特币的走势图现在是怎么样？”后不跳官网、不重复回答，并在原生 UI 显示行情图卡。
