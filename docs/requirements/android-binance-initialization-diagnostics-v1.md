# 币安网页初始化诊断

承接个人网格产品的真实读取验收。主 APK 已能加载官网并绑定适配器，但当前手机未发出可观察的账号和网格列表请求，已有诊断只统计脚本错误数量，无法定位初始化失败。不能将此状态当作空账户或私有接口已接通。

在现有 WebView 宿主和只读 `binance_host_status` 中增加有界诊断：错误类别、经校验的公开静态脚本位置及行号、少量已知缺失浏览器能力名、WebView 是否挂载及尺寸/可见状态。脚本位置仅接受 HTTPS 官网/CDN 的静态 JS 路径，移除查询和片段，拒绝用户资料、私有接口路径及其他来源。错误正文、堆栈、Cookie、认证头及网页内容不进入诊断。每页最多保留六个去重错误，换页和会话失效清空。

该增量不改变读取授权、账户校验、交易合同、网页登录或恢复策略，不新增任意脚本执行、周期查询或临时安装组件。公开脚本定位是对原来仅计数诊断的有意扩展，不扩展业务 IPC。

验收：分类、去重、上限、非法来源及敏感内容拒绝、清空行为通过单元测试；原网格合同回归通过；正式原签名主 APK 发布并覆盖安装后，通过现有 MCP 取得本机初始化证据。后续按证据修复真实失败层；本项诊断交付不等于列表、创建或交易验收完成。
