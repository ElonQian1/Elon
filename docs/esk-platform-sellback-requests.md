# 正式 ESK 卖回申请使用与协作边界

需求及验收真源：[正式卖回申请与占用 V1](requirements/esk-platform-sellback-requests-v1.md)。
本页解释独立合同与操作路径，不是生产开启公告。部署、实测与真实用户验收分别记录，
不能因代码存在、页面可打开或合成测试通过，认定用户已可成交、提现或获得收益。
版本、公开检查和待验收项见 [交付记录](delivery/esk-platform-sellback-requests-v1.md)。

## 用户看到什么

主 APK：个人中心 → 正式 ESK 平台登记 → 卖回申请与占用。
页面只使用当前登录本人的正式平台账本，区分以下三个数量：

| 名称 | 含义 |
| --- | --- |
| 正式总量 | 经审核入账的持有量；不是链上余额证明 |
| 申请占用 | 已提交且尚未取消的正式申请量；仍包含在正式总量中 |
| 可申请量 | 正式总量减申请占用；不是 USDT 金额、报价或即时兑付承诺 |

不能把三个数量相加，也不能加上 Paper 模拟数量。QSHARE 份额和净值继续独立核算。
原正式账户与跨 APK 摘要保持旧合同：其总量是总持有量，不偷偷改成可申请量。
量化 APK 本轮不接收新的占用字段，后续须单独版本化、授权和联调。

## 申请、取消与结果未知

1. 先读取本人记录和条款。没有经批准且已开启的独立政策时，不可新建。
2. 新申请填写 ESK 数量，核对当前账号、精确金额和条款，确认这是新的独立申请。
   一笔提交在服务端原子占用；不产生价格、成交、付款或资金转移。
3. 本人可以核对并取消已有申请。取消只解除该笔占用，不新增 ESK、不付款，
   重复取消也只释放一次。本版本没有自动到期、审核成交或执行提现路径。
4. 超时、断线、错误响应或退到后台不证明服务器没执行。先读取本人记录或
   按原幂等键查回；同一前台内可再次明确确认后用原键、原内容重试。
5. 查回未找到仅说明查询时未看到记录，不能据此自动创建另一笔。若仍不确定，
   保持待核对状态；“已核对”是用户判断，不是系统证明旧请求不存在。

后台、换号、退出和错误会清理私有展示及旧操作权，不会撤销服务端已收到的请求。
仅同进程、具有会话修订的只读恢复提示可保存不透明键；不保存金额、提交内容或同意。
进程重建后不从磁盘恢复旧操作，重新读取当前本人的记录并再次确认。

## 暂不可用时

- 公共 HTTP 不能用于传送真实私有会话。现有 APK 保护保持不变，不会因卖回功能
  关闭证书校验、放开重定向或改用 Paper 认证。公共信息和下载入口不等于私有读取。
- 当前政策缺失、无效或关闭，仍可在有效本人会话下查询及取消合法旧申请。
  停用账户不能绕过认证；异常处理渠道应在开启前批准的条款中明确。
- 可申请量大于零也不保证新请求获准；单笔、每人笔数、每人占用和全平台额度
  由服务端再次检查，其他并发请求可能先完成。
- 读取失败不显示猜测的零余额，提交错误不显示猜测的“已退款”。

网页只同步上述正式来源说明、页面名称与主 APK 下载路径，不提供正式私有余额或写操作。

| 原生解析、本人会话、页面和恢复 | `android/app/src/main/kotlin/com/elon/app/esk/platform/sellback/` |
| 网页说明与旧资产兼容 | `server/src/assets/web_page.html`、独立网页边界回归 |

新增状态先更新版本化需求、跨端合同及验收，不复用 Paper 状态或扩写旧 IPC。
报价、手续费、结算资产、实际付款、参与权重变化属于后续切片，不由申请开关推定。

上线前另行批准实际政策、用户范围、额度、条款、受保护连接及真实本人验收；
本说明不提供可直接开启的生产参数，不授权修改真实余额或执行资金操作。
