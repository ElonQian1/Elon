# 开放商业消费者关系人工映射与重新授权 V1 验收

## 当前实现

- 用户可从本人隔离包选择来源关系，并明确确认映射到当前有效发布商户。
- 映射按用户、消费者项目、导入包和来源关系隔离，支持幂等创建和显式撤销。
- 新授权只能使用用户自己的独立开发者 App，不能使用公共 `pc-web` 身份。
- 申请范围不能超过来源关系原范围，并继续经过目标商户现有授权规则。
- 旧关系和旧 Grant 不复制，目标商户仍需独立批准新申请。
- PC 工作台提供选择来源关系、搜索并选择已发布目标商户、管理映射和重新申请入口。目录搜索不代替消费者的同一主体确认。
- 签名可信 V4 包可显示公钥指纹匹配候选，映射保存当时的匹配证据；普通完整性包不产生该证据。
