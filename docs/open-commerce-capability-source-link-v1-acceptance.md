# 开放商业能力与内部同步回执来源绑定 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- V164 单能力单当前绑定、修订递增及级联清理结构。
- 同项目、同商户、同接入、数据域登记和回执资格校验。
- 能力版本变化、接入停用和回执状态异常的公开失效判断。
- 项目总览中的全部绑定和稳定阻断原因。
- 公开目录中的内部回执来源元数据、SHA-256 摘要和回执时间新鲜度。
- 商户 PC 绑定、重绑、移除与失效提示。
- 消费者 PC 来源标签和“未经外部平台验证”提示。

## 统一回归必须验证

- V164 从现有数据库升级、重复执行、外键级联和单能力唯一约束。
- 跨项目、跨商户、跨接入、未登记数据域、健康检查和失败回执全部失败关闭。
- 成功与部分成功回执可绑定，重复绑定修订递增且审计完整。
- 能力任意更新导致旧绑定不可公开，重新绑定恢复当前版本。
- 接入停用后目录回退普通商户声明，重新启用后的既有绑定行为符合决定。
- 公开目录、消费者发现和排序凭证中的来源字段、摘要和新鲜度快照一致。
- 旧客户端忽略新增可空字段时仍可读取目录，旧项目无绑定时行为不变。
- 商户 PC 的空列表、长名称、多个能力、多个数据域、解绑和窄屏布局。
