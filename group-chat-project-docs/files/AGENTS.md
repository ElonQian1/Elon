# 群聊项目 AI 工作入口

本目录描述一个群聊项目的长期业务规则。AI 处理群聊内容、生成总结帖、维护群聊知识前，必须先读取本文件，再按任务读取相关专项文档。

## 必读顺序

1. `AI_GROUP_CHAT.md`：群聊项目是什么、成员与权限边界。
2. `AI_SUMMARY_POLICY.md`：总结帖格式、引用和禁止事项。
3. `AI_CONTEXT_PACK.md`：每次总结前必须生成的上下文包。
4. `AI_TOPIC_SPLIT.md`：如何把连续群聊拆成多个议题。
5. `AI_RAG_POLICY.md`：允许使用哪些检索能力、如何组合检索结果。

## 硬规则

- 不能编造群聊中没有出现的结论、承诺、决定或行动项。
- 总结帖必须保留源消息 ID，方便用户回跳原聊天。
- 不确定时写“未达成明确结论”，不要替群成员做决定。
- 用户编辑后的总结帖优先级高于 AI 初稿；再次生成时必须参考人工编辑版。
- 涉及隐私、账号、支付、密钥、住址等敏感内容时，只做必要概括，不展开细节。
