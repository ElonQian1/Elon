# 一龙量化交易加入前公开预览 V1

## 目标

用户在项目广场加入“一龙量化交易”之前，可以读取官方目录提供的净化项目介绍，理解当前能力、Paper-only 边界、计划状态和与一龙主项目的关系。读取预览不登录、不加入项目，也不创建 Paper grant、仓位或交易请求。

## 范围

- `GET /api/store/projects/:id/preview` 只为当前公开且存在于内置官方目录的项目返回预览。
- 项目广场列表为可预览的官方项目返回 `preview_action`，PC 广场按需读取预览并展示详情弹窗。
- 预览只投影白名单字段：标题、标语、摘要、说明、功能亮点、目标用户、最近更新、隐私说明、系统要求、下载计划状态，以及净化后的受控 Paper 入口说明。
- 下载项只公开 `kind`、`label`、`status` 和 `note`；不公开下载 URL、manifest URL 或任意 landing 资源 URL。

## 非目标

- 不公开任意用户项目的完整 landing，也不把工作区路径、成员信息或项目文档正文放入预览。
- 不改变加入、申请、创建 ERP 实例、项目主页或成员权限流程。
- 不部署量化 Web/Windows/Android 客户端，不启用 sandbox/live 交易。
- 不签发代币、不接收或移动真实资金，不承诺固定收益，也不证明 KYC、付款或投资准入。

## 安全与兼容边界

- 非官方、私有、邀请制、删除或不存在的项目不返回预览。
- 响应 schema 固定为 `yilong.official_project_preview.v1`；未知字段由消费者忽略，现有项目列表字段保持兼容。
- 预览内容来自随 Server 构建的官方目录，不能被普通项目 landing 覆盖。
- 弹窗加载失败必须提供关闭和重试，不得自动执行加入或启动 Paper。

## 验收标准

1. 匿名请求公开官方项目预览返回 V1 schema 和白名单字段；非官方项目返回 404。
2. “一龙量化交易”预览明确显示 Paper-only、非保证目标、不接收或移动真实资金、客户端仍为 planned。
3. 响应序列化结果不包含 `url`、`manifest_url`、grant、participant、账户、密钥或仓位数据。
4. PC 项目广场在加入前显示“了解详情”，具备加载、成功、失败重试、Esc/遮罩关闭和可访问对话框语义。
5. 打开或关闭预览不会调用加入、申请、Paper launch 或任何写接口；原筛选、cursor 分页、加入和 ERP 创建路径保持可用。
6. 官方目录合同、Rust 定向测试、PC 类型检查/生产构建和线上匿名只读 smoke 通过。

## 回滚

回滚 Server/PC 前端到上一已验证版本即可移除入口。接口没有迁移、写入或用户状态，回滚不需要修改数据库；官方目录和既有项目主页继续保留。
