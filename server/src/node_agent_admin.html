环境变量参考（高级，普通用户无需配置）

登录后所有凭证自动持久化到本地，普通用户不用设置任何变量。以下仅供高级/服务器场景：

NODE_CLOUD_URL       云端 WebSocket 地址（默认 ws://43.139.149.158:8080/agent/ws）
NODE_USER_TOKEN      登录 token：设置后首次启动自动注册，免去网页登录
NODE_AGENT_ID        手动指定节点 ID（搭配 NODE_AGENT_SECRET 跳过自动注册）
NODE_AGENT_SECRET    手动指定密钥
NODE_OLLAMA_URL      本地 Ollama 地址（默认 http://localhost:11434）
NODE_LM_STUDIO_URL   LM Studio 地址（可选）
NODE_CUSTOM_LLM_URL  自定义 OpenAI 兼容地址（可选）
NODE_PRICE_PER_1K    每 1k tokens 收取的积分（默认 0.1）
NODE_STORAGE_ENABLED 启用项目硬盘服务（true/false）
NODE_STORAGE_ROOT    项目硬盘服务存储根目录
NODE_STORAGE_GIT_BASE_URL 外部 Git 服务基础地址（可选；默认使用云端 relay）
ELON_AGENT_API_KEY   Route B 本机 API runtime 的 API Key
ELON_AGENT_MODEL     Route B 本机 API runtime 的模型
ELON_AGENT_API_BASE  Route B OpenAI-compatible API 地址
NODE_ADMIN_PORT      本管理页端口（默认 7799）
