# 团队资产公开汇总转发 V1

用户明确授权向所有量化用户公开团队币安总估值与更新时间，不公开具体持仓。
新增 `GET /quant/api/v1/team-assets/summary`，只访问既有固定 loopback 量化服务。
私有账户、Paper、运营接口仍受原有边界约束。

## 实现与验证

`quant_http_preview.rs` 只增加路由与转发分支；`quant_team_assets.rs` 负责精确方法、
无参数/无请求体以及公开响应白名单。上游只有 200、至多 8192 字节、12 个完整字段、
规定 schema/source/scope/BTC 和只读标志才可转发；未知/重复字段、秘密扩展、错误
状态、缺少显式 null、非法金额和非预期类型失败关闭，不把上游原文回传给公众。

主服务 `quant_http_preview` 测试 10/10 通过，包含新模块 3 项测试；实际 elon-server
二进制测试目标已编译。验证指纹为
`3446844f862f5c1ee1c1a91d19859faea7d0cad6d49864354dedc9b7e7ac0248`。
它证明本地边界与兼容性，不证明公开部署、真实团队资产同步或 APK 验收。

## 部署与恢复

量化源功能位于独立仓库 `codex/team-binance-assets-v1`，与原任务的正式 APK 发布
候选隔离。共同发布继续协调；量化 API/PWA、主服务公开路径和采集器都必须部署后
才能验收端到端。当前采集凭据未提供，真实同步待验证。

撤回此路由可立即关闭主入口；量化侧关闭采集器后按时效降级。公开快照只包含批准
披露的数据；主服务不接触币安 Key/Secret。HTTP 预览不构成资产真实性审计证明。
