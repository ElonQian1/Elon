# 币安与 X 原文预览回填

状态：current；2026-09-16。

## 目标与边界

沿用公众号原文读取，将用户主动打开的币安广场帖子、文章和 X 帖子、文章的标题或短摘要、作者、真实配图补回聊天卡片。原文仍由官方网页提供；公开网页不保证匿名 HTTP、oEmbed 或跨域 iframe 可以取得相同内容。

缓存只在本机，按一龙服务器和账号隔离，最多 128 条，24 小时失效，不保存正文全文、Cookie、令牌。原消息及分享参数不变。纯文字无封面时维持平台标识，不伪造图片。登录、验证、删除、跳到其他帖子时不得覆盖卡片。

## APK 阅读浮窗（2026-09-18 起）

APK 的原文阅读器不再随"返回聊天"/返回键销毁：阅读会话由 `SocialLinkReaderSessions` 在应用级保活（最多 3 个，超出时淘汰最久未用的已最小化会话），WebView 挂在 `MutableContextWrapper` 上随 Activity 迁移；最小化后页面继续加载、回填读取继续，重新打开秒回原位置且不重载。聊天页右侧出现应用内浮球（不申请系统悬浮窗权限）：显示站点徽标、加载中转圈、多篇时角标计数，可拖动并贴边、位置记忆；点击恢复最近一篇，长按关闭全部。阅读器新增"关闭"按钮才真正销毁会话；系统回收 Activity 时同样只最小化。

## Windows 阅读标签（2026-09-17 起）

Windows 客户端不再用模态对话框打开原文。点击卡片在窗口顶部新增 Chrome 风格的阅读标签（首个固定标签是工作台本身），阅读内容默认停靠在聊天右侧、宽度可拖动，聊天区始终可输入；右键标签可切换“停靠在聊天右侧 / 覆盖整个工作区 / 弹出为独立窗口 / 收回到主窗口 / 在系统浏览器打开 / 关闭”。标签对应的原生 WebView 常驻：切换或收起时只移到屏幕外而不销毁，回填读取在后台继续；最多 8 个标签，同一链接不重复开。阅读标签共用一个持久化 Profile（登录态可复用），与 AI 官网会话隔离。原生 WebView 始终画在页面之上，因此有其他弹窗打开或拖动分栏时阅读内容会暂时收起。桌面壳命令 `open/resize/control/get/list_internal_browser_tab(s)` 增加 `tabId`，缺省 `source` 保持 AI 来源网页兼容。

## 成员回填共享（2026-09-17 起）

服务端因风控或网络无法抓取时，APK/Windows 在本机回填成功后额外向 `POST /api/me/link-preview/report` 上报同一份适配器输出（标题、摘要、作者、图片地址、原始 URL），不含正文、Cookie 或分享签名之外的任何页面数据。服务端重新执行同 ID 校验、标题黑名单、图片 CDN 白名单与每账号限速，只在没有自己抓到的完整结果时采纳，标记 `source=member`，与服务端结果同样 24 小时失效；卡片来源行显示“成员回填”。服务端同时把封面复制为小尺寸内嵌缩略图（`cover_data_url`）供各端优先使用，避免 CDN 防盗链。上报失败静默，不影响本机卡片。

## 验收

- APK 原文延迟渲染后读取，退出阅读器返回聊天后更新；重启仍能读取未过期缓存。
- Windows 使用受限原生读取命令，仅主窗口可调用，只允许读取当前打开且 ID 相同的支持页面，不提供任意脚本接口；旧客户端继续打开原文。
- PWA 继续官方嵌入/原文及服务端预览；浏览器跨域限制下不宣称支持外部标签页 DOM 回读。
- 公众号既有路径继续通过；帖子摘要、文章标题、配图、空封面、延迟、错误页面、切换账号、过期/容量及关闭读窗竞态有针对性验证。
- Android、PC 和桌面原生代码分别构建与发布；真实站点不可访问时分开报告离线证据和现场缺口。

## 接入证据

- [X 官方 oEmbed](https://docs.x.com/x-for-websites/oembed-api)：返回 HTML 片段及作者，不保证独立标题/封面字段，按 cache_age 缓存。
- [Binance 官方 Square Post](https://www.binance.com/en/skills/detail/binance/square-post)：说明短帖、多图、长文章与可选封面；这个公开工具只发布，不提供读取能力。未查到通用任意广场 URL 的官方 oEmbed 说明。

## 文件边界

原文 DOM 适配器放 Android assets，由 Android 和 Tauri 编译时共用；宿主负责身份、大小、会话边界及缓存。PC React 阅读器接回共享卡片。服务端获取规则、聊天存储协议和账号权限不变。
