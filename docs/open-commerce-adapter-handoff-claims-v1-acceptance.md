# 开放商业接入器任务领取与租约 V1 验收

## 已落位代码

- 任务领取权限与只写权限分离，签发或轮换时由项目编辑者显式选择。
- 每次领取一条任务，租约绑定商户、接入器、凭据 ID、凭据版本和一次性租约密钥。
- 活动租约可用同一密钥续租 60–900 秒，但首次领取即固定 1 小时绝对期限，避免无限心跳占用任务。
- 同一 Invocation 的活动租约由数据库唯一约束和立即事务共同防重。
- 完成回执与租约状态原子提交，回执保存 `adapter_claim_id`，重复提交复用原回执。
- 接入器可使用租约密钥主动释放未完成任务，释放原因受限、不会创建业务回执，任务可立即重新领取。
- 被拒绝任务按尝试次数进入 30–900 秒有界退避，领取顺序优先未尝试及最久未尝试任务；第 6 次拒绝后暂停自动重试，避免热循环和永久失败任务持续消耗资源。
- 项目编辑者可经明确确认把当前暂停项重新排队；服务端拒绝普通成员、重复恢复和对旧尝试的恢复。
- 项目内 AI 可用 MCP 列出同一租约视图，并在编辑者权限与明确确认下调用同一恢复服务。
- 项目工作台可查看最近租约的处理中、退避中、可重试、需人工处理、已回执、已释放和已超时状态，不展示 Token 或租约密钥。
- Connector SDK 提供通用顺序工作器，自动领取、续租、生成稳定回执键、重试幂等完成请求和优雅停机；商户适配器只实现带 Invocation 幂等键的业务处理函数。

## 仍未实现

- 历史数据库迁移、并发数据库租约压力、公网 TLS、PC 浏览器与受控生产凭据演练仍待专项回归。
- 真实厂商或 ERP 生产适配器、官方授权、外部回读和外部签名证明。
- 超过 1 小时的租约、批量任务、可配置优先级、失败赔付和跨运营方消息总线。
- 支付、分账、退款、链上提交或任何真实资金移动。
