# Sui 离线预检任务与短时租约 V1 验收

## 当前状态

`implementation_partially_verified`

Node SDK、CLI 和单任务工作器已经完成离线契约验证；服务端也已通过本地新库、V158 形态内存库升级、真实 Axum 项目/机器接口、租约边界与强制硬截止恢复、跨项目隔离、适配器失效、摘要漂移、并发单租约、标准/纠正争议阻断、原子纠正包离线预检、数据库写入失败回滚和本地 SQLite 一致性备份恢复验证。全部测试均不使用生产凭据、不连接 Sui 网络。真实长时工作器、操作系统级磁盘故障、生产库备份恢复和 PC 页面仍未验证。

## 已形成代码

- V159 显式任务队列、状态、适配器绑定、租约和报告引用。
- 项目编辑者从当前可导出投影包入队和取消待处理/阻断任务。
- 机器按适配器网络与投影类型权限领取任务。
- 60 至 900 秒租约、1 小时硬截止、续租、释放和过期回收。
- 领取前只读重建交接包，摘要漂移或不可导出时阻断任务。
- 完成报告与任务状态的单事务写入和幂等重放边界。
- PC 标准包、纠正包入队入口，以及任务列表、租约摘要和取消入口。
- SDK 任务客户端和 CLI `claim/renew/release/complete` 命令；凭据只从环境变量读取，领取不会自动完成任务。
- 可中止的单任务工作器，支持到期前续租、稳定完成幂等键、有限完成重试和异常释放。

## 已验证

- SDK 全量 `npm test` 通过 19 项测试，其中 12 项覆盖 Sui 离线预检。
- CLI 已实际执行文件复核、报告、领取、续租、释放和完成；HTTP 仅指向测试进程内的本机假服务。
- 适配器 Token 和一次性租约 Token 只从环境变量读取，命令行凭据参数在发起请求前被拒绝。
- 客户端会拒绝摘要篡改、链上提交标记、空领取夹带任务、跨任务续租响应、跨项目报告和完成报告绑定冲突。
- 工作器已验证到期前续租、同一幂等键完成重试、续租停止竞态、显式异常释放和进程中止释放。
- `elon-server` 已通过 4 项定向 Rust 测试：V159 本地新库可创建并运行任务，项目 HTTP 接口拒绝未登录和跨项目用户，入队与取消要求编辑者明确确认。
- 真实 Axum 机器接口已验证缺失/无效 Bearer 凭据被拒绝、领取时租约明文仅返回一次、续租、释放、重新领取及完全相同完成请求的幂等重放。
- 两个独立 SQLite 连接并发领取同一任务时只有一个获得租约，数据库中的 `attempt_no` 只增加一次。
- 上述服务端验证指纹为 `327322d6e7b05c04ad0f43c58f9c5aa0f1de31c9f0c24f879dfce85707f141b2`，结果为 4 项通过、0 项失败。
- V159 迁移已通过 3 项定向 Rust 测试：已有 V158 适配器数据在重复执行升级后保留，项目/用户/适配器/报告外键、包类型/网络/状态/尝试次数检查，以及活动包、租约摘要和报告引用唯一性均实际拒绝非法写入。
- 上述迁移验证指纹为 `6e053c201f03f70c3b26e86891a405ea2c9b390f14742ef5a58141b380bcba9b`，结果为 3 项通过、0 项失败；该证据不是生产数据库备份恢复演练。
- 租约过期后同一任务可由当前有效适配器重新领取，尝试次数只增加一次，旧租约令牌不能续租；网络或包类型不匹配的适配器不能领取任务。
- 适配器凭据轮换会使旧凭据和旧租约失败关闭，停用后的当前凭据也不能完成任务；交接摘要漂移会阻断旧任务，重新验证后可创建新的待处理任务。
- 完成请求复用相同幂等键但更改结果时被拒绝，原报告、投影摘要、完整性、提交就绪状态、`not_submitted` 和零提交次数均保持不变。
- 上述失败关闭验证指纹为 `0c715a5828c81e2b615a6691a313f833565fedf56638e3ecc0566eafc5dc1c13`，结果为 6 项通过、0 项失败。
- 租约请求小于 60 秒或大于 900 秒被拒绝，边界值可领取；把租约到期和 1 小时硬截止强制推进到过去后，旧完成请求失败，任务可由当前凭据重新领取。
- 另一项目的机器适配器即使网络和包类型相同也看不到当前项目任务；预先存在的冲突报告会使完成事务保持任务为 `leased` 且不绑定报告，改用新幂等键后才完成。
- 上述边界验证指纹为 `ecdfb9190ce0eb87dbdea58cdc2fbc5ff7c60aa5955f1fb911d0b56f370944fd`，结果为 3 项通过、0 项失败；强制时间戳测试不是实际等待一小时的工作器演练。
- 标准投影任务入队后新增争议会在领取时把任务阻断，争议状态下再次入队也会失败关闭。
- 已过账纠正的冲销与替换双腿可由仅允许 `correction` 的适配器领取并完成离线预检；仅允许标准包的适配器看不到该任务，交接包同时包含两条腿，完成后投影仍为 `not_submitted` 且提交次数为零。
- 替换凭证新增争议会阻断已入队纠正任务和后续入队，不会把争议中的纠正包交给机器。
- 上述业务分支验证指纹为 `8a8ec5faf2f3383848a0e206cef6dc99a2740ecabee2c7c6ab105ad007d3e59f`，结果为 3 项通过、0 项失败。
- SQLite 触发器分别注入报告插入失败和任务完成更新失败；两种情况下任务均保持 `leased`、不绑定报告且报告表无残留，移除故障后同一租约可恢复完成。
- 上述事务故障验证指纹为 `25f6c75aceeb41169aa8d9b0c3d69deb8ef9bd9a06351b902b9807a251868afa`，结果为 2 项通过、0 项失败；该证据不等同于操作系统级磁盘故障演练。
- 通过 SQLite `VACUUM INTO` 形成一致性快照后，待处理任务、适配器凭据哈希和投影引用可在重新打开的数据库中恢复，原机器 Token 可继续领取并完成任务。
- 已完成任务、报告引用和幂等键在快照恢复后保持一致；同一租约与完全相同完成请求只返回原报告，不产生第二条报告。
- 上述本地备份恢复验证指纹为 `2146f6e9c9de41c8ffdfa337ef207bb9ebc2a966e50e061e00b48016bd7aa5b9`，结果为 2 项通过、0 项失败；该证据不等同于生产数据库备份恢复演练。
