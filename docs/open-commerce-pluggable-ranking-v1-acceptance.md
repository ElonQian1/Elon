# 开放商业消费者可替换透明排序器 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已验证

- 消费者发现请求可显式选择五种内置排序策略，省略时兼容原偏好匹配策略。
- 服务端统一解析策略、选择单个商户能力并对最终结果执行确定性排序。
- 响应返回当前策略、可读解释、用户是否显式选择以及完整可用策略清单。
- 所有内置策略固定标识为非付费排序，未知策略失败关闭。
- 省略、空白和显式默认策略的兼容结果，以及五种策略的多商户顺序。
- 同一商户多能力在主排序值相同时先按偏好分和价格，再按能力键与版本稳定并列。
- 同一候选集重复请求顺序稳定，目录同时间戳以商户 ID 收口，未知策略失败关闭。
- 价格、能力、偏好、来源和 App 身份过滤继续先于排序生效。
- 策略键、名称、解释、用户选择标识、五项描述和 `ranking_is_paid=false` 完整一致。
