# APK 社交同步提示生命周期修复

普通好友同步的空列表提示挂在共用消息容器上。切到 AI 聊天时原读取被取消，提示未随之清除，可能覆盖已经出现的另一套消息；首次读取尚未结束时发送消息也存在残留风险。

本次仅修正 APK 状态归属，不更换主题、消息协议、缓存及读写重试策略。

## 验收

- 暂停、退出或交接到 AI 聊天后，同步提示消失，取消后的迟到响应不能重新显示它。
- 普通好友与群聊首次成功同步后显示消息或正确空态；有消息时后台轮询不显示同步遮罩。
- 发送或转发产生待发消息后清除空列表提示，不需要等待网络回执。
- 空列表首次网络失败仍能显示可点击重试；隐藏时清除重试动作，重新进入可重新加载。
- 通过 Android 定向回归与正式 APK 构建，核对线上版本、源码来源及安装包；实机未验证时如实记录。

实现范围：SocialChatStatus、MainFriendChatActions、MainGroupChatActions 及相应回归测试。
