# APK 手动网格对话与只读 MCP

复用主 APK 的 BinanceHostRuntime、身份验证和固定私有读取适配器，向本人授权的
MCP 提供实际网格列表及精确策略详情。手机不依赖 Win 登录；两端不得混用账户。
聊天仅在点击“附带网格”时读取，用户选择、预览后将快照加入当前 ChatGPT 草稿，
点击发送才通过已有发送器提交。快照直接可见、可移除，不作为隐藏附件自动复用。

## 合同

- 本机认证 MCP 的 binance_grid_read 只接受 list/detail、request_id、start、分页和策略 ID。
- 显式 start 才初始化会话和读取；轮询与分页只读取同一不可变快照，不触发新私有请求。
- 每次详情前取得新列表，验证策略属于当前账户；只输出固定字段与采集时间，精确值为字符串。
- 快照最长五分钟、最多十六份、列表最多五百条、每页最多五十条；相同请求不同身份拒绝。
- 读取绑定主账号、币安账号、文档和请求；换号、文档变化、超时和并发冲突明确失败。
- MCP 与聊天复用一个读取服务；不持久化快照，不输出账户标识、Cookie、token 或网页任意文本。
- 草稿绑定当前 ChatGPT 会话和来源；发送只验证、不刷新。失效时要求重新点击读取。
- 官网登录/验证继续由用户完成。创建、加仓、终止、交易、钱包读取不属于本功能。
- 扩展已有供应商无关 stdio MCP；不自动修改 Claude 桌面配置或扩大旧会话授权。

## 验收

1. 手机后台宿主可由认证 MCP 启动，返回真实新列表、分页及精确详情，无桌面或坐标操作。
2. 空列表、错误策略、重复请求、过期、并发及来源变化均有确定结果，不回退到旧缓存。
3. 普通聊天不读取币安；只有手动入口读取。取消、移除、换会话不留下隐藏附件。
4. 快照预览与发送内容一致，发送一次，使用原 ChatGPT 私有发送及回执机制，不盲目重放。
5. 定向测试、正式发布、设备安装与版本回读分别取证；真实账号或网络缺口独立记录。
