# 网格卡片消息行与引用修复

## 原因与边界

APK 旧卡片按显示屏宽度分配固定尺寸，真实消息行还包含头像、边距及多选栏；卡片因此超过气泡可用宽度。此前独立卡片测试没有覆盖这个父布局。

APK 将网格归入特殊卡片，跳过了通用消息长按动作；PWA 已有消息动作，但引用摘要仍把协议 JSON 当正文显示。此次复用现有消息菜单及结构化引用协议，不新增服务端写接口，不操作币安、不发送生产群测试消息。

## 行为

- 卡片以实际父布局可用宽度测量；PWA 专属气泡去除重复内边距，保留其它卡片样式。
- 单击打开只读详情；长按打开引用、复制、转发、多选菜单；滚动取消长按，长按松手不会再打开详情。
- 引用草稿及已发送引用显示 `[网格快照] QNTUSDT · 做多 10×`；发送仍携带原消息 ID/修订，由用户点发送。
- 点击引用可定位已加载原消息；原消息撤回或不可用保留原有提示。多选期间卡片只切换选中状态。
- 已公开金额和数量继续显示，存储精度不变；历史隐藏快照继续尊重原公开边界。
