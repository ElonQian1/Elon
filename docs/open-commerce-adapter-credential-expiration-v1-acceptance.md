# 开放商业接入器凭据限时有效 V1 验收

## 已实现

- 新签发和轮换必须选择 1–366 天有效期，服务端生成并保存绝对到期时间。
- 鉴权以数据库时间检查到期状态；过期 Token 即使摘要、凭据状态和接入状态仍匹配也无法使用。
- 现有凭据迁移时补 90 天期限，不保留永久有效凭据。
- PC 默认选择 90 天，显示到期日、已到期和 14 天临期提醒。
- 到期不改写历史机器回执；恢复使用必须轮换并产生新版本。

## 验证范围

- Rust 测试覆盖有效期上下界、过去时间失败关闭、服务端 `is_expired` 以及旧数据迁移回填。
- PC 构建和契约测试覆盖显式有效期参数、默认选项、到期状态和临期提示。
- MCP Schema 与领域服务执行双层 1–366 天校验。

## 未完成边界

- 尚无到期通知、自动轮换、双 Token 交接窗口或外部秘密管理器。
- 没有生产平台适配器、外部授权到期同步或外部 ERP 回读。
