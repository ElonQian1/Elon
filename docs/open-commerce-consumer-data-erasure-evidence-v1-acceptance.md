# 开放商业消费者删除请求外部证明 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- V160 新增追加式外部删除证明账本，单个删除请求可记录多个外部系统证明。
- 只有商户已声明完成的请求可附加证明，且只有商户项目编辑者可提交。
- 提交字段包含证明类型、外部系统、回执编号、回执 SHA-256、摘要和显式未核验确认。
- 相同请求、外部系统和 SHA-256 重复提交返回既有记录，不重复写审计。
- 消费者查询按本人项目和本人账号隔离；商户查询按项目与商户隔离。
- PC 商户端可在完成请求下追加证明，消费者端可查看证明摘要和固定来源边界。
- 响应固定返回 `merchant_supplied_unverified` 与 `platform_verified: false`，不冒充外部平台核验。

## 统一回归清单

1. 从 V159 升级及空库执行 V160，验证外键、唯一约束、摘要格式约束和索引。
2. 编译 Rust 服务端并执行新增模块及现有删除请求相关测试。
3. 验证未完成请求、只读项目成员、跨项目、跨商户和跨消费者提交均失败关闭。
4. 验证同摘要幂等、不同摘要追加、删除请求级联清理及审计只写一次。
5. 构建 PC 前端并验证商户登记、消费者读取、长文本、空状态和错误状态。
6. 验证原删除请求、MCP、可携带包 V1-V4 和旧数据库升级不发生回归。

## 本批未执行

根据当前快速开发策略，本批未运行 Rust 编译、Cargo 测试、PC 构建、TypeScript 检查、数据库迁移、HTTP 调用、权限验证或界面验证。不能声称代码可运行、外部删除已发生或证明已被平台核验。

## 后续边界

- 外部适配器可在获得官方授权后自动提交回执，但必须保留来源身份和验证结果。
- 原始回执文件、签名验证、可信时间戳和可选链上摘要应作为独立版本设计。
- 删除证明已进入 V5 可携带数据包代码，版本与兼容边界见 `docs/decisions/open-commerce-consumer-portability-exports-v5.md`；该批同样尚未编译或验证 V1-V4 摘要兼容。
