# Win ChatGPT 私有金融组件与回答去重

## 目标

Windows Tauri 原生聊天在被授权观察 ChatGPT 官方会话响应时，应把同一轮私有流与官方页面快照合并为一条助手消息，并将响应中结构化的金融组件转换为项目既有富内容协议，不再显示重复正文或通用“交互内容”占位。

## 范围

- 仅修改 Windows 共用 WebView 适配资产、Windows 本地 AI 浏览器和对应测试；不修改 PWA。
- 被动观察官方请求响应，不重放、不伪造或增加官方请求。
- 解压并解析 `message.metadata.view_state.widgets` 中获准使用的 gzip JSON 金融组件。
- 对字段、组件数量、压缩体积、解压体积、图表点数和生命周期设置严格上限。
- 私有流消息与当前用户问题之后的最终 DOM 助手消息按逻辑轮次去重，并保留引用和富内容。
- 私有结构缺失或解析失败时继续使用 DOM 富内容提取和官方页回退。

## 验收标准

1. 同一个问题的私有流结果和 DOM 完成结果只显示一条助手消息。
2. ChatGPT 金融组件能够显示名称、价格、涨跌、周期、折线数据和指标，不再退化为“交互内容”。
3. 私有金融组件只解析已授权字段，超限、损坏或未知结构安全忽略。
4. 旧的 Markdown、引用、Google AI 和官方页回退能力保持不变。
5. Web 适配器单元测试、富内容合同测试、Win Web AI 全量验证和正式构建通过。
