# 消费者本人授权状态 MCP V1 验收

状态：`implementation_uncompiled`

## 已形成代码

- 查询由当前项目、当前用户和本人 App 三重条件约束。
- 支持四种稳定状态筛选和 1 至 100 条有界返回。
- 返回批准后的 Grant 期限、次数和预算，但省略内部身份字段。
- 工具只读，不推进任何授权或调用状态。
- 项目编辑者可在固定确认短语后撤回本人 pending 请求，并复用现有双侧审计。
- 非 pending 请求幂等保持原状态，批准后的 Grant 不受影响。

## 最终统一回归

- 多用户同项目、多项目同用户和相同 App 名称隔离。
- 四种状态、空结果、边界数量和非法状态。
- 批准后 Grant 字段、拒绝说明和取消状态。
- 响应不存在商户项目、申请人/审核人用户 ID 和任何凭据。
- 历史 approved 但 Grant 过期或撤销时，执行计划仍失败关闭。
- 本人/他人请求、项目编辑/只读权限、正确/错误确认短语和重复撤回。
- 消费者项目与商户项目均形成现有取消审计，且没有 Grant 撤销副作用。

本批按快速实现策略只完成 Rust 格式化、静态差异和文件规模检查；未执行 Cargo 编译、数据库查询、MCP 或端到端验证。
