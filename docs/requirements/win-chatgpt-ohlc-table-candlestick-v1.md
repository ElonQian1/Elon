# Win ChatGPT OHLC 表格 K 线降级 V1

## 用户问题

游客态 ChatGPT 可能只在可见两列表格中给出最新价、开盘、最高和最低，却在正文中声称已展示
K 线。Win 原生聊天能同步表格，但不能把这组明确行情字段显示成 K 线富内容。

## 范围

- 复用现有 `yilong.rich-content.v1` finance 卡和 K 线渲染器，不建立第二套行情协议。
- 仅从官网回答中字段明确、可见的两列表格读取 OHLC；“最新价”只在同表同时存在开、高、低
  时作为最新收盘值，生成一根标为“最新交易日”的 K 线。
- 缺少任一字段、数值不是有限数，或 high/low 无法包含开收盘时失败关闭并保留原表。
- 不读取 Cookie、凭证、请求头、截图像素或未授权私有响应。

## 验收标准

1. Finance AST、Rust 清洗和 TypeScript 校验接受 1–512 根合法 K 线，仍拒绝空数组和矛盾 OHLC。
2. 官网可见的“最新价、开盘、最高、最低”两列表格转换为单日 K 线行情卡，并保留标题、代码、
   涨跌和原始指标。
3. 普通表格、缺字段表格和数值矛盾表格不生成行情卡。
4. Win 原生 UI 显示可访问的 K 线图；单根 K 线仍提供开高低收说明。
5. 富内容合同、前端类型/构建/lint、Rust 测试及真实游客 Windows 验收通过。

## 非目标

- 不用单日 OHLC 推算历史价格或技术指标。
- 不保证官网未公开的数据可在本地复现。
