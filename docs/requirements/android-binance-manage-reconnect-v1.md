# 币安管理页过期恢复

用户真实反馈无法查看网格。ADB确认管理页显示连接已结束，策略和读取禁用；源码确认
恢复按钮只调用可能已经为空的旧WebView，没有续建本机Host会话，因此可能无效。

1. 原生恢复与固定MCP reload共用一条重连路径：先取消旧准备、清除确认，再调用既有
   Host.begin恢复同一主账户；仅成功后重新接线并挂载新网页。已经存在的网页才主动刷新，
   新创建的网页沿Host的首导航加载一次。失败不得回报reload_started。
2. 提交中拒绝重连。保留未核对操作、账号/文档/策略核验、互斥槽、15分钟授权与本地记录。
   不自动勾选、准备、重放或提交交易，不改变网站登录资料。
3. 恢复入口放在账号状态下方；账号未确认时先明确重连，选择网格后再显示管理操作。
   统一管理页背景、文字、输入与按钮的对比度；不替代量化APK的卡片列表。
4. 回归覆盖恢复失败、过期无网页、新网页只加载一次、已有网页刷新、提交中拒绝。
   正式APK构建、安装与真实只读重连另行记录，不把模拟传输当作真实交易验收。
