# APK 统一媒体卡片交付记录

更新：2026-09-30。需求与边界见 [打开方式合同](android-media-card-opening.md)。

## 已实现

- 视频号、抖音、小红书、B站复用卡片尺寸、标题、封面/作者区域；后三者保留固定双入口。视频号按最新要求只显示微信入口，忽略旧站内偏好，失败不自动进入二维码引导页。
- App/站内入口点击即保存平台偏好并打开，卡片按偏好路由；默认标记、未安装/禁用、恢复安装、返回撤销及账号隔离均有处理。
- 复用微信新鲜 handoff；其他平台采用精确包的 HTTPS ACTION_VIEW，抖音桌面链接转换为已观察到的分享页路由。短链解析有超时、跳数和同平台边界。
- 保留长按、多选、复制、转发、阅读浮窗及画中画；临时回退不篡改默认值，网页自动拉起 App 被阻止。
- 其他平台从 Activity（包括包装上下文）启动时不再强制 NEW_TASK；非 Activity 上下文仍带系统必需标志。微信已有任务策略不变。不清理外部 App 的任务，也不后台抢前台。
