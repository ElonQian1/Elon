- 生产聊天页的真实输入框可以生成测试样本，原生编辑器可以打开并编辑副本；不是测试 UI 或官网兜底页。

- 外部脚本仅修改带固定测试标记且摘要匹配的本机副本，不触发官网保存。临时测试工具自动移除，测试会话与导出文件保留，不删除账号数据。
