# Sui 离线预检任务与短时租约 V1 验收

## 当前状态

`implementation_partially_verified`

Node SDK、CLI 和单任务工作器已经完成离线契约验证；测试只连接本机假服务，不使用生产凭据，不连接 Sui 网络。服务端 V159 专项迁移、真实 Axum 机器接口、并发租约和 PC 页面仍未运行。

## 已形成代码

- V159 显式任务队列、状态、适配器绑定、租约和报告引用。
- 项目编辑者从当前可导出投影包入队和取消待处理/阻断任务。
- 机器按适配器网络与投影类型权限领取任务。
- 60 至 900 秒租约、1 小时硬截止、续租、释放和过期回收。
- 领取前只读重建交接包，摘要漂移或不可导出时阻断任务。
- 完成报告与任务状态的单事务写入和幂等重放边界。
- PC 标准包、纠正包入队入口，以及任务列表、租约摘要和取消入口。
- SDK 任务客户端和 CLI `claim/renew/release/complete` 命令；凭据只从环境变量读取，领取不会自动完成任务。
- 可中止的单任务工作器，支持到期前续租、稳定完成幂等键、有限完成重试和异常释放。

## 已验证

- SDK 全量 `npm test` 通过 19 项测试，其中 12 项覆盖 Sui 离线预检。
- CLI 已实际执行文件复核、报告、领取、续租、释放和完成；HTTP 仅指向测试进程内的本机假服务。
- 适配器 Token 和一次性租约 Token 只从环境变量读取，命令行凭据参数在发起请求前被拒绝。
- 客户端会拒绝摘要篡改、链上提交标记、空领取夹带任务、跨任务续租响应、跨项目报告和完成报告绑定冲突。
- 工作器已验证到期前续租、同一幂等键完成重试、续租停止竞态、显式异常释放和进程中止释放。

## 服务端统一回归仍须验证

- V159 从空库和 V158 升级时的外键、唯一索引和状态约束。
- 重复入队、并发领取、租约竞争、到期回收、硬截止和凭据轮换。
- 跨项目、超出网络或包类型权限、错误租约令牌和已停用适配器。
- 交接摘要漂移、争议阻断、不可导出投影及 blocked 后重新入队。
- 完成与报告插入的事务原子性、完全相同重放和冲突重放。
- 任务生命周期前后投影状态、网络提交次数和真实资金均不变化。
- Rust、TypeScript、迁移、HTTP 权限、PC 交互和可访问性。
