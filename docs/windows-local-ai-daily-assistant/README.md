# Windows 本地 AI 工作日报助手 MVP

最后更新：2026-07-09

## 一句话定位

这是一个参考“小黑日报助手”方向的新独立 MVP 项目：在 Windows 本机自动记录工作轨迹，用 AI 生成时间线和 Markdown 日报。

## 项目目标

先做一个个人可用的本地工具，不先做团队管理、不做云端同步、不接入一龙现有 APK/服务器发布链路。

MVP 需要验证四件事：

1. Windows 本机能稳定采集定时截图和前台应用信息。
2. AI 能把截图和窗口标题理解成可信的工作事项。
3. 用户能看到一天的工作时间线，并手动修正明显错误。
4. 用户能导出一份可直接提交或二次编辑的 Markdown 日报。
