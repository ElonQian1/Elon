# 开放商业 HTTPS 出站公网地址固定 V1 验收

## 当前状态

`implementation_uncompiled`

本批次只形成代码、执行 Rust 格式整理及仓库源码和文档门禁，尚未编译、解析真实 DNS、建立 TLS 连接或执行 Webhook 投递。

## 已形成代码

- 共享模块解析全部地址，并拒绝任一私网或特殊用途结果。
- 客户端禁用环境代理和重定向，把请求固定到本次已检查的公网地址。
- App 域名 challenge、Webhook challenge 和每笔真实 Webhook 投递共用相同边界。
- 实际 Webhook 投递每次重新解析；不安全目标记为稳定错误并停用订阅。

## 统一回归必须验证

- IPv4、IPv6、IPv4-mapped IPv6、混合公网/私网、多公网地址和空解析结果。
- 回环、RFC1918、链路本地、共享地址、文档网段、基准测试、组播、保留、ULA、6to4 和 NAT64 边界。
- DNS 检查与连接地址确实一致，TLS SNI 和证书主机校验仍使用原始域名。
- 禁用代理、禁用重定向、连接超时和总请求超时。
- Webhook challenge、实际投递、重试、死信和自动停用状态。
- 域名验证白名单与 Webhook 白名单继续独立生效。

## 仍未完成

- 多公网地址故障切换和经过限制的重试策略。
- DNSSEC、DoH、解析结果缓存、网络级 egress 防火墙和独立出站代理。
- 本批次全部编译、DNS、TLS、网络与并发验证。
