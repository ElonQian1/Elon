# 产品范围约束

最后更新：2026-07-09

## MVP 只做什么

MVP 只做个人本地工作日报助手：

- Windows 桌面端。
- 用户手动开启记录。
- 定时采集当前工作状态。
- AI 分析成时间线。
- 用户可编辑时间线。
- 生成 Markdown 日报。
- 用户可删除本地数据。

## MVP 不做什么

- 不做团队后台。
- 不做老板看板。
- 不做绩效统计。
- 不做云同步。
- 不做自动发日报。
- 不做移动端。
- 不做 macOS。
- 不做浏览器插件。

## 后续可以做但必须重新评估

- 周报/月报。
- 飞书/企业微信导出。
- 本地模型分析。
- 多设备同步。
- 企业模板。
- 安装器签名和自动更新。

## 产品话术边界

可以说：

- 本地存储。
- 用户可暂停。
- 用户可删除。
- 可选 AI 分析。
- 用于个人工作总结。

不能说：

- 绝对安全。
- 绝对不上传。
- 完全不会泄露隐私。
- 自动脱敏 100% 准确。
- 可以监督员工。
