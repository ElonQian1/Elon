# Sui 离线预检适配器身份与报告 V1 验收

## 当前状态

`implementation_partially_verified`

Node 离线交接复核、报告客户端和 CLI 已通过契约测试及本机假服务运行；尚未执行服务端 V158 专项迁移、真实 Axum 机器接口、PC 页面或任何 Sui 网络连接。

## 已形成代码

- V158 项目级预检适配器档案和追加式报告表。
- 明文只显示一次、只保存 SHA-256、可轮换、可停用和限时有效的机器凭据。
- 目标网络与标准/纠正投影类型的最小权限限制。
- 默认关闭的机器报告入口和项目成员只读报告列表。
- 服务端只读重建交接包并比对 `handoff_digest` 后接受 `passed/rejected`。
- 同一适配器与幂等键的不可覆盖报告语义。
- PC 档案创建、轮换、停用、一次性令牌展示和历史报告查看。
- 连接器 SDK 的确定性交接摘要复核、严格离线约束检查和 HTTPS 报告客户端。
- 默认只本地检查、显式 `--report` 才上报且只从环境变量读取凭据的命令行入口。

## 已验证

- SDK 会拒绝摘要篡改、额外字段、非 `not_submitted` 状态和任何非离线约束。
- 报告响应必须与已复核交接包、请求结果和幂等键逐项绑定；跨项目或跨投影响应失败关闭。
- CLI 已实际执行离线复核与显式报告，凭据只从环境变量读取，命令行凭据参数会被拒绝。
- 测试 HTTP 只连接进程内本机假服务，未使用生产凭据、钱包、RPC 或 Sui 网络。

## 服务端统一回归仍须验证

- V158 在全新数据库和从 V157 升级时的表、约束、索引与外键。
- 创建、轮换、停用、到期、错误令牌、旧令牌和跨项目访问。
- 网络与投影类型权限，标准包和纠正包摘要一致及摘要漂移拒绝。
- 运行开关默认关闭、显式开启和进程环境变化行为。
- 完全相同幂等重放、冲突重放和并发提交只有一份报告。
- 报告前后投影完整性、验证时间、争议状态、提交状态和次数均不变化。
- PC 表单空选择、期限边界、一次性令牌复制、忙碌状态和错误提示。
- Rust、TypeScript、生产构建、HTTP 权限和页面交互。
