# AI Task Template

把任务交给 AI 时，建议按这个格式描述。

```md
## 任务目标

请修改：

## 约束

- 不要修改无关文件。
- 不要覆盖未提交改动。
- 新增逻辑放到职责明确的小模块。
- 修改后运行验证命令。

## 必读文件

1. `AGENTS.md`
2. `.github/copilot-instructions.md`
3. `AI_PROJECT.md`
4. `AI_INDEX.md`

## 希望 AI 先输出

1. 相关文件列表。
2. 每个文件为什么相关。
3. 修改计划。
4. 预计验证命令。

## 最终回复

- 修改了什么。
- 为什么这么改。
- 运行了哪些验证。
- 是否还有风险或后续工作。
```
