# 钱包授权过期恢复交付

## 问题与行为

主 APK 1.1.1725 与量化 0.7.68 / 85 真机复现：用户点击钱包同意后仍停留授权页，状态为“授权未完成，请重新识别账户后再试。”，按钮继续可点。钱包 MCP 显示身份确认失效、没有在途请求，未取得钱包数据。根因为五分钟账户确认过期后，旧 Activity 没有到期提示和重新识别接续。

`BinanceWalletConsentGate` 只记录当前前台人工点击。过期点击立即显示进度，复用现有身份接口；31秒内确认仍是已显示的同一主用户、币安账户摘要与类型时才完成这次同意。换号、错误、超时、后台或失焦取消意图，不能由之后的回调自动授权。授权写入前再次校验调用者、焦点和账户。

`BinanceWalletState.identityRemainingMs()` 与新鲜度使用同一时钟和期限；Activity 只设置一次本地到期回调，不增加定时网络轮询。保留独立钱包用途、原签名调用者、nonce、FLAG_SECURE、遮挡触摸保护、结果协议和登录资料。

## 验证范围

自动测试覆盖单次人工意图、无点击不授权、过期同账户恢复、重复点击、主用户/币安账户/类型变化、清空身份、超时精确边界、时钟倒退、迟到响应、生命周期取消和显式重试。钱包状态测试补充期限与新鲜度一致性；同时运行原钱包、宿主授权与状态回归。

钱包与宿主定向测试38项通过：授权意图11项、钱包状态11项、宿主状态15项、宿主授权1项，零失败。首次编译发现Activity属性引用歧义，已修复后重新通过；源码与文档规模门禁通过。正式发布和真机安装结果随后分别记录。待新版主 APK 安装后进行当前账户授权与钱包读取；钱包余额口径、撤销/换号、空网格、像素和真实交易均不因离线测试通过自动验收。量化自身 0.7.68 四区与1网格读取已有独立证据，钱包本次仍未读取成功。
