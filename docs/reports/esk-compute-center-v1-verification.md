# ESK 与算力账户中心验证记录

本报告证明账户中心首期的实现与离线验证，不代表完整 ESK 支付闭环或真实用户验收完成。用户已确定平台未来主要使用 ESK 扣费，人民币和 USDT 作为参考金额；首期采用用户付款后管理员核验并入账，服务价格和正式切换时间仍待确定。

## 当前实现

正式 ESK 总登记、卖回占用与剩余登记来自同一只读事务；最近 20 笔审核登记与原完整流水入口保留。AI 用量区分平台、本人账号、共享账号、自带 Key 和客户端参考上报。账单及预占保留真实 CNY 币种、价格版本和计量引用，没有把历史人民币消费换写成 ESK 消费。

PC 安全页为 `/pc/esk-compute`，使用主账号认证、本次会话仅存内存；原工作台和移动网页提供独立安全窗口入口。Android 个人中心提供原生入口，读取专用 HTTPS 资产服务。账户切换、后台、到期与取消会清除旧数据。

参考报价读取 `ESK_COMPUTE_REFERENCE_QUOTE_JSON`，未设置时读取 `billing_config` 的 `esk_compute_reference_quote`。字段见 `ReferenceQuote`，汇率为六位微单位整数字符串，包含报价 ID、来源、观测与有效截止时间；有效期上限五分钟。最终 USDT、CNY 金额分别一次舍入，过期或无效报价不提供估值。没有接入自动行情采集，也没有配置生产报价。

## 已执行验证

- 正式 ESK 独立 harness：167 项通过，覆盖现有登记、占用、回执等回归及本次同事务快照、账户隔离、真实币种和来源区分。
- PC 合同：17 项通过，覆盖金额精度、报价失效、溢出、余额守恒与凭据读取前安全连接检查。
- Android 专项单元测试：5 项通过，覆盖共享合同、金额、重复 JSON、溢出、不安全连接及取消前凭据保护。
- 服务端生产代码检查通过；PC 最终类型检查与生产构建通过；Android `assembleDebug` 内部构建通过。
- 移动 V2 治理自测 12 项及当前规范检查通过。该检查仅证明治理合同。
- PC 本地实际登录页已查看：输入框、禁用状态与 HTTP 安全入口提示可见。没有提交真实凭据。
- Android API 34 独立模拟器安装内部包并启动 `EskComputeActivity`，原生层级确认未登录提示、四个入口、返回与刷新按钮。未登录按钮可见高度 126 px，密度约 2.625，对应 48 dp；不是全部状态的视觉或可访问性验收。

## 尚未通过或执行

完整服务端 HTTP 测试未运行成功。首次尝试因磁盘不足中断；改用任务临时目录后，基线测试模块出现多项 E0364 私有符号重新导出错误，阻止整个服务端测试程序生成。新 HTTP 测试源码已提交，不把生产代码检查或独立 Store harness 当成完整 HTTP 测试通过。

首次发布后的线上核对发现账户 HTTPS 白名单没有组装新中心，API 返回 404。已单独注册受保护的中心路由，复用 socket peer 限流，并限制精确路径、方法和单一规范分页参数。账户 HTTPS 独立 harness 已通过，包含新增入口策略、请求凭据拒绝与 socket 身份要求测试；其他账户白名单保持原策略。主项目旧 HTTP public URL 对应的中心同源限定为已有 HTTPS 资产端点，不从请求头推导；自定义部署继续要求可信 HTTPS public URL。

真实用户登录后的余额、报价、分页及账单联调尚未执行。原生正常余额状态、字体放大、读屏和全部恢复路径尚待验收，因此没有正式发布 APK。内部 debug 安装只发生于本任务的新模拟器，没有操作真实手机。

## 后续经济路径

充值订单与收款核验、幂等入账、按模型配置 ESK 价格、ESK 原子预占/扣减/释放/退款、任务预算和正式余额各消费者的统一守恒仍需独立实现与验收。购买、ESK 服务扣费能力均保持关闭；未接入的 ESK 服务占用与消费字段返回 null。

启用自动参考行情还需要确定可信源和更新作业；展示报价不能代替实际扣费时冻结的价格快照。上线扣费之前需完成原人民币路径的受控迁移和真实用户验收。
