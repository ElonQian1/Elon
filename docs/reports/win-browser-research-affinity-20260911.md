# Win 研究请求实例归属验证

## 结果与边界

研究桥接原来按全局队列竞争，任意 Win 实例可领取不属于它的会话请求。
本批将动作绑定原生进程与当前用户派生的实例 ID，并在节点单锁内核验租约和归属。
前端拒绝不匹配动作，领取后不重发原生操作；账号变化丢弃旧用户结果。

原生身份只公布当前用户实际持有 WebView 宿主的项目及会话 ID，最多 8 项。
新开会话的成功回执立即绑定，填补下一次心跳之前的间隔。节点重启可从运行宿主恢复；
原生进程重启或换用户得到新身份，不能接管旧会话。多宿主时 MCP 明确选择，Win 页面自选当前实例。
新节点拒绝旧桥接无身份领取；须配套更新节点、桌面壳和 PC 前端。

## 验证覆盖

- 所属/非所属实例任意先后轮询、错误显式实例、无实例旧客户端、重复领取。
- 项目隔离、宿主发现不泄漏其他项目会话；账号变化期间心跳与领取不执行旧命令。
- 宿主租约过期、新进程/新用户不接管、原进程心跳恢复、节点重启重新登记。
- 登记及绑定容量、整体心跳校验失败不部分写入；回执一致重投和冲突拒绝。
- 既有站点、范围、大小、凭据边界与结果校验；路由字段在进入原生业务命令前移除。
- 原生实例在运行时克隆/前端重载间一致，两个运行时或用户之间不同。

独立工件组 `win-browser-research-affinity-v1` 保存工作流、运行日志和后续安装证据。
构建缓存 doctor 报可用空间 7.72%，dry-run 没有可清理目标；未删除任何缓存，
正式验证入口仍允许并完成上述验证。没有重启或关闭现有登录窗口。
