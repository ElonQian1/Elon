# 币安广场发布渠道

状态：实现与本地专项验证通过，发布待验收。主项目文章中心覆盖 Android、PC React 与移动 PWA。

## 产品合同

作者绑定自己的 Square OpenAPI 发帖凭证，选择文章版本，在币安版本预览后主动公开发布。群文章的阅读权限不随外部分发改变。支持长文章（标题、文字正文、可选封面）、文字动态、最多四图动态及单视频动态。标题、段落、引用会转换为可见纯文字；文章内插图不会静默消失，预览会明确列出未发送图片，必须确认转换。视频独立选择，不能与图片动态混用。

发布队列保存不可变输入、作者、凭证代次、请求键、计划时间和结果。立即/定时发送均在服务器执行，关闭客户端不影响排队。取消仅适用于未提交任务；提交阶段不能承诺取消。相同文章版本、模式与素材只保留一条发布记录；失败后的重试复用该记录。请求超时、5xx、响应不完整或进程在提交阶段中断标记结果待核实，禁止自动重发；作者在币安核实后填写帖子链接或确认未发布，后者才恢复显式重试。

绑定只证明已保存，第一次真实发帖成功才证明凭证可用。凭证使用现有服务器 AES-GCM 密钥存储能力加密，密文附带 owner/channel 身份，接口不返回明文，日志不记录外部响应正文。轮换/解绑使旧代次排队任务取消，已经提交的不受影响。全部渠道接口只组装到原生TLS监听器，HTTP入口没有这些路由；写操作同时校验真实连接信息与登录令牌，不信任请求头伪造HTTPS。

Android与本机PC工作台通过受信任HTTPS调用接口。HTTP网页只显示安全页面入口，在完整的 `https://43.139.149.158:8443/square` 页面登录、选择自己的文章、管理凭证及发布。该页面的登录令牌只保留在内存，发帖凭证保存后清空输入框，不写浏览器持久存储。证书申请、续期和热加载见[原生ACME运维说明](account-native-acme.md)。

## 实现与验证边界

复用文章媒体所有权和不可变版本，新增渠道凭证、持久任务及短期视频素材表。图片仍按文章媒体上限；视频客户端提取首帧封面，单文件最多32MiB、10分钟，服务器验证MP4/WebM签名、所有权、时长上限和存储配额；这是本产品首版边界。

测试用例覆盖跨用户拒绝、过期版本、重复请求、相同内容去重、凭证代次、撤下/取消竞争、预提交失败与提交结果不确定、重启恢复、单次claim、配额、预签名URL校验、正常返回及响应脱敏。恢复同一密钥下旧任务也受100条待发布上限限制；请求回执丢失后，即使草稿和凭证已变化，原请求键仍可查询原记录。
