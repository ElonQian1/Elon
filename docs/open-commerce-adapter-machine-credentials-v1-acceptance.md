# 开放商业接入器机器凭据 V1 验收

## 已实现

- 项目编辑者可按数据接入签发、轮换或撤销一个机器凭据，并列出不含明文 Token 的凭据元数据。
- 明文 Token 只显示一次；服务端只保存 SHA-256，PC 只保存在当前页面内存并提供一次性复制。
- 凭据固定为 `business_handoff.write`，专用 HTTP 入口从 Token 派生项目、商户和接入器后复用既有衔接校验。
- 轮换使旧 Token 立即失效，撤销凭据或停用数据接入均拒绝后续鉴权。
- 机器回执与人工回执使用不同权威标识；机器回执固化凭据 ID 和版本，不能声明人工确认。
- PC 工作台显示凭据状态、版本、末尾提示和最近使用时间，并区分“接入器鉴权”与“人工确认”。

## 验证范围

- Rust 测试覆盖一次性返回、摘要存储边界、轮换、撤销、接入停用、旧版本失败关闭、项目角色、MCP 列表和明确确认。
- PC TypeScript 构建、目标文件 ESLint 和开放商业契约测试覆盖一次性提示、固定权限、无浏览器持久化及回执来源区分。
- 迁移保留既有 `project_editor_asserted` 回执，并为机器回执增加凭据 ID 和版本约束。

## 未完成边界

- 没有美团、抖音、京东、淘宝闪购等生产适配器，也没有外部 ERP 回读或自动重试执行器。
- V1 使用受限 Bearer Token；后续已补服务端限时有效，但尚未提供自动轮换、mTLS、非对称签名、硬件密钥或跨运营方信任链。
- 接入器回执不是外部订单、库存、支付、履约或退款的独立证明，不移动真实资金。
