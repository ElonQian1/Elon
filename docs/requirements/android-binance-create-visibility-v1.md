# 币安创建与连接页面可见性

## 目标和边界

修复量化应用进入主应用后，创建表单和读取授权页面看似空白的问题。
浅色系统下，页面固定深色背景但原生控件继承浅色主题文字；必须显式设置文字、输入框、下拉项及按钮颜色。
入口必须明确区分创建表单与只读授权，页面就绪、读取失败和官网重载必须可见。
保留现有账号隔离、900 秒只读授权、撤销、数据新鲜度与用户本人确认交易合同。
持续授权和自动续期是独立功能，不在本批次通过改文案伪装实现。验收不提交真实交易。

## 验收条件

1. 从量化创建按钮进入创建 Activity，显示参数表单、连接状态、官网重载和返回；浅色、深色系统均有明确对比度。
2. 读取授权页面有独立标题、用途和时限，官网可展开；重载可以恢复已销毁连接并加载新页面，无永久无提示空白。
3. 回到量化仍能读取本人列表及详情；授权不能用于创建、修改或结束策略。真实交易验收保持单独待用户测试。

## 文件与验证计划

- 共用原生样式约 100 行；仅用于网格模块，不调整全局主题。
- 修改创建 Activity（约 220 行）、表单（约 75 行）、连接 Activity（约 160 行）；不改交易适配器。
- 核对既有创建、只读授权、管理恢复测试及正式 APK 编译和 lint。
- 真机只读验证导航、结构、输入项、读取授权和返回；未获得真实像素证据时明确延期视觉验收。
