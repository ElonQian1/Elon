# 币安独立止盈止损托管接口 V3

承接主会话服务V2与量化商业G19，产品需求及完整合同分别由量化仓库 `docs/requirements/grid-protection-v3.md`、`docs/contracts/binance-native-manage-v3.md` 维护。主项目只扩展领域、网页适配、版本化IPC和恢复日志，不新增主管理产品UI。

新增protection操作支持价格、盈亏金额、收益率及显式清除。主服务从已核验详情计算精确目标，网页重新核对基线与账号，提交前再校验；保留未改设置。收益率基数及舍入来自已取得的币安模块59977/45337/53944/56001/19696/37954源码链，不把静态证据冒充实际交易结果。

保留V2四项端点与严格响应；V3独立声明能力并返回保护详情。保护目标仅以指纹进入新版日志，兼容旧日志。V2遇到V3在途记录提示更新恢复，不自动删除或重放。账户、文档、参数与准备绑定继续有效，凭据不出主APK。

实现按领域快照、规范化、网页纯参数模块、Session/State/Command接线、固定版本协议分开；现有管理入口不堆积转换代码。预计新模块60～150行，修改入口仍低于500行。必须覆盖正常、清除、精度、漂移、账户、旧协议、重复提交、未知结果和日志恢复；源码与网页合同向量对应。

按主项目正式入口发布主APK；量化另仓发布原签名子APK。当前版本两端完成只读准备与回读验收，最终金融写入由用户本人确认。未经该步骤不得称交易闭环完成；Win/Chrome登录资料保持，不以重启或移动凭据替代接口设计。
