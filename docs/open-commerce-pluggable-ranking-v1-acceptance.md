# 开放商业消费者可替换透明排序器 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 消费者发现请求可显式选择五种内置排序策略，省略时兼容原偏好匹配策略。
- 服务端统一解析策略、选择单个商户能力并对最终结果执行确定性排序。
- 响应返回当前策略、可读解释、用户是否显式选择以及完整可用策略清单。
- 所有内置策略固定标识为非付费排序，未知策略失败关闭。
- PC 消费者沙箱提供排序选择并展示当前策略及非付费标识。

## 统一回归必须验证

- 省略、空白和显式 `transparent_preference_match.v1` 的兼容结果。
- 五种策略分别对多商户、多能力、相同主排序值和缺少偏好时的顺序。
- 未知策略键、空候选集、单候选集以及请求条数 1、50 和超过 50 的收口。
- 精确能力键、价格上限、城市、类别、标签和 App 身份过滤先于排序生效。
- 同一候选集重复请求得到稳定顺序，商户 ID 和能力键并列条件无随机漂移。
- `public`、`authorized` 和异常访问级别的优先级；更新时间与调用价的边界值。
- 响应中的策略键、名称、解释、`ranking_is_paid=false`、用户选择标识和五项描述完整一致。
- 目录最多 100 个商户候选的限制不会被文档或 UI 误表述为全网穷举。
- Rust、HTTP 序列化、TypeScript 类型、PC 选择器、窄屏布局和错误展示。
