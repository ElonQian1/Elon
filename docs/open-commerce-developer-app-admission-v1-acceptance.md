# 开放商业开发者 App 可撤销准入审查 V1 验收

## 当前状态

`implementation_compiled_local_state_and_http_subset`

Rust `elon-server` 测试目标已编译；全新 SQLite 专项测试已通过资料与域名本地前置状态完成准入提交、批准和暂停，并验证资料修订会退回既有准入、准入暂停会撤销活动生产凭据。2 项进程内 Axum 专项已验证登录、项目与 App 管理隔离、申请人确认、重复提交、平台管理员队列、批准及重复审批。尚未验证历史迁移、真正并发、真实 TCP 或 PC 交互。

## 已形成代码

- V153 新增与开发者 App 一对一的准入记录，不继续扩张 App 主表。
- 申请绑定当前资料修订、当前域名证明、主体声明和申请人明确确认。
- 平台管理员可批准、要求补充或暂停；批准固定人工风险层级。
- 资料修改会原子失效待审或已批准准入，App 停用会原子暂停准入。
- PC 开发者门户提供准入申请和状态查看，管理员工作台提供审核与暂停。
- 准入批准本身不签发生产凭据；后续独立凭据批次会读取该记录并在暂停时原子撤销。
- `server/src/open_commerce_developer_production_state_tests.rs` 已验证上述撤销联动及生产 Webhook 停用结果。
- 项目成员身份不自动获得 App 准入资料访问权；App 所有者或项目 owner 可读取和提交，普通成员、其他 App 编辑者、项目外用户及未加入项目的平台管理员统一在 HTTP 入口失败关闭。
- 平台管理员队列和审核端点独立鉴权；项目 owner 不能代替平台管理员审核，未授权响应不返回登记编号。

## 统一回归必须验证

- V152 到 V153 升级、空表、重复迁移、唯一约束和外键删除。
- App 所有者、项目 owner、普通成员、其他编辑者、非项目成员和平台管理员权限隔离已通过进程内 HTTP 专项；项目 admin 写入仍待补充验证。
- 未审核资料、旧修订、无效域名证明、停用 App 和未确认声明失败关闭。
- 主体名称、地区、登记编号、审核说明和风险层级边界。
- 重复提交和重复审批已通过进程内 HTTP 专项；真正并发提交、过期修订审批和停用暂停的原子性仍需补充，资料修改失效和准入暂停撤销凭据的本地事务已通过专项测试。
- 退回后重提、暂停后重提、重新启用不自动恢复以及审计字段。
- PC 表单初始化、状态、错误提示、管理员队列和小屏布局。
