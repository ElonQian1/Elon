# 本人币安网格设置与结束 V1

用户要求继续完善创建后的管理，并由本人执行真实交易测试。本批主 APK 继续托管登录，
量化仅增加专用管理入口和严格回执。仅本人自有资金技术测试，无代客交易或公共 live 开关。

管理页从当前已验证列表选择策略，再固定 GET 查询详情并前后核对实际 UID。只支持两项
独立操作：修改终止时市价平仓设置 cps；按当前已核验 cps 结束网格。每次均要求可见
原生摘要、用户显式选择、勾选与最终点击。修改和结束不得自动串联；AI/MCP/后台没有写入口。

采用已观察 update-grid 六字段合同，保留 sharing、两个 trailingStop 标志，只有 cps
可更改。详情缺少这些布尔字段、cos、精确策略ID或WORKING状态时不准备写入。close-grid
只发送数值 strategyId，超过JS安全整数范围时拒绝，不舍入。区间/格数/追加资金、独立
平仓、止盈止损及分享/跟踪修改不在本批，继续提供官网入口。

提交前重新读取详情并逐字段比较确认快照，最后核验身份；账号、页面、设置变化、超时
或取消使准备失效。固定路径、无凭据导出、无任意HTTP入口、无自动重试。创建/管理共享
进程锁，未核对的另一类本机操作记录阻止新写入；读取恢复不触发交易。

先写本机原子记录再发送，断网/重启按未知恢复。业务成功只表示受理；独立GET再核对
目标设置或结束状态，CANCELED/CANCELLED/CLOSE_WITH_POSITION不等于仓位为零或资金结清。
用户结束本机核对记录不会结束交易所策略。未知请求不得自动重发。

验证：合成网络与状态机覆盖错误账号/ID、字段变化、重复、超时、恢复、互斥；双APK
签名和回执；真机只读入口与恢复。实际修改、结束及挂单/仓位/资金核对保持本人验收待完成。
