# 开放商业能力与内部同步回执来源绑定 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- V164 单能力单当前绑定、修订递增及级联清理结构。
- 同项目、同商户、同接入、数据域登记和回执资格校验。
- 能力版本变化、接入停用和回执状态异常的公开失效判断。
- 项目总览中的全部绑定和稳定阻断原因。
- 公开目录中的内部回执来源元数据、SHA-256 摘要和回执时间新鲜度。
- 商户 PC 绑定、重绑、移除与失效提示。
- 消费者 PC 来源标签和“未经外部平台验证”提示。

## 已验证

- V164 在内存数据库中重复执行，表、两个显式索引和五条外键保持稳定；真实 Store 夹具完成全量迁移后，回执删除会级联清理来源绑定。
- 编辑权限、跨项目、跨商户、跨接入、未登记数据域、健康检查和失败回执均失败关闭，失败请求不新增绑定或来源审计。
- `succeeded` 与 `partial` 业务回执可绑定；重绑保留链接身份和创建时间、修订递增，并各自产生一条脱敏审计。
- 能力更新后稳定阻断码为 `capability_version_changed`，目录回退普通商户声明；显式重绑固化新版本并恢复公开。
- 接入停用后稳定阻断码为 `integration_disabled`，目录回退普通商户声明；重新启用后，版本和回执仍有效的原绑定恢复公开。
- 目录只公开内部回执 ID、厂商、接入方式、数据域、状态、完成时间和 SHA-256，新鲜度基于回执完成时间；游标摘要、授权范围和原始数据不进入公开结果。
- 数据库触发器分别阻断绑定和解绑审计时，事务会回滚来源变更，接口错误不会留下实际已生效的半完成状态。
- 既有接入/同步上下文测试和消费者发现 MCP 测试继续通过。
