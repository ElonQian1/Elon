# 币安 Android 宿主事件通信 V1

量化 APK 保持独立原生创建、管理、列表和记录 UI；主 APK 保留网页登录及固定私有业务接口。用户要求停止以固定周期查询维持连接及等待结果，改用请求完成通知。

## 通信合同

- 原 ContentProvider 的包名、签名、UID 校验继续生效。增加能力探测、订阅和注销三个固定方法；通过 Binder/Messenger 发送订阅标识、主题和递增修订号，不发送业务正文或网站凭据。
- 订阅登记先于初始状态读取。客户端合并重复通知；后台注销，Binder 死亡清理。订阅与具体 create/manage 操作标识绑定；注销后沿用有界闲置释放。
- 前台订阅替代轮询续租，但不得延长主账号本身有效期，不能消除换账号、撤销、文档代际、准备及回执校验。
- WebView 请求结束后发送受官方源和主框架约束的短通知。原生侧仅按当前文档、请求 ID 读取已完成结果，禁止周期 evaluateJavascript 检查。
- 创建、管理状态与报告完成或失败及时通知。超时及过期保留一次性截止时间；客户端收到通知再取当前固定业务快照。旧客户端可继续调用原快照方法；新客户端遇旧宿主明确提示更新。
- 通知不得重放任何写操作。私有 HTTP 完成事件不等于持续私有行情或订单推送；未验证的私有 WebSocket 不得宣称已接入。

## 验收

1. UID 归属、订阅数量、注销、进程死亡和操作租约均有边界；通知不泄露账户及认证正文。
2. 动态参考、可用资金和参数检查由完成事件推进，取消或迟到事件不会更新旧请求。
3. 列表、报告、创建和管理读取无空闲周期 IPC，不用周期读取触发网络恢复。
4. 原字段、账号隔离、最终确认及未知交易结果保护保持；双包正式构建发布，装机和接口实测独立记载。

量化消费者及公开行情推送在独立 yilong-quant 仓库交付。现有官网自身的定时请求不属于宿主新增调度，必须与本机 IPC 和公开 WebSocket 分别记录。
