# 开放商业消费者内部回执来源筛选 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 默认关闭的来源要求请求字段和稳定响应枚举。
- 能力候选层对 `integration_sync_receipt` 的精确筛选。
- 匹配原因、PC 复选框和结果条件标志。
- 请求指纹与排序凭证中的来源要求。
- 现有 Rust 直接请求夹具的默认兼容字段。

## 统一回归必须验证

- 字段省略、显式 `false` 和显式 `true` 的反序列化与旧结果兼容。
- 同一商户同时存在普通声明、有效内部回执和已失效绑定能力时的候选选择。
- 来源筛选与 `require_current_declaration` 四种组合的结果。
- 五种排序器、能力键、价格上限和候选数量边界不被改变。
- 筛选条件进入输入摘要和凭证负载，切换后摘要不同。
- PC 开关、结果标志、空结果和窄屏布局。

- 外部平台签名、官方回读证明和第三方可信来源策略。
- 按厂商、数据域、回执状态或自定义时间阈值筛选。
