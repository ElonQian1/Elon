# Win ChatGPT OHLC 富卡连续快照稳定性 V1

## 用户问题

OHLC 表格首次提取时会被标记为已归属行情富内容；后续语义快照把这个自身标记误判为嵌套富卡，
导致 K 线富卡瞬间出现后消失，最终只剩正文。

## 范围

- 已标记的 OHLC 表格自身必须在后续快照中继续幂等解析。
- 位于另一个已标记富内容根内部的表格仍须跳过，防止重复卡片。
- 共享适配器版本递增，保证已安装 Win 端重新注入修复脚本。

## 验收标准

1. 同一合法 OHLC 表连续提取两次都返回同一 finance K 线富卡。
2. 嵌套在其它富内容根中的表格不会重复生成卡片。
3. 全量游客浏览器测试、类型检查、lint、生产构建和源码门禁通过。
4. 正式安装后真实游客回答保持 `finance` 富卡，原生 UI 可访问到缓存 K 线图。

## 非目标

- 不改变 OHLC 数值规则，不推算缺失字段。
