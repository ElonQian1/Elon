一龙 PC 节点客户端

普通用户用法：

1. 解压本压缩包。
2. 双击「安装一龙PC节点.cmd」。
3. 浏览器打开 http://127.0.0.1:7799/ 后，用一龙账号登录。
4. 登录成功后，这台电脑会自动注册为 PC 节点并开始连接服务器。

安装器会做的事：

- 安装到当前 Windows 用户目录：%LOCALAPPDATA%\ElonNode
- 创建桌面快捷方式「一龙PC节点」
- 注册当前用户登录后的开机自启任务
- 启动系统托盘图标
- 后续托盘启动时自动拉取最新版客户端包，更新 agent、托盘脚本和安装/卸载入口
- 如需卸载，可运行安装目录里的「卸载一龙PC节点.cmd」

前提：

- Codex CLI / Copilot CLI / Git / Node.js 等能力建议先装好。
- 如果未装，打开本地管理页后可以查看环境检查结果，并使用「一键安装」辅助安装。

高级配置：

- 普通用户不用编辑配置文件。
- 如需自定义服务器、端口或 TTS Worker，可复制 node-agent.env.example 为 node-agent.env 后修改。
