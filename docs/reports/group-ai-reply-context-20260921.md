# 群 AI 回答来源与私人续聊

## 已实现

- APK、Windows：ChatGPT 精选分析回答气泡末尾有“使用 ChatGPT 继续讨论”，下方有带姓名、摘要、数量的来源记录卡片。
- 阅读页复用现有 Markdown、代码、表格、图片和附件组件；显示发送者与时间。关闭阅读页保留群聊位置；私人续聊有返回原群入口。
- 分析前可以勾选允许群成员继续讨论，分析后只有发起人能开启或关闭。服务端每次检查成员资格、回答状态、授权和设置版本，不依赖前端按钮隐藏作为权限控制。
- 快照与选区请求原子写入。后续编辑不会改变历史依据，来源撤回隐藏正文与附件，回答撤回拒绝打开。旧版本无快照的回答保持本人导出，不扩展为可授权他人续聊。
- 续聊使用查看者自己的 ChatGPT，新会话就绪后只准备草稿，由用户发送。原有草稿不覆盖、未确认的新会话不填入、私人回复不自动回群。
- 移动 PWA 同步来源卡片、阅读和分享设置；PWA 继续讨论提示使用 APK/Windows，不创建公开链接、不借用分享者账号。

- Windows：17 项纯逻辑/执行状态测试通过，TypeScript 检查通过。
- Playwright 使用实际 React 组件与隔离假传输，在 1280 和 390 宽度验证来源阅读、Markdown 表格/代码、分享开关、私人草稿准备、已有草稿保护与原群返回；页面无水平溢出、无 JavaScript 异常。
- 完整群聊 React 页面回归通过：单条/多选、原群投递、切群后状态保持、好友不显示群 AI 操作；新增纯链接回答的续聊按钮可见性检查，以及分享设置网络失败后重试仍回到设置而非误进续聊。
- Android Release Kotlin 编译通过；10 项定向测试 XML 确认零失败、零错误、零跳过，覆盖气泡内续聊/气泡外来源卡片、重复绑定、撤回清理、分享草稿兼容、私人草稿策略与阅读布局。

## 范围

- 本批不改变官网私有发送协议或 WebRTC，不建立每群 ChatGPT Project，不复制 Cookie，不实现官方公开链接分叉。
- 来源阅读保留附件，但分析和私人续聊仍不自动上传附件原文件；界面明确提示此边界。
- 新来源卡片仅覆盖有明确 selected 来源的回答，不虚构旧版或近期窗口回答的完整上下文。
- 关闭授权会阻止新的续聊上下文获取，不撤销已经送达用户设备或由其保存的资料。
