## 已形成代码

- 生产运行绑定在登记和调用阶段均要求精确白名单内的标准 443 HTTPS。
- 健康验证和每笔业务调用都会重新校验地址与当前白名单。
- 商户运行时复用 V2 全部地址检查、混合答案整体拒绝、禁代理、禁重定向和本次
  已验证地址集合固定。
- 不安全目标作为基础设施失败进入既有运行绑定降级流程。
- 测试编译仍保留本机回环 HTTP 入口，不扩大生产权限。

## 统一回归必须验证

- 已保存绑定在白名单移除后立即失败关闭并降级。
- HTTP、非 443、账号信息、查询参数、片段和非白名单地址。
- IPv4、IPv6、混合公网/私网、DNS 变化和空解析结果。
- DNS 检查与连接地址一致，TLS SNI 和证书主机校验仍使用原始域名。
- 禁用代理、禁用重定向、500 至 15000 毫秒超时边界及 512 KiB 响应限制。
- 单元测试与临时商户服务的回环通道只在测试编译生效。
- 健康验证、真实调用、失败审计、运行绑定降级和重新验证恢复。
