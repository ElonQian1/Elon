# 微信记录群 AI 分析

## 根因与实现

已通过当前 Windows 登录态的 MCP 找到指定测试群 09:55 发布的“微信聊天记录”。原有卡片支持阅读，但 PC 特殊消息过滤和 Android 项目卡片绑定屏蔽了 AI/多选入口；选区后端也只接收外层卡片而非完整记录。

- 新增 PC 直接按钮、右键 AI 分析和多选；Android 复用消息长按及多选链路，特殊记录不显示纯文字转发。
- 从服务器保存的群消息绑定展开记录，不接受客户端任意记录 ID；正文、嵌套关系、发言者和时间进入提示词。
- 复用原上传和群回复状态机；记录媒体经平台授权下载后走 ChatGPT 私有上传。旧客户端不能静默丢弃附件。
- 来源预览可重新打开原记录；继续讨论草稿包含完整文本，明确不自动再次上传原附件。
- 权限、撤回、超限显式阻止发送；重复完成不会产生第二条群回复。

## 已验证

- 后端全量 Store 测试中的 5 个定向用例通过：完整嵌套记录和受保护媒体、撤回、退群/旧客户端、伪造卡片、超限不截断；续聊草稿完整文本断言也已通过。
- PC 上传、控制和任务状态机测试通过；TypeScript/Vite 构建通过。
- `scripts/test-chat-record-ai-ui.cjs` 在 1280 和 390 宽度使用真实 React 组件验证直接按钮、右键、多选和预览；截图位于本机 `.ai-tmp/record-ai-ui`，无私人内容。
