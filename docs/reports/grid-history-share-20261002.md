# 历史网格分享与中文代币检查

范围见 [当前需求](../requirements/binance-grid-history-share.md)。本记录区分代码与真实账户结果，不作为新的产品规则。

## 已实现

- Win/APK 的分享与本人 ChatGPT 附带入口复用历史报告，支持最近 7/30/90 天和明确分页；读取由点击触发。
- 历史卡与详情展示起止时间、采集时间、公开金额、网格利润，以及未知的结算/仓位状态；历史引用保留原消息版本与收益口径。
- 历史记录不读取当前持仓补值，也不套用运行快照五分钟期限。来源变化、聊天变化、取消、重复记录和错误响应仍拒绝。
- 新快照默认公开金额。旧隐藏分享保持原公开边界；服务端成员权限、撤回、幂等和不可变更新机制沿用。
- APK 代币缩写原先仅允许 ASCII，中文会显示问号。现复用已有中英文合约规则，中文名称与本地文字图标均保留。

## 构建环境处置

Rust 容量门禁最初拒绝启动。通过项目缓存工具预览并回收退役 `legacy-universal-target` 31.05 GiB；遇到其他 Cargo 活跃时工具拒绝清理，待其退出后执行。另按当前无锁的托管 GC 计划回收约 21.84 GiB；未删除任何项目源码或未知目录。C 盘仍不能承载默认 Rust 最终产物安全余量，因此使用工具计算的工作区哈希，将最终产物与 TEMP 显式放到现有 D 盘缓存根；不降低容量门槛、不创建共享任务分区。

## 数据边界

历史接口当前提供的 `profit` 是 gridProfit。它不证明最终总盈亏、最终平仓、费用是否已计入或收益率分母。缺少追加撤出、完整成交、调整与收益曲线时，AI 上下文明确禁止推算最终净收益或最大回撤。网格利润为正时仍可能总亏损；三端分别显示这些指标，未知不作零。
