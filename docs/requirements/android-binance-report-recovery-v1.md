# 币安记录读取兼容与诊断 V1

量化 APK 真机成交记录已读出，但当前委托和策略持仓失败。主 APK 应在现有本人同源只读接口内报告有界的失败阶段、HTTP 状态和业务代码，让维护者能定位网络、接口及字段层。记录、账户标识、凭据和服务端原始错误消息不得进入诊断。

可选展示字段不兼容时显示未知，不能丢弃身份和范围已经验证的整页记录；策略 ID、币种、买卖方向、账户和总数仍严格验证。无策略 ID 的普通委托不属于当前网格，不得混入结果。

修改仅限记录适配器、诊断投影和对应测试。复用主 APK 会话、授权、撤销、过期、分页及量化原生 UI，不改变交易写入。验证包括可选字段漂移、严格范围拒绝、业务失败不伪装空列表、有界诊断及原签名 APK 真机回读。未解决的外部错误保留明确失败证据。
