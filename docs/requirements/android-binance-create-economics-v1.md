# 创建网格经济参数只读参考

承接量化移动创建页需求：用户填写区间、网格数量、保证金和杠杆时，动态查看数量范围、最低投入、每格手续费后利润及每笔数量，避免复制截图固定值或用保证金除格数估算。

## 实现合同

- 量化拥有表单；主 APK 通过固定 `create_reference_*_v2` 提供参考，V1 输入和输出严格保持兼容。V2 增加可空保证金输入，新增利润百分比、每笔数量及计量单位。
- 复用现有动态配置、当前账号 maker 手续费及合约行情。无配置或费率不得猜默认值；普通网格数量以基础币计，追踪数量以 USDT 报价金额计。杠杆后名义投入不等于实际持仓或收益。
- 计算行为以已取得且校验哈希的币安前端计算模块及调用点为依据，提交独立实现和合成向量，不提交整站代码、私有会话和真实余额。
- 未填/无效格数仍可读数量范围；未填保证金仍可读最低投入及利润。数量仅在保证金和对应规则可用时返回。失败、换号、换文档、草稿变化、过期及迟到结果不能显示为当前参考。
- 读取不能改变准备状态、提交订单、修改仓位或结束策略。保留现有操作、文档、账号、请求隔离及本人最终确认。

## 验收

1. 官方计算器差分涵盖等差/等比、方向、追踪、触发、窗口边界、小价格与不同手续费。
2. V1/V2 严格契约和生产客户端白名单测试；动态范围/最低投入旧测试保持。
3. 原签名发布、安装、真实只读参数变化和原生视觉证据分别记录。缺失证据不记通过。
