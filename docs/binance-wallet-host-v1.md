# 本人币安钱包概览宿主

量化商业网格工具需要经授权读取本人账户资产。主 APK 保管官网会话和固定业务接口，量化拥有资产 UI；本模块实现钱包概览生产端，不扩展旧创建页面，不依赖 Win 在线。

量化仓库 `docs/binance-wallet-read-contract-v1.md` 定义双端合同；其 `docs/delivery/grid-wallet-response-audit-20260914.md` 记录20份已核验历史响应及USDT/BTC查询参数。历史响应不是当前账号数据，不进入生产缓存或测试金额夹具。

## 接入范围

- 固定同源 GET `/bapi/asset/v2/private/asset-service/wallet/balance?needBalanceDetail=true&quoteAsset=USDT`；读取前后核对真实账户。原始凭据只留页面，投影不含资产明细和原始账号。
- 使用独立 `wallet_summary_read` 用途、精确调用者和原签名校验。网格 grant 不升级为钱包 grant；持续授权可恢复，也可单独撤销，换号需重新同意。
- 新版本化钱包概览投影保留钱包类型、启用状态、可空十进制估值、当前来源和时间；错误、未知和零余额不同。合约/策略钱包不直接相加，不宣称可提现或完整权益。
- 复用现有事件、生命周期和WebView；钱包不以存在网格为条件，后台不定时查询。主应用只在登录和授权需要用户时显示。

## 实现范围与验收

新增钱包JavaScript适配器、状态/授权、运行时与固定IPC、用途授权Activity及测试。现有宿主、同源脚本清单、调用者与Manifest仅接线；不改交易方法。

先补构造数据测试，再实现和发布。验证HTTP/业务错误、空/未启用/缺字段/未知类型、精度、响应大小、重复类型、错误调用者、旧grant、换号、撤销、迟到回调、期限与进程恢复。当前真实会话只读结果须与官网核对；正式原签名主APK及对应量化版本装机、资金口径与像素分别留证据。

本模块不授权下单、仓位修改、结束策略、划转或提现；不接收用户资金、不跨账户合计。尚未完成的生产端、消费端、设备和视觉验证分别保留未完成状态。
