# 本人 U 本位网格完整使用流程 V2

用户要求补齐量化 APK 管理本人合约网格的核心能力。主 APK 托管官方登录及适配，量化 APK 使用原生统一界面；Win MCP 负责来源研究。推荐、排行榜、跟单和团队募资不在本功能范围。

## 已接受的合同变化

- 用户首次明确同意持续只读连接后，主应用仅保存绑定一龙用户、币安精确账户、正式量化签名消费者和只读用途的同意记录。短期访问票据仍为十五分钟，可在同意有效且当前身份重新确认时续发；退出量化界面不撤销同意。撤销、换账号、退出主账号立即隔离旧数据。进程恢复必须重新证明账户，不能拿持久化的旧投影冒充实时资产。
- V1 调用者继续使用原来的短期授权；V2 使用独立恢复/读取方法及严格版本数据。网站凭据不跨 APK。
- 主动刷新仅允许已经观察并验证过的只读请求；未知请求体不猜测。覆盖范围、更新时间、失败和未知字段必须明确。
- 原生详情按真实字段显示投入、收益与风险；金额用十进制字符串，不能将名义价值冒充保证金、将网格收益冒充总收益。
- 创建和管理的真实提交保留在用户可见确认流程，必须有账号、参数复核、单次提交、未知结果查询和不可自动重试语义。研究、MCP、自动验收不执行交易。
