# 开放商业调用凭据来源与环境隔离 V1 验收

## 当前状态

`implementation_uncompiled`

本批仅形成代码、Rust 格式整理及仓库静态门禁，尚未编译、执行数据库迁移、运行接口、连接商户运行时或发送 Webhook。

## 已形成代码

- V155 为调用账本增加凭据环境、凭据 ID 和 App 环境时间索引，旧记录保守标记为 `legacy`。
- 平台、沙箱与生产入口写入不同来源证据；生产调用必须绑定具体生产凭据。
- 幂等重放校验凭据来源，生产凭据不能跨环境、跨轮换凭据或继承旧记录重放。
- 沙箱凭据在查询能力信息后、创建调用前拒绝真实商户运行时；动作准备、动作确认和最终执行均有相同限制。
- 商户运行时信封附带凭据环境和非秘密凭据 ID。
- 开发者事件页、详情和游标按凭据环境隔离；V1 沙箱游标仍可兼容读取旧版游标。
- 现有 Webhook 的自动入队、历史补发、死信重试和工作器结果读取均不会交付生产调用事件。

## 统一回归必须验证

- V154 到 V155 升级、空库、历史库、重复迁移、列约束、索引和 Webhook 触发器替换。
- 平台、沙箱、生产和旧记录的写入与读取组合，以及非法环境和生产缺少凭据 ID 的失败关闭。
- 相同幂等键在同一生产凭据、轮换后凭据、沙箱、平台和旧记录之间的全部重放组合。
- 沙箱对静态查询、静态动作和 `merchant_runtime` 查询/动作的准备、确认、执行边界。
- 生产凭据范围、到期、撤销、App 停用、域名重验、准入暂停后的调用与事件读取。
- 沙箱/生产游标互换、旧 V1 游标兼容、跨 App 游标、详情越权和轮换后的生产事件连续性。
- 自动 Webhook、历史补发、死信重试和工作器面对生产调用时均失败关闭，且沙箱通知不回归。
- 运行时签名信封包含正确环境与凭据 ID，且不包含明文 Token、摘要或其他密钥材料。
