# 开放商业消费者可携带偏好字段级采用 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 请求显式携带所选低敏偏好字段。
- 服务端去重并限制五个允许字段，拒绝空选择、未知字段和未变化字段。
- 按当前档案与导入档案合并所选值，未选值保持不变。
- 沿用修订号并发检查、完整前后快照、审计和安全回滚。
- 采用记录从快照派生 `selected_fields`，无需 V160 或平行状态表。
- PC 逐字段复选、中文标签、选择数量确认和历史采用字段展示。

## 统一回归必须验证

- 五种字段分别采用、组合采用、全选和空选。
- 未变化字段、未知字段、重复字段和预演后并发修改。
- 无当前档案与已有档案的合并结果及规范化边界。
- 旧整包采用记录的读取、列表与回滚兼容。
- 采用后修改档案时拒绝回滚，未修改时恢复完整前快照。
- Rust、TypeScript、HTTP 权限、PC 交互和审计内容。

## 未完成

- 本批所有编译、接口、旧数据、行为和 UI 验证。
- 带共同祖先的三方历史合并、跨设备审批、关系恢复和业务数据迁移；多来源静态偏好合并由独立 V1 承接。
