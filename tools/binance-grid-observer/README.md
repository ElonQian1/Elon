# 币安网格观察工具

这个 Chrome 扩展把你在币安网页上实际触发的部分请求整理成脱敏结构摘要，方便研究网格接口。它不会自动查询、创建、修改或结束交易，也不会替你登录。

当前是研究工具。真实 Chrome 加载、币安列表采集和导出仍需现场验收；完成工具不代表量化项目已经接通币安。

## 第一次安装

1. 保留现在已经登录的币安标签页，不需要刷新或退出账号。
2. 如果收到的是压缩包，先解压。在 Chrome 新标签页的地址栏输入 `chrome://extensions`。
3. 打开右上角的“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择本工具文件夹：打开它应能直接看到 `manifest.json`，不要选压缩包或仓库最外层。
5. 在 Chrome 右上角的扩展菜单中找到本工具，可点击图钉固定到工具栏。

这是 Chrome 的[本地扩展加载流程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。**不需要按 F12，也不需要粘贴控制台代码。** 需要 Chrome 106 或更新版本。

## 第一次采集

1. 回到现有 `https://www.binance.com` 合约或合约网格标签页。
2. 点击工具栏中的本工具，在弹窗内点击“启用观察”。每次启用会清除上一轮摘要，需要保留旧摘要时先导出。
3. 由你自己点击币安的“运行中”或“历史”网格列表；第一次只查看这两类列表。
4. 再打开扩展弹窗，点击“更新状态”查看状态和摘要数量。结束后点击“停止观察”，再点击“导出摘要”，保存生成的 JSON 文件。

第一次研究不用创建、修改或结束任何机器人，也不用调整保证金。扩展不会要求你提供密码、验证码、Cookie 或 API 密钥。它不会刷新或关闭币安页。

## 暂停、清除和卸载

- **停止观察**：停止接收本次采集的新摘要，已收集摘要保留，便于导出。
- **清除摘要**：删除扩展内已保存的摘要；自行保存的导出文件需要你另行删除。
- **卸载**：先停止观察，再到 `chrome://extensions` 找到本工具并点击“移除”。不需要退出币安账号。

摘要只暂存在 Chrome 会话存储中，不自动上传。浏览器重启后不要依赖旧摘要仍在；需要保留时请先手动导出。观察在 15 分钟后自动停止；网页导航后也需要重新启用。

## 导出内容和覆盖限制

导出仅包含地址模板、方法、状态、字段类型和计数等研究摘要。查询参数、字段的实际值、账号与订单标识、持仓金额和请求头不会进入摘要。只分享本工具的摘要，不要附带浏览器个人资料目录或其他抓包文件。

摘要来自不可信的页面观察，不能证明账户归属、交易成功或可执行交易；页面也可能伪造观察消息。重复结构会合并；过大的内容可能被丢弃或标记截断，未知字段会归并。摘要是有上限的结构样本，不能当作完整接口定义。

没有摘要时，先确认已启用，再手动切换一次只读列表。**零摘要不代表没有网格。** 本工具不能补捕启用前的请求；页面缓存、预先保存的网络函数、开启前已准备好的 XMLHttpRequest、Worker、WebSocket、非 JSON 内容和其他传输方式都可能不被观察。XHR 只分析文本响应；数组只抽取前几个元素的结构。它不会为了补齐数据而自动请求接口。

开发者设计与验收范围位于项目的 `docs/binance-grid-observer-v1.md`。权限仅为临时当前页访问、脚本注入和会话存储，没有 debugger、Cookie 或长期全站访问权限。
