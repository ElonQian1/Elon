# 开放商业商户可携带身份 V1 验收

## 当前实现

- 项目编辑者可为本项目商户提交 RSA 公钥和私钥持有证明。
- 服务端校验公钥规格、SPKI SHA-256 指纹、签名和项目/商户绑定。
- 有效指纹随商户开放目录详情发布，撤销后不再公开。
- PC 端可在本地生成密钥、先下载私钥、再发布公钥指纹，并可显式撤销。
- Node 连接器 SDK 提供指纹、签名消息、持有证明生成与本地验证函数。

## 验证状态

根据当前快速开发策略，本批次未运行 Rust 编译、PC 构建、TypeScript 检查、数据库迁移检查、SDK 测试、密码学往返验证或完整回归。当前状态为 `implementation_uncompiled`，不能声称可运行或已通过安全验收。

## 后续统一验证

- WebCrypto 与 Rust/Node 对相同消息的 RSA-SHA256 互操作。
- 非 RSA、弱密钥、篡改签名、错误项目/商户绑定和超长输入的失败关闭。
- 项目权限、商户归属、3 枚有效密钥上限、幂等重放和撤销不可恢复。
- 公开目录未发布/撤回时的指纹可见性。
- PC 私钥下载、页面刷新丢弃和服务端请求不含私钥。
