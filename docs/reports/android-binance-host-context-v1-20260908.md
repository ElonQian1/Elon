# 手机币安网格：同页请求上下文与分层诊断

依据[正式需求](../requirements/android-binance-host-read-v1.md)。本批仍为主 APK 托管本人币安会话、量化 APK 经限时授权读取；Win/Chrome 未重启，未执行交易。

## 根因证据和修复

正式主 APK 1.1.1564 装机后，手机诊断为页面完成、桥接已绑定、列表请求/响应各 1 次；随后适配器主动发出的基础账号 GET 返回 HTTP 401，分类为 `identity_response_failed`。因此 `list_verified=false/row_count=0` 表示列表未通过身份验证，不表示账号没有网格。较晚的官网身份请求返回 200，不能覆盖此前 401 的失败结论。

本批修复三个相互独立的问题：

- 文档绑定前，同一账号的身份事件不能覆盖已验证且待发送的列表；账号变化仍丢弃旧列表。回归测试已复现旧实现失败。
- 身份 GET 与已知详情 GET 使用官网实际列表请求的同页上下文，覆盖 fetch/Request 和 XHR；请求上下文仅保留在页面闭包内，拒绝跨 origin 和方法覆盖，不进入桥接、MCP、APK 间接口或日志。
- 带账号选择查询参数的身份 URL 不作为当前登录账号的证明。该边界有离线测试；不据此猜测手机曾出现子账户分类的具体原因。

固定诊断只返回请求/响应次数、有限错误枚举、页面阶段及布尔值。它不输出网页正文、请求头、账号标识或资产值；首次 MCP 请求异步更新页面事实，以 `diagnostics_observed_at_ms` 判定新旧。
