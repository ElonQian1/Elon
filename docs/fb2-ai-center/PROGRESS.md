## 风险

- 现在“代码/契约/脚本”明显领先于最终证据，不能把脚本可运行等同于用户端真实完成。
- 真实群聊 smoke 有副作用，会产生可见消息；必须保持显式授权开关。
- fb2 live 数据和权限边界是最终产品的核心，不能用示例 JSON 或无 token smoke 替代。
- 后端运行代码没有在本轮修改；如果后续改 server 代码，必须 commit + push 后按发布脚本部署并 live 验证。
