# 币安网格管理页只读调试与空列表

用户要求AI自行检查账号、列表与详情，不因无策略要求用户测试不存在的策略。复用
[管理V1](android-binance-grid-manage-v1.md)；真实提交仍由用户在原生页面完成。

1. 区分账号/列表尚未核验、已核验空列表和存在策略。空列表明确提示，禁用需要策略的
   读取和准备按钮；上次未核对操作仍可在原账号查询，不能被空列表阻断。
2. 固定MCP工具只允许状态、按当前列表索引选择、详情读取和官网列表刷新；无任意脚本、
   URL、策略ID或交易参数输入，不能准备、确认、提交、清除核对记录或改变交易设置。
3. MCP给出有界布尔/计数/阶段回执，能看到人工与工具触发的读取序号、结果及原因，
   不包含账号ID、策略ID、金额、凭据和网页正文。失去前台或存在准备/提交流程时拒绝
   干扰表单；未知结果只查询，不重发。
4. 单元验证空列表、未选策略、账户/页面变化、待核对恢复及写动作拒绝。真机验证已登录
   子账户的新策略只读详情，记录失败与范围限制；不以网络替身冒充真实结果。

主APK承担全部实现，量化入口与交易写合同保持兼容。无需安装临时检查组件、重启Win或
Chrome；不清除登录资料，不创建或结束交易所策略。
