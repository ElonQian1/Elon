# Win 完整视口后台官方 AI WebView 输入命中隔离 V3

## 用户问题

V1 完全隐藏 WebView 会暂停官网会话恢复；V2 将控制器缩为 1×1 后虽然原生输入可用，
但 Google 页面进入极窄响应式布局，真实发送误入设置弹窗并被安全回滚。

## 目标

- 后台保留同一个 WebView2 Profile、页面、脚本、会话与完整官网视口尺寸。
- 官方 WebView 不覆盖主窗口任何可见交互区域。
- 原生输入框、“新对话”和其他一龙 UI 可正常点击、输入和发送。
- 用户主动显示官网时恢复原有嵌入区域、尺寸、可见性和焦点。

## 实现约束

- 停放坐标取主窗口当前物理宽高，使控制器左上角位于父窗口右下可见边界之外。
- 不缩小后台控制器，避免 Google / ChatGPT 响应式布局和 DOM 语义发生变化。
- 后台保持 `show`，维持官网脚本、会话恢复和发送能力。
- 前台 `present` 继续重设正常位置与尺寸。
- 不修改 PWA、Android、聊天布局或官方页面 DOM 适配器。

## 验收标准

1. 静态合同证明后台停放使用父窗口物理边界，且不修改官网视口尺寸。
2. Win 用户浏览器合同、Rust 定向测试和 PC 生产构建通过。
3. 发布后原生输入框可正常输入，后台官网仍保持完整桌面 DOM。
4. 真实发送后停留在原生聊天 UI，消息不被恢复或错误控件点击回滚。
5. Google 官方回复可继续同步回原生聊天 UI。
