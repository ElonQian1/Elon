# 跨端群成员与管理

范围：用户已授权完善 APK、移动 PWA、宽屏 PWA 和 Win 群成员模块。沿用已有自动入群、聊天和 AI 能力，不将全站用户目录作为群成员名单。

## 用户能力

- APK 群信息用有限的自适应头像网格，完整成员进入全屏纵向名单；PWA 窄屏保持同样层级。
- Win 和宽屏 PWA 在聊天右侧显示可收起的当前群成员栏，窄窗口仍有可发现的成员入口。
- 全群搜索、分页、群主/管理员标识、最近加入排序、本人和离线成员可见；AI 目标不计入真人名单。
- 成员资料提供 @ 和添加好友并私聊；原有好友邀请能力保留。
- 群主可设置邀请规则（所有成员、管理员、邀请需审核）、任免管理员、转让群主、解散群聊。
- 管理员可审核邀请和移除普通成员；群主可移除管理员；禁止移除自己或群主。支持最多 100 人的明确批量选择。
- 普通成员可退出；非空群的群主先转让。退出或被移除后普通登录不会重新入群。
- 入群、移除、退出、角色变化以事务记录通知；写请求可安全重试。三端刷新以服务端成员关系为准。

## 验收

1. 172 人、1000 人名单无预览截断；跨页搜索正确，总人数不等于当前页人数。
2. 分页游标绑定群、查询、筛选和名单版本；名单改变后拒绝旧游标，客户端可恢复。
3. 非成员不可查，普通成员不可提权；批量操作失败不部分生效，重试不重复通知。
4. 三端邀请、审核、角色、转让、退出、解散具备加载、失败、重试和明确结果。
5. 账号/群切换不混用旧名单；自动入群和多人协作后的名单能刷新；保留搜索和合理的阅读位置。
6. PC/PWA 浏览器运行、APK 构建与原生运行分别取证；生产发布与装机身份独立回读。

不包含本次范围之外的聊天搜索、公告编辑、群二维码和项目空间成员体系重构。
