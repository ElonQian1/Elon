# 主项目正式 ESK 平台登记个人入口 V1

## 范围与单一真源

属于 [首批用户路线图](esk-first-user-delivery-roadmap-v1.md)。个人中心新增“正式 ESK 平台登记”
独立入口，打开非导出原生只读页面；不改变原有 Paper 卡、兑换、卖回、双 APK 17 字段协议。
唯一读取来源为已配置主服务 `GET /api/me/assets/esk/platform`，合同见
[平台账本](esk-platform-recorded-assets-v1.md) 和 [接入边界](../esk-platform-recorded-assets.md)。

本切片不建立新的发行账本，不入账，不交易，不迁移，不返回量化 Activity result。
正式数量、模拟余额和未来链上余额不能相加。ESK 经济含义不变，QSHARE 独立。

## 用户体验

- 个人中心入口在原资产组内稳定出现，旧卡刷新或重新挂载后不丢失，也不重复添加。
- 正式页面显示 ESK 名称、精确六位数量、平台登记 / 尚未上链标识、最近审核入账流水。
- 有更多历史时明确“最近记录”，总量来自完整账本，不能把当前页求和当总量。
- 已审核登记不代表程序自动验证付款、不表示 USDT 价值、固定收益、公司法股权或即时兑付。
- 空账本显示“暂无正式登记”；加载、未登录、会话变化、网络失败、格式错误不能冒充零余额。
- 不提供正式卖回成交或提现按钮；原 Paper 卖回继续只属于模拟来源。
- 网页个人中心同步正式来源说明和主 APK 下载入口。本切片正式私有页面限定原生读取，
  网页不模拟原生授权、不新增本人正式余额请求；Web 完整私有界面另行登记和验收。

## 私有读取与生命周期

- 仅接受构建配置里的 HTTPS origin，使用默认系统证书验证；不从 Intent 或用户输入读取地址。
- HTTP 必须在读 AuthManager/session/token 或创建网络请求之前拒绝；不自动安装证书、换地址或降级。
- 独立无缓存、无 cookie、无重定向、无重试客户端；不复用带拦截器的共享网络客户端。
- 只读当前已登录用户，绑定 token、用户 ID、会话到期和请求代次；无身份查询参数。
- 退出、换号、auth 字段变动、退后台、保存状态和销毁时取消请求并清空展示。
  A→B→A 不能复活 A 的旧回调。重新进入重新读取；不持久化余额、token 或快照。
- 私有页禁止系统截图/最近任务快照，不在日志、错误、Intent、WebView 或剪贴板输出敏感数据。
- 严格校验 JSON 键、重复键、UTF-8、类型、字节/深度/条数上限和版本；整数不得使用浮点。
  校验金额与最小单位一致、正数分录、防重复、历史计数与总量关系、来源与能力标识。

## 验收及交接

1. 正确的空/单条/多条/截断历史、六位小数和 i64 极限通过；错误版本、金额、类型和来源拒绝。
2. HTTP 零 token 读取/零网络；401、重定向、超大响应、错误媒体类型、取消及重复请求拒绝。
3. 会话失效、请求乱序、后台取消及 A→B→A 在纯逻辑测试验证；原 Paper/IPC 测试继续通过。
4. 新模块按职责拆分，Preview-first Views、现有颜色和 48dp 触控规范；APK 编译并正式发布。
5. 记录 UI 工作台与构建、推送、发布、用户验收状态，不能用静态测试冒充手机实测。
6. 当前没有批准安全传输配置和真实付款入账，实际本人数量联调保持待验收；不伪造余额截图。
