# 创建准备强制动态规则检查

承接原生会话托管与[只读参考需求](android-binance-create-reference-v1.md)，完成量化商业目标G11/G12的规则检查缺口。参考显示与正式准备必须复用同一服务，不能只在界面提示后继续生成不符合规则的确认。

检查流程：解析草稿与合约规则 → 同账号/文档/请求动态参考 → 精确格数及最低保证金检查 → 原有身份/配置准备 → 原有用户最终确认。动态参考不发送交易、不自动勾选或确认，不改变提交/查询/未知结果语义。

必须覆盖缺失、过期、超时、区间过窄、格数越界、保证金不足、相等边界、文档/账号更换、取消及迟到回执。失败不能进入可提交状态，原因用中文返回量化的现有message。动态规则计算、缓存和来源沿用参考V1；不得复制公式或使用固定金额/数量替代。

文件计划：新增纯调度/校验`BinanceCreateRuleCheck.kt`约160行、回归测试约180行；会话接线约30行，命令服务共享一个参考实例约1行。主APK与量化状态提示补丁分别发布，正常产品UI仍归量化。保持创建V2和参考V1合同，不增加任意网络/脚本方法，不迁移凭据或账户数据。

完成证据：离线正常/失败/取消/迟到检查、既有回归、正式构建发布、同账号同参数官网对照与双包只读准备。手机缺席只允许记录离线和发布状态，不能宣称实际账户已验证。
