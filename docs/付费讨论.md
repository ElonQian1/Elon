截至 **2026-06-01**，结论大概是：

**Copilot 超出额度后，已经越来越接近“API key 按 token 付费”的模式，但不是直接用你的 OpenAI/Claude API key 计费。** GitHub 现在用 **GitHub AI Credits** 计量：模型输入 token、缓存 token、输出 token 都会按模型价格折算成 credits，**1 AI Credit = $0.01**；额度用完后，要设置额外预算才会继续扣费，不是无条件自动乱扣。Copilot Pro / Pro+ / Max 每月分别包含 1,500 / 7,000 / 20,000 AI Credits；代码补全和 Next Edit suggestions 对付费用户仍不扣 AI Credits。([GitHub Docs][1])

旧的“premium requests”规则只主要影响还在旧年度套餐上的用户：例如 legacy Copilot Pro 是 300 requests/月，Pro+ 是 1500 requests/月，额外 premium request 曾是 **$0.04/request**；用完后可用 included models 或设置预算买更多。([GitHub Docs][2]) 但从 GitHub 官方公告看，**2026-06-01 起主线已经切到 usage-based billing**，也就是按 token 消耗算 credits。([The GitHub Blog][3])

**Codex 也类似，但分两种。**
用 ChatGPT 里的 Codex：Free / Go / Plus / Pro / Business 等套餐里包含一定 Codex 用量，Plus 是 $20/月，Pro 从 $100/月起；达到限制后，Plus / Pro 用户可以购买额外 credits 继续用。用 OpenAI API key 跑 Codex CLI / SDK / IDE extension，则是直接按 OpenAI API token 价格收费，而且没有一些云端功能，比如 GitHub code review、Slack 等。([OpenAI开发者][4])

### 和自己直接用 OpenAI / Claude API key 比，谁便宜？

| 场景                          | 通常更便宜                                                            |
| --------------------------- | ---------------------------------------------------------------- |
| 只是偶尔问代码、用量很少                | **直接 API key**，因为没有月费，只按 token 花钱                                |
| 每天在 IDE 里写代码，需要补全、聊天、解释代码   | **Copilot Pro / Pro+** 往往更划算，因为月费里包含 credits，而且代码补全不扣 AI Credits |
| 重度 agent 编程，频繁让 AI 改仓库、跑长任务 | **Codex Pro / Claude Max / Copilot Max** 这类订阅可能更划算，但要看是否经常撞限     |
| CI、批处理、自动化脚本、自己精细控制上下文      | **API key** 更可控，尤其可用 Batch/Flex 之类更低价模式                          |
| 超出套餐额度后的继续使用                | **基本接近 API 价格**，不是订阅内“无限便宜”了                                     |

看具体模型价格，Copilot 里的很多模型价格和 API 价格非常接近，甚至就是按对应模型 token rate 来折算。比如 GitHub Copilot 里 GPT-5.3-Codex 是 **$1.75 / 1M input tokens、$0.175 / 1M cached input、$14 / 1M output**；OpenAI API 的 gpt-5.3-codex 也是这个价格。([GitHub Docs][5]) Claude 也是类似：Copilot 表里 Claude Sonnet 4.6 是 **$3 input、$0.30 cached input、$3.75 cache write、$15 output / 1M tokens**；Anthropic 官方 Claude API 价格也列出 Sonnet 4.6 为 $3 input、$15 output，并有对应缓存价格。([GitHub Docs][5])

所以最关键的一句话是：

**在套餐额度内，Copilot / Codex / Claude Code 订阅通常比自己 API key 便宜；一旦超出额度并开始买额外 credits，大多数情况下就接近标准 API 价格了。**

有两个例外值得注意。第一，Copilot 付费用户使用 auto model selection 时，GitHub 说模型成本有 **10% 折扣**，所以某些交互可能比直接 API 略便宜。([GitHub Docs][1]) 第二，直接 API 如果你能用非实时的 Batch/Flex/缓存，就可能反过来比 Copilot/Codex 便宜；例如 Anthropic 标明 Batch 可省 50%，OpenAI API 也有不同服务层价格。([Claude][6])

### 我的建议

你如果主要写 Rust、在 VS Code / JetBrains 里边写边问，**先用 Copilot Pro 或 Pro+ 更省心**；它的补全价值很高，而且不用你自己管理上下文、token、IDE 插件和 billing。

你如果经常让 AI 自动改整个仓库、跑长任务、生成 PR，**Codex / Claude Code 的高阶订阅更像“买打包算力”**，在额度内可能比 API 划算很多；但撞限之后追加 credits 就要当成 API 价格来看。

你如果只是偶尔用，或者你愿意自己做工具链、严格控制上下文长度，**OpenAI / Anthropic API key 最便宜、最透明**。特别是长仓库任务，不要把整个 repo 都塞进去；直接 API 可以自己控制只传相关文件，这一点很省钱。

## 先把底线说清楚：不要共享账号密码

OpenAI 明确说账号是给创建者本人用的，别人需要使用应该注册自己的账号；共享登录凭证会带来安全和误用风险。([OpenAI Help Center][2]) OpenAI 的使用条款也写明不能共享账号凭证或把账号给别人用，你要对账号下发生的活动负责。([OpenAI][3]) GitHub 也很直接：一个 login 只能一个人用，不能多人共享。([GitHub Docs][4])

所以我的建议是：

**Codex / OpenAI API 可以给他“独立项目 + 独立 key”，但不要给你的主 key。Copilot CLI 不要共享你的 GitHub 登录；要么他用自己的 GitHub 账号，要么你用组织 seat 正规分配给他。**

OpenAI API 平台支持项目成员生成只限于某个项目和资源范围的个人 API key，这很适合给他单独算账。([OpenAI Help Center][5]) GitHub Copilot 在组织/企业方案里，Copilot seat 是分配给唯一 GitHub 用户账号的 license，组织 owner 可以给具体用户授权，授权后开始计费。([GitHub Docs][6])

OpenAI 官方说 API 可以设置月度预算，但限制执行可能有延迟，超出的部分仍由你负责。([OpenAI][7]) OpenAI 项目预算也更像软性支出门槛和提醒，超过后请求仍可能继续处理，不是绝对硬停。([OpenAI Help Center][5]) 所以**不要后付**，一定要预付。

## Codex / OpenAI API 怎么算账

如果他用的是 OpenAI API key 跑 Codex CLI，就按项目 usage 算最清楚。OpenAI API 的 gpt-5.3-codex 标准价是 **$1.75 / 1M input tokens、$0.175 / 1M cached input tokens、$14 / 1M output tokens**；Priority 模式是 **$3.50 / $0.35 / $28**。([OpenAI开发者][8])

你可以这样解释给他：

```text
一次仓库任务费用 =
输入 token 百万数 × 输入单价
+ 缓存输入 token 百万数 × 缓存单价
+ 输出 token 百万数 × 输出单价
+ 工具/容器费用
```

举例，假设他一次任务扫了 **500k input tokens**，输出 **50k tokens**，用 gpt-5.3-codex 标准模式：

```text
0.5 × $1.75 + 0.05 × $14
= $0.875 + $0.70
= $1.575

你收他：
$1.575 × 1.2 = $1.89
```

如果一次任务是 **2M input tokens + 200k output tokens**：

```text
2 × $1.75 + 0.2 × $14
= $3.50 + $2.80
= $6.30

你收他：
$6.30 × 1.2 = $7.56
```

这还没算工具调用、容器、web search 等附加费用；OpenAI 文档里工具和容器也是单独计费的，例如 web search、containers、file search 等都有自己的计费项。([OpenAI开发者][8])

所以他如果一天跑 10 次大任务，一个月真的可能是 **$100～$300+**，不是夸张。

## Copilot CLI 怎么收费

Copilot 现在是按 **GitHub AI Credits** 算，**1 AI Credit = $0.01**；Copilot Pro / Pro+ / Max 每月分别包含 **1,500 / 7,000 / 20,000 AI Credits**。([GitHub Docs][9]) Copilot CLI、Copilot Chat、cloud agent、Spaces、Spark、第三方 coding agents 都会消耗 AI Credits；但付费计划里的代码补全和 Next Edit suggestions 不扣 AI Credits。([GitHub Docs][9])

如果你能合法地给他一个独立 Copilot seat，那么收费公式可以是：

```text
Copilot 费用 =
seat 月费
+ 他额外消耗的 AI Credits × $0.01
+ 15%～20% 风险/管理费
```

如果你只是把自己的 GitHub Copilot 登录给他用，那我建议**不要这么做**。因为 GitHub 明确不允许多人共享同一个 login。([GitHub Docs][4])

如果你想比较正规，可以考虑 GitHub organization / Copilot Business seat。GitHub 公告说 Copilot Business 是 **$19/user/month**，并包含对应的月度 AI Credits；Copilot 的用量会按 token，包括输入、输出、缓存 token，按模型价格折算。([The GitHub Blog][10]) 但这条路要看你当前账号是否能开通/购买，因为 GitHub 文档也显示 2026 年 4 月起部分新自助注册临时暂停。([GitHub Docs][11])

## 具体操作建议

你现在应该做这几件事：

1. **立刻停用他正在用的主 API key**，重新生成你的个人 key。OpenAI 服务协议明确限制共享登录凭证，且禁止买卖、转让 API keys。([OpenAI][12])

2. 在 OpenAI dashboard 建一个项目，名字比如：

```text
roommate-codex
```

3. 只给这个项目开他需要的模型，比如先只开：

```text
gpt-5.3-codex
gpt-5.4-mini
```

不要一上来给 GPT-5.5、Priority、图像、web search、containers 全部开放。OpenAI 项目可以管理 Model Usage 和 rate limits。([OpenAI Help Center][5])

4. 让他先预存，比如：

```text
首次充值：$100
余额低于：$20 停用
单日建议上限：$10～$20
每月硬性人情上限：$150，超过必须先补钱
```

5. 每月底把 OpenAI 项目 usage 截图发他，按：

```text
实际成本 × 1.2
```

扣余额。

6. Copilot CLI 不要用你的个人 GitHub 登录给他跑。要么他自己搞 GitHub Student / Free / 自己的 Copilot，要么你用组织 seat 给他独立授权。GitHub 学生计划是给 verified students 免费使用 Copilot 功能的，但当前文档显示新注册曾临时暂停，所以他能不能马上开通要以 GitHub 页面为准。([GitHub Docs][13])
