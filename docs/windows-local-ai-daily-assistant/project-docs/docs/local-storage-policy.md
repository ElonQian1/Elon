# 本地存储约束

最后更新：2026-07-09

## 一句话结论

SQLite 是本地事实来源，但截图原图默认不是事实来源。

## 数据库原则

- 使用 SQLite。
- 数据库只存本机。
- 不默认云同步。
- 所有表必须支持按日期清理。
- 数据迁移必须可回滚或可重试。

## 建议表

- `settings`
- `capture_events`
- `analysis_records`
- `timeline_segments`
- `reports`

## 原图策略

默认：

- 临时图片用于 AI 分析。
- 分析完成后删除。
- 分析失败后也删除。
- 数据库只存 hash、状态、错误摘要，不存原图。

如果未来要保存缩略图，必须由项目负责人明确批准。

## 备份和导出

MVP 只支持：

- 导出 Markdown 日报。
- 删除本地数据。

不支持：

- 数据库云备份。
- 自动上传历史记录。
- 后台同步。
