# 正式 ESK 卖回申请与占用 V1

## 目标与授权边界

落实 [首批用户路线图](esk-first-user-delivery-roadmap-v1.md) 的正式申请、占用和进度，
不是成交、兑付或保证收益。只读取经审核正式平台账本；Paper、QSHARE、准备中入账、
迁移或未验证链证据都不进入本切片的额度。ESK 总量仍表示持有量，不冒充公司股权。

本版实现一种待生产确认的候选机制：提交即占用、本人可取消尚未成交的申请，
不自动到期、不审核成交。该候选不是从 Paper 自动继承的已批准商业政策。
代码、合成测试、默认关闭部署可以推进；不得创建生产测试申请或改动真实资产。

没有经批准的独立政策与明确开启配置时，新申请不可用。不得提供可直接开启的
生产示例额度、真实用户名单、收益率、价格、支付网络、收款地址或手续费默认值。
暂停新增、政策缺失或更换，不妨碍真实本人查询和取消已存在的有效申请。

## 账本不变量

- `T` 为本人全部完整验证的正式入账量，`H` 为全部未取消正式申请量，`A=T-H`。
  `A` 仅称“可申请量”，不是承诺可卖价格、可支取现金或即时兑付金额。
- 六位 ESK 精度，以规范十进制整数文本传输 base units，内部检查型 i64 运算；
  负数、零申请、溢出或 `H>T` 失败关闭，不截断、饱和或改用浮点。
- 请求和取消分别追加，不更新或删除历史。取消只降低占用，不新增正式分录、
  不恢复发行额度、不伪造返币；取消两次最多释放一次。
- 所有本人读写在同一 SQLite 快照／Immediate 事务中验证真实会话、正式政策和
  全部本人分录及申请；写入前后复核会话，变更失败完整回滚。
- 共用接受当前连接和会话的完整正式扫描器，不在事务内重新调用 Store 开新连接，
  不用只读 SUM 代替逐笔审核来源验证。页面外损坏不能隐身。
- 独立额度摘要同时绑定正式账本摘要、本人全部请求／取消事件与请求政策身份。
  仅入账 history 摘要不能作为额度修订号；分页锚点变化须重新读取。
- 本人幂等键与规范请求内容绑定；同键同内容返回原记录，内容变化报冲突。
  原申请已取消时重放不能重新占用。并发提交、取消、入账必须串行一致且不超占。

## 独立政策

新政策与已固定的付款入账政策分离，不改变原政策摘要或历史销售比例。
生产开启前至少批准：适用本人／正式来源、单笔上下限、每人未取消笔数及占用上限、
全平台占用上限、提交占用模式、取消范围、无自动到期机制、停用账户恢复渠道，
以及占用期治理／未来利润资格。此切片不实现或更改治理与利润权重。

政策必须具有版本、审批引用摘要、条款正文及 SHA-256，并与当前正式来源身份绑定；
请求须携带所见政策摘要和显式同意的条款摘要，服务器复核一致并保存不可变快照。
本版只接受明确的 `on_submit` 和 `owner_cancel_until_settlement` 候选模式，
但本版没有任何 settlement 路径；未实现的政策模式失败关闭。
技术输入长度／分页限制不等于商业限额，商业值不得静默补默认值。
独立配置 `ESK_PLATFORM_SELLBACK_MODE` 缺省或 `disabled` 时关闭，
仅 `approved_requests` 读取 `ESK_PLATFORM_SELLBACK_POLICY`；其他值无效。
配置名称不授予生产启用权；条款／额度／名单仍须单独批准。

## 接口和兼容

独立正式路径 `/api/me/assets/esk/platform/sellback-requests`：

- GET：本人额度快照及有界分页申请，返回正式总量、占用、可申请量、额度摘要、
  新申请可用性／当前公开条款、页范围和游标。不得接受 client user ID。
- POST：规范金额、本人幂等键、所见额度摘要、政策摘要、同意条款摘要；
  仅 `submitted`，没有价格、成交、付款或收款地址字段。
- GET `/:request_id`：本人单条查回及同快照额度，供网络结果未知后恢复。
- POST `/lookup`：只读、严格 schema 与本人幂等键的精确查回，不在 URL 携带键；
  只返回本人原记录及同快照额度，不创建申请或产生写权限。
  未查到仅表示查询时未见记录，不证明之前的请求未执行或不会稍后执行。
- POST `/:request_id/cancel`：本人明确取消，幂等追加取消回执；
  按请求身份取消，不因其他申请改变额度摘要而困住合法释放。

所有接口先鉴权再处理请求错误；拒绝未知字段、重复参数、非法数量、超限请求体。
成功、空、错误均有 `no-store/no-cache/no-referrer`，错误不泄露其他用户或内部异常。
新增独立卖回错误码，不挪用 `ESK_PLATFORM_PAYMENT_CONFLICT` 的付款语义。
JSON 固定标注正式平台记录、未上链、非模拟、无资金移动、无结算能力。

旧账户 18 字段、完整入账 history、正式原生 21 字符串合同和 Paper 17 字段合同不变。
`sellback_settlement` 继续 false；不因申请可用而改成 true，不将可申请量塞回旧 total。
本版先供主 APK 使用；量化端的独立占用协议作为后续版本，不原地扩宽旧 IPC。

## 主 APK 与网页边界

从现有正式资产页打开独立、非导出的“卖回申请与占用”页面，不携带账号／token extras。
复用现有正式来源会话快照、HTTPS-before-token、禁止重定向、请求门禁和安全窗口；
不放宽用户当前 HTTP 连接保护，不复用旧 Paper 卖回弹窗或认证路径。
页面清楚区分总量、占用、可申请量、条款及状态；开关关闭时明确不可新建。
每次提交或取消均明确确认；同意绑定本人会话修订和精确请求内容。

超时、断线、请求取消或退到后台不代表服务器未执行，必须呈现“结果未知”，
查回本人记录或以原幂等键和同一内容重试，不能自动换键创建第二笔申请。
成功后采用服务端同快照返回值，不在客户端自行加减；换号、退出、后台和错误
清理私有展示及旧操作权。恢复不得跨用户或从旧只读 IPC 获得写权限。
不在磁盘、日志、剪贴板、保存实例状态或 Intent 中保存私有金额、条款同意或 token。
同一进程可保留仅含不透明幂等键及账号／会话修订绑定的只读恢复提示；
后台清除写入 payload 和同意，重新验证同一会话后才可查回，换号／退出清除提示。
进程终止不持久化提示；新建前必须读取本人记录并明确确认这是新的独立申请，
不是重试未确认的提交。已知结果未知时另行锁住新建，直至用户核对确认。
查回未找到不能自动解锁、新建或重发；前台重试只能使用原键及不可变原内容。

页面复用主项目颜色、字号、48dp 触控和安全区，不引入新主题。
网页沿既有正式来源说明同步入口名称、可用状态和 APK 操作路径；继续不读取
正式私有余额／不模拟原生写入授权。不得把仅说明页宣称为网页申请功能。

## 验收与上线条件

1. 使用生产 Store、全新及升级 SQLite 验证追加约束、迁移幂等与故障回滚；
   独立连接并发证明总占用不超过正式量，取消不改变入账 history 摘要。
2. 覆盖同键重放／冲突／取消后重放、不同用户、撤销／到期／换绑会话、
   页外分录／申请／取消损坏、整数边界、政策更换／关闭、新申请额度限制。
3. 实际生产 Router 验证所有路由、鉴权先行、未知字段／参数、隐私头与脱敏错误；
   未配置的新申请拒绝，已有合法请求仍可本人查询和取消。
4. Android 严格解析与网络／状态机测试覆盖本人绑定、结果未知、同键重试、
   生命周期与旧回调、取消恢复、精确金额、HTTP 阻断和旧合同回归。
5. 按项目规则提交推送、发布后端和主 APK；核对实际源码／版本／包身份。
   无真实账户、受保护连接和政策批准时，只验收公开只读入口与合成用户环境。
6. 真实用户看到本人占用、提交／取消并查回，是独立上线验收；默认关闭的
   源码、构建和公开 smoke 不能替代该验收，更不能标记真实提现已实现。

上线报价、手续费、结算资产、资金来源与执行权限属于后续成交切片，须另行批准。
