# 币安创建与授权页面显示修复

## 取证与修复范围

修复前手机安装量化 0.5.1 (6)、主应用 1.1.1582 (1582)。
用户反馈页实际为 `BinanceHostConnectActivity`：原生读取授权按钮存在，下方 WebView 没有可访问子节点。
只读 MCP 已确认本人子账户、1 条网格和有效列表响应；这不证明官网区域正常渲染。
实际从量化 `hosted-grid-create` 进入后，创建页有合约、方向、保证金、杠杆、上下限等原生表单节点；未复现创建按钮误跳读取授权页。

设备 `mNightMode=1 (no)`、`mCurUiMode=0x11`。主应用窗口固定深色，创建与连接页却继承 DayNight 默认原生控件颜色，存在浅色系统下黑底黑字的明确兼容缺陷。

- 新增共用原生网格样式，显式设置文字、提示、按钮、输入框、下拉项和勾选框颜色。
- 创建页顶部提供官网重载、登录与官网展开入口；原生表单和返回有稳定语义标识。
- 读取授权页明确用途、15 分钟期限、与创建入口的区别；读取就绪后官网可折叠，未就绪时保留官方登录页面。
- 只读重载先恢复 Host，再按旧页面身份判断是否加载，避免已销毁页面上的空操作。
- 移除页面时只移除仍归本页面所有的 WebView，避免清理另一页面已接管的父容器。
