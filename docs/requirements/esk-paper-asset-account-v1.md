# ESK Paper 资产账户与卖回申请 V1

## 用户结果

登录用户在一龙主项目中看到名称为“一龙 ESK”、符号为 `ESK` 的独立资产账户，能够清楚区分总余额、卖回申请占用额和当前可用额，并能提交或取消本人卖回申请。相同账户事实随后通过版本化契约投影到“一龙量化交易”子项目，不让子项目维护第二份余额真源。

本 V1 解决“用户看不到自己被登记了多少 ESK、也没有可追踪卖回申请”的问题。它不把数据库数字伪装成已经部署的链上 Coin。

## 命名决定

- 用户当前指定主项目代币名称为 `ESK`，新资产能力统一使用大写展示符号 `ESK` 和小写稳定资产 ID `esk`。
- 历史文档中的 `NET` 是尚未发行的候选名称。ESK 取代后续用户产品中的 NET 命名，但旧 NET Paper 合同在单独迁移完成前保持原样，不能被当作 ESK 余额或真实发行证明。
- AI Token 用量、人民币计费余额、节点积分、量化内部份额和 ESK 是不同账本，不互相冒充。

## 权威边界

主项目服务端是 ESK 平台登记余额和卖回申请的唯一真源。PC、Android 和量化子项目只读取版本化视图；任何客户端数字、聊天付款截图、量化仓位或链上投影都不能反向修改主账本。

所有金额采用固定六位小数的十进制字符串和整数 base units。API 不用 JavaScript 浮点数传递资产金额。

## V1 状态与运行模式

`ESK_ASSET_MODE` 只能是：

- `disabled`：默认值；只返回资产目录与不可用原因，拒绝登记和卖回写入。
- `paper`：允许管理员登记模拟 ESK，允许用户演练卖回申请和取消；所有响应固定 `simulated=true`、`funds_moved=false`、`chain_status=not_deployed`。

未知模式必须失败关闭。V1 不提供 `live`、`mainnet` 或真实结算开关。

## 余额账本

- 余额只从追加式 `esk_asset_ledger_entries` 聚合，历史记录禁止更新和删除。
- 管理员 Paper 登记必须使用服务端管理员令牌、存在的用户 ID、正数精确金额、外部对账引用、幂等键和固定确认文本。
- 相同幂等键只允许精确重放；用户、金额或引用不同必须冲突失败。
- 用户不能给自己增加 ESK，也不能提交负数、指数格式、超六位小数或超出整数边界的金额。
- 页面必须展示余额修订号和最近同步时间，不能把未加载、错误和零余额混为一谈。

## 卖回申请

- 用户只能以本人可用余额提交正数申请；同一幂等键只允许精确重放。
- `submitted` 申请立即占用可用余额，防止并发重复申请超过余额。
- V1 用户只能把本人 `submitted` 申请取消为 `canceled`；状态变化采用追加式事件，不覆盖历史。
- `application_only=true`、`settlement_enabled=false` 必须进入 API 和 UI。提交成功只表示官方收到申请，不表示价格确定、申请批准、法币已支付或链上资产已销毁。
- V1 不实现 `approved`、`paid`、`settled`，也不接受收款账户、银行卡、钱包私钥或 KYC 文件。

## 用户界面

PC 账号页和 Android 个人页使用同一服务端视图，至少显示：

- ESK 名称、符号和精确余额；
- “Paper 测试登记 / 尚未上链”状态；
- 可用额与申请占用额；
- 卖回申请入口、申请列表、取消动作；
- “申请不等于成交或付款”的短说明。

不得显示价格、法币估值、固定回购价、固定收益率、主网合约地址或“已链上发行”等未经证实内容。

## 生产门禁

真实发行、真实购买和真实卖回属于后续独立阶段。进入前至少需要确定发行法律实体、服务法域与排除地区、资产分类、KYC/AML 与制裁流程、托管与密钥、多签和恢复、供应量与精度、价格和费用、储备与流动性、结算时限、争议与审计，并完成合约和生产系统安全验收。

把发行和官方赎回组合在一起，可能在不同法域触发虚拟资产管理、兑换或赎回义务；相关判断必须由目标法域的专业顾问确认，不能由本功能开关替代。

## 验收标准

1. 未登录请求被拒绝，用户只能读取和操作自己的 ESK 账户。
2. `disabled` 默认拒绝全部写入；`paper` 响应始终明确模拟、未上链且未移动资金。
3. 管理员登记、余额聚合、并发占用、幂等重放和冲突均有服务端测试。
4. 卖回申请不能超过可用余额；取消后占用额恢复，历史事件保留。
5. PC 与 Android 使用精确字符串显示余额、错误、空状态和申请状态。
6. 量化子项目接入另立版本化投影功能；完成前不得复制余额或把历史 NET 仓位改称真实 ESK。
