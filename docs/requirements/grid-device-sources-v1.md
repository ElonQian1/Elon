# 本人币安网格多设备来源 V1

## 用户目标与范围

主项目 Android、Win，以及量化 APK 均可独立勾选 Android 和 Win 来源，允许同时选择。
原有手机本地托管读取、Win 本地读取继续可用；手机正常使用不依赖 Win 在线。
主项目负责本机会话、固定字段读取、本人设备间的私密传输；量化负责网格产品界面。
本功能只有读取，不把读取勾选解释为跨设备交易、自动发送聊天或公开分享的授权。

## 来源合同

- yilong.grid_device_snapshot.v1 复用主 APK 已验证的网格行和 metrics 字段；不复制网页请求适配器。
- platform 为 android 或 windows，device_id 为安装生成的不透明随机标识。
- 同一用户、平台、设备只有一个最新槽位；账号变化替换整个槽位，不能拼接前后账号。
- account 为已验证账号的 SHA-256，account_kind 区分主/子/未知账户；不传原始 UID。
- sequence 是设备持久递增序号。相同序号与相同正文幂等；相同序号不同正文、倒序提交拒绝。
- observed_at_ms / fresh_until_ms 来自实际观察，最长有效 5 分钟；重读云端不延长观察时间。
- unavailable 必须是空行，清除该来源旧数据。服务器接收时间不冒充观察时间。
- 本地显示选择与源设备同步开关分开；设备只在用户开启本人设备同步后发送，停止后发送空状态。

## 传输与消费

/api/me/grid-device-sources 仅挂在现有可信 TLS 入口，要求当前真实一龙用户会话。
owner 从认证推导，不接受请求自报。不同用户不能枚举或覆盖来源；不进入公开 /quant 代理。
每份最多 500 行 / 256 KiB，每人最多 16 来源 / 1 MiB；24 小时未更新来源退出目录。
Cookie、CSRF、网页 token、任意 URL/脚本/请求头均不在合同中。
量化通过正式原生只读授权读取，不把主账号或币安凭据注入 WebView。
量化 /api/asset-access/grid-device-sources 继续使用现有 grid.snapshot.read，
只返回 Win 来源，与原同意范围一致；APK 来源继续使用现有本机托管授权，不扩大旧授权。

各消费者保留来源身份、状态及观察时间；以来源/账号/策略组成选择键，不能只按策略 ID 合并。
同币安账户在两台设备的重复策略不得被重复汇总收益；身份无法证明一致时分组展示，不猜测合并。
一个来源离线或失败不能清掉另一个来源；换账号、取消选择、页面退后台使迟到响应失效。
远端只读快照不能作为本地详情、报表或交易命令的目标，不以相同策略 ID 路由到另一个账户。

## 验收与当前边界

必须分别验证：APK-only、Win-only、双选、全不选；空列表、离线、过期、换账号、
迟到/重复/乱序、同 ID 不同账号、同账号双设备去重、停止同步及恢复。
主项目聊天附件与分享的最终发送继续由用户操作；读取不自动发布任何网格。
源码、离线测试、各包构建、服务器部署、真实双设备读取分别记证，不由其中一项推断其他项。
Feature Registry 工具本会话未提供，登记待工具可用后完成，禁止手改注册表。
