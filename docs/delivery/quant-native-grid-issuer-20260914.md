# 原生模拟网格授权签发

主项目新增个人会话签发入口 `/api/me/quant/native-grid/access-grants`，仅挂载到实际 TLS 私有路由。真实 users/sessions 是账号和期限的真源；静态 owner/admin、过期、撤销、停用、虚拟账号、重复鉴权头、查询参数和 simulate 范围均拒绝。

签名覆盖 `yng1.` 与原始 base64url payload，与旧 Paper 原始 JSON 签名分离。subject 使用独立 HMAC 域，签名密钥轮换不改变同一 subject。事务内读完身份后才取得签发时钟，期限最多300秒并受父会话剩余期限限制，不保存 token、不延长登录、不改资金和权限数据库。

## HTTPS 入口漏项修复

0.3.1749（源码564d9c909）正式构建、部署、健康和版本核对成功，但实际8443的签发入口返回404。根因是账号HTTPS的精确路径白名单没有包含新接口；它已经通过共用私有路由挂载，不能再归因为漏挂载。此前测试只覆盖内部私有路由，未经过这个外层白名单。

本次仅放行该精确路径的GET/POST，并让完整服务集成测试复用生产HTTPS组装，包含已启用的公开量化路由。17项相关生产源码测试全部通过，覆盖真实用户签发、缺少鉴权、公开路由不吞凭据及入口方法/查询/编码/后缀边界。独立account-https harness曾因依赖下载失败而未执行，不记通过；随后完整服务直接执行同一入口测试和其余16项通过。

发布后的必要检查是实际8443匿名GET/POST返回401且no-store，其他方法及带查询参数仍404，旧资产鉴权入口和量化首页仍可达。构建成功不替代这组公网检查，也不证明已配置正式签发密钥。

## 交付边界

本批未配置生产密钥，未用真实主账号签发；不能声称个人原生网格已经上线。客户端同意页、长效撤销/恢复、实时调度与量化原生策略 UI 仍未完成。签发期限不是要求用户每5分钟操作授权；长期连接需要后续独立合同。

本批未更新 APK、未操作用户手机或网页登录、未创建/修改/结束交易所网格。量化钱包同意已经完成的历史证据保留，当前手机离线，新的点击无响应问题仍待设备复核。
