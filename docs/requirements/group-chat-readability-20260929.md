# 群聊消息可读性与底部遮挡修复

用户反馈主 APK 群聊的 AI 正文在浅色气泡上接近不可见，底部账号说明与聊天记录重叠。
原始截图是当前错误证据，不是设计目标；私有群内容不进入源码或公共验收夹具。

## 本批范围

- 修复 ChatAdapter 运行时旧固定文字颜色覆盖 V2 XML 颜色的问题，覆盖 AI、群成员、
  自己、过程、错误、撤回及复用行。闪烁渐变同样使用主题文字，避免动画重新变成白字。
- 输入区使用不透明主题底色，遮住滚到其下方的历史消息；继续按实际输入区高度留白，
  保留输入展开、键盘和发送行为。群聊账号入口简化为标题与“账号与群聊记忆”，
  完整用量、账号、独立项目及记忆边界保留在详情中。
- 原生补验发现展开编辑器仍把浅色主题表面配上旧白字，因此统一收起/展开/附件输入
  面板的语义底色、正文、提示和单色操作图标；收起后的草稿预览也须保持对比度。
- 引用来源、继续讨论、分享设置、模型选择、草稿和账号跳转保持原有回调；本批不发送
  真实群消息、不更换账号、不清空数据。群聊继续讨论热区至少 48dp。

## 验收矩阵与跨端影响

消息必须走实际 ChatAdapter 绑定，不能仅 inflate XML 后填字。输入区使用实际
MainInputComposerSetup 和 MainKeyboardInsetsAnimationActions。单元检查覆盖 320/411dp、
浅/深、100%/150%/200% 字体、收起/展开输入与草稿；原生运行覆盖两种输入状态、
浅/深和三档字体。新预览仅使用合成群数据，无网络业务执行。

PWA 已通过 --bubble-ai-ink/--bubble-user-ink 消费 V2 配对颜色，不执行 Android 的
ChatAdapter 固定色覆盖，也没有 GroupChatGptConnectionPrompt 原生账号入口。本批不改
共享 Token、消息协议、业务能力或网页资源。仍以生产 PWA 的离线聊天结果捕获验证
共同的消息阅读状态；原生群聊账号区、来源卡片、输入展开由原生证据单独验收。
跨端规格验证共同阅读能力，明确两个夹具文案和聊天场景不同，不称群业务或像素一致。
PWA 使用 411px 默认文字，不冒充网页 200% 缩放。正式装机与视觉证据分别报告。

本批修复不等于两套 APK 全面重构完成，也不证明真实登录、发送、完整群聊权限和性能
已重新验收。用户反馈触发一次有界真机复核，设备不可用时如实延期；正式发布后的
登记手机覆盖安装与版本回读仍由统一脚本执行。
