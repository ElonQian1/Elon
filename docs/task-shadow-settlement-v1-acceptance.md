# 链外影子结算 V1 验收

## 自动化标准

1. v110 迁移创建项目设置、用量凭证、结算意图、来源关联、结算凭证、账本交易和账本分录七张表；v122 创建 Sui 链下投影包表；v123 创建争议案件和追加式事件表；v124 创建纠正流程和事件表，并为凭证增加种类与纠正关联。
2. 默认全局关闭，项目默认关闭；项目设置不能关闭 `shadow_only`。
3. 同一来源重复到达返回同一用量凭证；摘要变化返回冲突。
4. 同一 Assignment 重放不产生第二个结算意图。
5. 节点、Matter 或 Assignment 不匹配时拒绝创建事实。
6. 未人工验收的 Matter 不能过账。
7. 人工验收后每个待处理意图只过账一次。
8. 节点收益不得超过真实计算成本。
9. 已过账交易借方和贷方金额相等。
10. Matter 取消只作废待处理意图。
11. 商业调用只记录用量，不产生真实扣款或收入。
12. Sui 信封只能由已对账影子凭证生成，且明确标记未提交网络。
13. 同一凭证、目标网络和 schema 重复准备返回同一投影包，不同网络生成不同摘要。
14. 投影包保存来源摘要和投影摘要；任一内容被篡改后复核状态变为 `conflict`。
15. 没有网络适配器时，所有投影包保持 `not_submitted`、零提交次数和 `adapter_required`。
16. 同一凭证只允许一个待审核争议；完全相同的重复提出幂等复用，内容变化拒绝覆盖。
17. 争议只能从 `open` 转为 `accepted`、`rejected` 或 `withdrawn`，每次变化追加事件且不能再次处理。
18. 待审核或已接受争议阻断 Sui 信封和新投影准备，已有投影包返回 `dispute_blocked`；驳回或撤回恢复就绪。
19. 接受争议不改写历史凭证、双分录、节点收益或真实资金。
20. 只有已接受争议可创建纠正 Matter；同一活动请求幂等，内容漂移冲突，取消后可以重新规划。
21. 纠正 Matter 未人工验收前不得过账；关闭影子经济时手工重试也必须拒绝。
22. 验收后在同一事务内追加一张冲销凭证和一张替换凭证，两张凭证各自借贷平衡，原凭证保持不变。
23. 概览按标准与替换金额加总、冲销金额扣减；重复过账不产生额外凭证。
24. Matter 取消不生成纠正凭证；冲销凭证不能再次发起争议，替换凭证可继续形成下一条纠正链。
25. 单张冲销或替换凭证不能生成普通 Sui 信封或投影包，PC 工作台同步禁用该操作。
26. v125 创建独立纠正投影包表；重复执行迁移不得失败，冲销和替换凭证 ID 不得相同。
27. 只有已人工验收并完成过账的纠正可以准备原子包；待验收或取消纠正必须拒绝。
28. 原子包同时绑定冲销与替换凭证、来源包摘要和目标网络摘要；同一网络请求幂等，不同网络生成不同包和摘要。
29. 纠正包始终保持 `not_submitted`、零提交次数；篡改摘要后复核持久标记 `conflict`。
30. 替换凭证的新争议把纠正包就绪状态派生为 `dispute_blocked`；冲销凭证不能单独建案或投影。
31. 未纠正标准凭证的根凭证和有效凭证相同，请求位置为 `effective_standard`。
32. 从任意冲销或替换凭证查询时，能够回溯根凭证并沿多次已过账纠正得到唯一有效替换凭证。
33. 待验收和已取消纠正出现在非过账计划列表中，但不改变有效凭证；有效凭证争议状态单独返回。
34. 纠正链遍历有 32 层上限；循环、分叉、缺失替换或双腿关联错误必须失败关闭。

## 纵向场景

自动测试应创建真实测试数据库并完成：

```text
用户和提供者
  -> 项目、Matter、Assignment
  -> 节点执行记录及真实成本
  -> 用量凭证与待处理意图
  -> 未验收过账被拒绝
  -> Matter 标记人工验收
  -> 单次影子过账
  -> 双分录平衡
  -> Sui 未提交信封
  -> 持久链下投影包
  -> 摘要复核与篡改冲突
  -> 追加式争议案件
  -> 投影阻断但不自动改账
  -> 已接受争议创建独立纠正 Matter
  -> 未验收和关闭开关时拒绝过账
  -> 人工验收后原子追加冲销与替换双分录
  -> 概览显示纠正后净额，普通 Sui 投影仍被阻断
  -> 两条腿共同保存为链下原子纠正包
  -> 摘要复核、篡改冲突与替换凭证争议阻断
  -> 从任意凭证解析根、纠正步骤和当前有效凭证
  -> 待验收计划可见但不改变有效金额，异常链失败关闭
```

## 不属于本期验收

- Sui SDK、Move 合约、测试网或主网交易；
- 钱包、私钥、稳定币、Gas 赞助和链上托管；
- NET、CREDIT、RevenuePosition 或股权发行；
- 合同现金流自动分配；
- 对现有人民币余额、Token 扣费和节点提现的任何修改。
