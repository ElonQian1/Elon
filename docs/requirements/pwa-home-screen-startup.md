# PWA 桌面启动与品牌修复

用户反馈 iPhone Safari 添加到主屏幕后打不开或白屏，主要使用群聊；名称要求为“一龙ai”，使用正式品牌 Logo。

已复现：线上首页返回 200，但 head 中同步资源延迟时 body 尚未解析；localStorage 被拒绝会中断主脚本。线上 manifest 两个 PNG 地址为 404，名称不符。尚未获得用户实际网址和 iPhone 版本，不能把这些证据当成目标真机根因已全部确认。

## 验收范围

1. 运行时模板自包含全部同源启动脚本和样式，断开的可选外站 SDK 不阻塞登录及群聊。所有嵌入代码保持原顺序，生成阶段校验缺失和不安全的结束标签。
2. 启动状态有明确的加载、失败和重试；存储读写被拒绝时可在当前页面登录、进入群聊，不丢弃已有正常存储，不自动重放消息。
3. 公共壳离线及服务端 5xx 使用已有壳；无缓存时返回可重试页面；不缓存 API 或用户数据。
4. manifest 与 Apple 元数据名称为“一龙ai”，桌面启动到聊天；180/192/512 PNG 返回真实声明尺寸并从 assets/brand/logo.png 派生。
5. 隔离浏览器验证正常、资源中断、存储拒绝、登录、群聊、退出、缓存重启、5xx、离线、账号隔离；发布后核对首页、图标、版本。iPhone 主屏幕启动未现场验证时明确延期。

## 所有权

新建独立启动及 PWA 路由模块；模板只连接模块。复用已有社交缓存/恢复模块，不重写消息协议，不改 APK 或 Windows 功能。并行发送者名称改动在模板 appendBubble，保持其所有权；本任务仅启动、元数据、运行时打包及 PWA 壳。

## 发布与恢复

服务端和 runtime 模板均通过官方发布入口。模板静态更新不能替代新增图标路由及 Worker 的服务端发布。保留缓存键兼容和原始会话令牌；恢复按钮不清除聊天缓存或用户存储。Apple 桌面已保存的名称/图标可能需要重新添加；未完成真机验收不标记为 verified。
