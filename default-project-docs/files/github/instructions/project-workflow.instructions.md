# 项目开发流程

本文件用于任务开始、任务卡住或跨模块改动时读取。

## 开始前

1. 确认当前工作目录、分支和 Git 状态。
2. 阅读 `AGENTS.md` 和 `.github/copilot-instructions.md`。
3. 只读取与当前任务相关的专项 instructions，不全量展开所有文档。
4. 找到真实入口、数据结构、调用链和现有测试或验证脚本。

## 实现中

- 先修清楚当前用户目标，不顺手做无关重构。
- 新逻辑放在按职责命名的模块里，避免扩大入口文件。
- 发现已有用户改动时，判断是否相关；不相关就避开，相关就兼容处理。
- 需要新增配置、脚本或文档时，优先沿用项目已有约定。

## 卡住时

- 回到真实错误、日志、接口响应或构建输出，不凭猜测继续扩大改动。
- 缩小复现路径：单测、最小命令、最小页面、最小接口。
- 如果依赖外部状态或用户授权，说明阻塞点和已经确认过的事实。

## 收尾

1. 运行最小有效验证。
2. 检查 `git status`，确认新增文件已显式纳入。
3. 提交代码；如果项目要求，推送远端。
4. 汇报验证命令、提交 SHA、推送状态和发布状态。
