# 消费者本人授权状态 MCP V1 验收

状态：`implementation_verified`

## 已验证

- 查询由当前项目、当前用户和本人 App 三重条件约束。
- 支持四种稳定状态筛选和 1 至 100 条有界返回。
- 返回批准后的 Grant 期限、次数和预算，但省略内部身份字段。
- 可另行列出当前项目本人 App 下仍有效的 Grant、期限、已用和剩余调用/计量预算。
- 预算耗尽的有效 Grant 明确标记 `budget_exhausted`；无上限预算不伪造剩余数字。
- 工具只读，不推进任何授权或调用状态。
- 项目编辑者可在固定确认短语后撤回本人 pending 请求，并复用现有双侧审计。
- 非 pending 请求幂等保持原状态，批准后的 Grant 不受影响。
- 同项目其他用户和同用户其他项目的申请、Grant 与相同 App 显示名称不会串入本人结果。
- 撤回响应与列表条目使用同一最小安全投影；Grant 总览不返回消费者项目 ID。
- 定向 Rust 套件已通过，覆盖 MCP 路由、数据库查询、预算投影、权限与审计。

## 仍需执行计划回归

- 历史 approved 但 Grant 过期或撤销时，执行计划仍失败关闭。
- Grant 当前有效但 App 已封禁时，执行计划仍失败关闭。
