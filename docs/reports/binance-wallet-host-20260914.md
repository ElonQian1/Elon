# 币安钱包概览生产端

按照[钱包宿主需求](../binance-wallet-host-v1.md)新增固定钱包读取、独立用途授权和版本化概览接口。量化消费端尚未实现，本记录不代表当前账户钱包已接通，也不代表完整商业网格产品已完成。

## 代码

- `binance_wallet_adapter.js` 复用页面实际观察的账户请求上下文；固定 USDT 钱包 GET，前后确认精确账户。只发送钱包类型、启用状态及十进制估值，不导出资产明细或请求凭据。
- `grid/wallet` 分开管理钱包状态、持续授权恢复、请求期限、固定 IPC 和用户授权页。持久同意与网格读取分开保存，grant 留内存；原网格授权格式和用途保持兼容。
- 宿主复用既有 WebView、身份验证、生命周期和无载荷事件。账号改变、页面换代、授权撤销和旧请求结果被隔离；没有新增两秒轮询或交易命令。
- 原生 MCP 只增加钱包状态、身份是否验证、请求是否在途、钱包数量和错误类别，不包含金额、账号或 grant。

## 离线验证

JavaScript 58项通过，包含新适配器、真实组合接线及既有网格读取/报告/生命周期回归。其中组合测试只经过账户身份接口、没有网格列表或策略对象，也可完成钱包读取；页面token改变后旧响应被取消并丢弃。

Android定向26项通过：钱包状态10项、原宿主状态15项、原网格同意1项。覆盖十进制精度、缺失金额、未启用钱包、空集合、重复类型、错误金额类型、账户错配、撤销、迟到响应、新身份验证接续、过期与独立用途。主APK Debug源码和测试编译通过；未以这些夹具证明当前官网资金口径。

## 交付与待验

功能登记仅更新 `binance_wallet_summary_host_v1`，其余记录语义未变。正式发布与装机身份待后续回执补充；量化资产消费端、原签名双包当前账户只读对照、授权/撤销/换号/进程恢复及原生像素仍待验。

历史采集响应用于确定读取路径和字段类型，没有进入生产数据或测试金额。合约与策略钱包分列但不直接合计，估值不能被解释为可提现金额、可用保证金或完整权益。本批没有执行交易或重启Win/Chrome。
