# 开放商业网络 Sui 与 AI Agent 经济架构草案

## 文档状态

本文整理阶段四的候选技术方向，不改变当前 V1，也不代表区块链、代币、去中心化存储或闲置算力市场已经实现。现行边界以 `docs/decisions/open-commerce-network-v1-architecture.md` 为准。

已确认的边界只有三项：Sui 只作为阶段四候选经济层；Sui 不承载模型计算和原始经营数据；前三阶段成立后才研究上链和发币。其余组件和参数均为待验证方案。

## 一句话定位

> Sui 是开放商业网络的所有权与结算层，不是 AI 模型的计算层。

项目目标不是单纯发行代币，而是让消费者 Agent、商户 Agent、技能开发者和算力节点使用不同 App，通过统一对象和协议发现能力、授权调用、完成任务并自动结算。

## 与现有路线的关系

```text
V1：商户节点、能力发布、授权调用、计量审计
  -> 阶段二：标准化商户节点和可迁移数据
  -> 阶段三：跨 App 发现、调用与真实结算
  -> 阶段四：评估 Sui 所有权、结算、信誉和治理层
```

Sui 方案不能成为前三阶段的依赖。只有真实商户密度、稳定调用量、真实结算和争议处理得到验证后，才进入原型研究。

## 候选分层架构

```text
消费者 App / 商户 App / 第三方 AI Agent
                    |
          开放 API、SDK、MCP
                    |
     身份、授权、任务、计量与争议服务
          |                     |
Sui 所有权与结算层          链外执行层
          |          云、PC、GPU、边缘节点
          |                     |
  对象、托管、分账      加密数据、模型和结果文件
  信誉、治理、摘要       Walrus/Seal/普通云存储候选
```

模型推理、代码构建、图片视频生成和 GPU 任务在链外执行。链上只登记资产归属、能力凭证、任务状态、支付条件、结果摘要、信誉与争议证据。

## Sui 特性与项目映射

| Sui 能力 | 项目中的候选用途 | 设计约束 |
|---|---|---|
| 对象模型 | Merchant、Agent、ComputeNode、SkillPackage、Job、Escrow、DataCapability、ResultReceipt、Reputation | 不把所有状态集中在单一全局对象 |
| 并行执行 | 每任务独立建模，市场按区域、行业或能力分片 | 压测共享对象热点、延迟和成本 |
| 可编程交易块 | 原子完成托管、授权、验收、分账和信誉更新 | 争议和复杂验收仍需链外服务 |
| zkLogin 类入口 | 使用熟悉账号进入 | 用户不直接处理助记词 |
| 赞助交易 | 平台或套餐代付 Gas | 需要额度、限流和防滥用 |
| Kiosk 类机制 | 技能、模板、小游戏和 Agent 插件的授权与版税 | 可交易性不能替代质量审核 |
| Walrus/Seal 类能力 | 保存并按策略开放加密模型、记忆、代码和媒体 | 原始经营数据不上链，访问可撤销、可审计 |
| Nautilus/TEE 类能力 | 验证部分链外任务环境和结果 | 不等于任意 GPU 任务都可验证 |
| DeepBook 类流动性 | 网络代币确有兑换需求时提供流动性 | 不作为商户使用产品的前置条件 |

实施时必须按届时 Sui 官方文档和测试结果重新核验这些能力。

## AI 任务与算力结算闭环

1. 商户或消费者 Agent 创建独立 Job，声明预算、权限、期限、验收和争议规则。
2. 预算进入 Escrow；算力节点或技能 Agent 报价并承接任务。
3. 系统签发最小权限、限时、可撤销的 DataCapability。
4. 节点在云端、PC、GPU、边缘设备或可信执行环境完成任务。
5. 大文件和敏感结果进入链外加密存储，链上登记哈希、索引和 ResultReceipt。
6. 商户 Agent、规则引擎或人工验收结果。
7. 可编程交易块原子释放费用，向节点、技能开发者和协议服务方分账。
8. 成功、失败和争议更新不可转让 Reputation；作恶可触发质押惩罚。

## 三层资产模型

### NET：网络安全与治理资产

NET 为可转让网络代币，候选用途是节点和服务商质押、作恶惩罚、协议治理及长期激励。它不直接承担商户日常服务计价，避免币价波动传导到 AI 使用成本。

### CREDIT：稳定服务计量单位

CREDIT 为闭环、价格稳定的服务积分，用于 AI Token、GPU 时间、构建、存储和能力调用。用户可充值或通过完成真实算力任务获得；发行、赎回、退款和兑换规则须单独验证。

### Reputation：不可购买的信誉

商户、Agent、开发者和算力节点的履约、争议和能力认证进入不可转让信誉对象，不能通过购买 NET 或 CREDIT 获得。

网络价值的核心指标是：

```text
商户节点数量 x 可调用 Agent/技能数量 x 有效任务量 x 真实结算量
```

代币价格不属于产品价值验证指标。早期收入继续来自商户 AI 经营系统、托管、能力调用、任务执行、结算和插件市场服务。

## 关键风险与进入条件

- 任意 GPU 任务的验证成本可能接近重新执行，需设计复算、抽检、证明和争议机制。
- 高并发共享对象可能形成热点，必须按真实对象模型压测。
- 激励应主要来自真实任务收入，不能长期依赖新增代币补贴。
- Sui 不能解决第三方平台拒绝开放 API、原始数据失真或 AI 结果质量问题。
- 候选组件的成熟度、成本、退款、密钥恢复和争议流程必须单独验证。

进入测试网原型前，应同时满足：阶段二、三已证明跨 App 调用；存在稳定计费和分账需求；节点贡献可用任务结果和 SLA 衡量；中心化账本已出现真实的多方信任或迁移成本；普通商户无需理解钱包和 Gas；失败、退款和争议已有可执行方案。
