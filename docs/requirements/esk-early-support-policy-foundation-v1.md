# ESK 两年保障政策草案合同与离线检查 V1

## 本批次目标

建立可以由后续 Android、Web、外部 AI 和发行准备工具共同读取的版本化政策草案。
离线检查器准确指出缺少哪些业务决定，拒绝损坏或越界输入；即使字段填写完整，
输出也只代表可进入政策审阅，不能证明担保成立、资金已到位或允许发行。

本需求接受的是草案合同及校验工具的工程范围，不接受未确定的经济条款。

## 已确认的业务方向

- 用户购买 ESK 后，团队计划将募集资金用于投资并给予回报。
- 团队提出早期兜底保障，政策持续两年。
- “保底”是否含最低收益、计价币种、起止规则、责任主体和补亏资金来源尚未明确。
- ESK 保持既定名称和服务支付、治理、团队利润参与方向；本需求不将其替换为 QSHARE。
- 公开币安资产展示仍仅限总估值及更新时间，不因政策草案而扩大公开字段。

## 当前能力与冲突

- ESK 既有决定不包含保本或随时面值回购。两年保障是新增政策要求，不能沿用旧假设。
- 量化仓库有限实缴 Junior 先吸收亏损的计算，不等同持续补足的两年保障承诺。
- 现有卖回申请只是登记、占用及取消，不是现金兑付或保障赔付执行器。
- 测试网地址绑定、发行计划与交易所账户估值均不能证明保障已获得资金支持。

## 输入与输出合同

- 输入版本为 `elon.esk.early_support_policy_draft.v1`，状态只能是 `draft`。
- 业务方向固定为 ESK、募集资金计划用于投资、计划给予投资回报、早期保障意向及两年政策。
- 未决定字段使用显式 `null`，不能用零金额、空字符串、假地址或测试日期代替。
- 草案需要记录保障范围、计价币种、期限基准、计划起止日期、责任主体、资金来源及说明、
  兑付时点规则、转让规则、消费规则、是否交回代币、已领回报如何处理、周年计算约定，以及最低收益条款。
- 最低收益条款仅在选择本金及最低收益保障时必须填写；其他范围保持 `null`。
- 程序统一维护枚举、稳定缺失项标识和一致性错误；严格拒绝未知字段、错误类型、
  重复 JSON 键、危险对象键、过大输入、非有限数、非法日期及结束早于开始。
- 日期使用 UTC 秒精度时间；周年计算和闰日约定属于待决定字段，不擅自用固定 730 天代替。
  每笔购买起算时，计划窗口与单笔保障到期分别建模；本工具只检查草案日期有效且先后正确，
  不替不存在的购买记录生成到期日，不宣称已经校验完整经济条款。
- 输出包含版本、输入摘要、审阅状态、缺失决定列表和一致性问题，
  不回显责任主体、资金说明、用户、地址或其他自由文本。
- 所有成功输出固定 `policy_status=draft`、`production_authorized=false`、
  `funding_verified=false`、`funds_moved=false`。字段完整只能得到 `ready_for_policy_review`。
- 无效文档返回有界的稳定错误与非零退出码；合法但未完成的草案可以正常读取，
  其审阅状态必须为 `needs_decisions`，消费者不得以进程成功代替政策批准。

## 资金和权利的后续模块边界

1. 购币记录：付款、购买批次、适用政策版本与保障对象。
2. 投资账本：真实净资产、盈亏、费用与已结算利润；购币募集款不计作投资利润。
3. 保障义务账本：保障本金、期限、适用条件、申请、已履行与剩余责任。
4. 准备金账本：实际资金来源、归属、占用及补足；同一笔资金不得重复计入投资与独立准备金。
5. 分配账本：批准的利润、资格快照、领取与纠正；不假定消费或转让自动决定保障权。

以上是后续实现的责任分层，本批次不新增真实账目、收款入口、交易或赔付接口。
政策窗口结束不等于既有义务清零；审批、签名、资金证明及政策版本变更需后续独立合同。

## 验收

1. 真实 fixture 被识别为未完成草案，逐项列出未确定决定，没有任何正式保障默认值。
2. 字段完整的合成草案只进入政策审阅，仍不批准发行、资金或保障生效。
3. 错误类型、未知字段、重复键、危险键、超限、非法日期、擅改两年意向及条件矛盾被拒绝或明确列为一致性问题。
4. 对草案字段顺序变化生成一致摘要；输入内容变化改变摘要；输出不回显自由文本。
5. CLI 路径、错误及成功用例通过真实子进程验证，所有输出为稳定有界 JSON；无网络依赖。
6. 现有 ESK、QSHARE、公开资产、地址绑定、Move 合约及发行预检文件保持原有实现。
7. 源码、Schema、fixture、测试和交付证据通过当前任务提交至主线；不需要生产部署。

## 完成边界

完成本批次只说明“当前任务已接管新工作，政策草案能由机器读取及检查”。
两年保障的最终条款、资金证明、真实账本、用户钱包验收、真实售币、投资、
利润分配、测试网或主网签名广播均不因此完成或获得授权。
