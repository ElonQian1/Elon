# Sui 适配器离线交接包 V1 验收

## 当前状态

`implementation_uncompiled`

本批只形成代码、Rust 格式整理及仓库静态门禁，尚未编译、运行 API、生成实际下载或连接 Sui 网络。

## 已形成代码

- 标准投影和纠正双腿投影共用的版本化离线交接契约。
- 导出前重新复核来源、投影摘要和信封，并再次应用争议阻断。
- 项目、包、来源、目标网络、原始信封和安全约束共同参与交接摘要。
- 标准包固定 `atomic_bundle=false`，纠正包固定 `atomic_bundle=true`。
- 网络状态只允许 `not_submitted` 且提交次数必须为零。
- 约束明确为离线预检，不包含签名、广播、最终性和资金移动。
- PC 标准包和纠正包均可请求交接包并下载 JSON。

## 统一回归必须验证

- 标准包与纠正包的字段、摘要确定性、JSON 往返和不同目标网络隔离。
- 来源凭证、纠正双腿、投影摘要或信封漂移时拒绝导出。
- 新增阻断争议、完整性冲突、非零提交次数和非 `not_submitted` 状态。
- 纠正包不能丢失、交换或拆分冲销与替换两条腿。
- 跨项目、只读成员、项目编辑者和不存在包的权限结果。
- PC 下载文件名、内容、错误提示、忙碌状态和生产构建。

## 仍未完成

- Rust/TypeScript 编译、API、权限、摘要往返、并发和 UI 验证。
- 机器适配器身份、租约、密钥、Gas、PTB、签名、广播、重试和最终性确认。
- Move Package、测试网或主网提交、真实 Token、收入权益和资金移动。
