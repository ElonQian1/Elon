## Promotion Change

Transaction version 23 and adapter 389 enable only the accepted native first-send
path with a bound official composer. They reuse the existing preparation,
security-aware same-origin HTTP, owned stream decoder, history reconciliation,
native receipt and identity-based placeholder merger. No second sender is added.

`__elonChatGptFreshTextNewConversationsEnabled = false` disables this default.
Explicit `true` and the existing one-command trial retain their research scope.
The main private-text switch still applies. Independent project, tool, attachment
and temporary flags remain opt-in; the initial composer-free path is not promoted.
This remains page-local private HTTP with the WebView identity/runtime layer,
not an independent Android HTTP client or elimination of that layer.

`fresh-new-default-tests-fixed-20260914-104704-858` passed all 269 focused Node
tests, with no failures, cancellations or skips. Real-context personal first-send
and follow-up fixtures now omit the experimental flag. Scope tests cover narrow
default admission, explicit opt-out, composer absence and retained trial behavior.

cleanup assertion was corrected before the final green run.
