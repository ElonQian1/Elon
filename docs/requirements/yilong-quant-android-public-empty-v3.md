# 官方量化 APK 公开空状态 V3

## 目标

`yilong-quant` 是主项目内置的公开子项目。主 APK 在用户登录前也会访问其固定
Android 下载地址，因此该精确项目不能在没有合格新版时回落到成员下载鉴权。
没有通过当前新版准入的发布时，固定地址必须直接返回明确的 `404`；存在合格发布时，
同一地址必须无需主账号 token 返回服务器托管且复核过摘要的 APK。

## 行为合同

1. `GET /api/store/projects/yilong-quant/downloads/android` 在没有合格
   `versionCode >= 5` 发布时返回 `404` 和稳定的“暂无可安装新版”错误，不读取 bearer、
   查询参数 token 或项目成员关系。
2. 合格发布存在时继续走受管工件路径，复核文件位于发布根目录、大小和 SHA-256，
   匿名返回 `200`、`no-store` 与 `x-apk-sha256`。
3. 其他项目保持原合同：公开发布可匿名获取；没有公开发布时仍可凭项目成员身份读取
   私有下载，未登录继续返回 `401`。
4. 旧量化发布、任务 APK、静态 landing 和任意工作区文件不得用于填充空状态。

## 验收标准

- 处理器测试证明精确官方项目在匿名、伪 token 和无 token三种请求下均得到相同
  `404` 空状态，并且错误不包含内部路径、发布记录或鉴权信息。
- 回归测试证明相似项目 ID 与普通私有项目仍进入既有成员鉴权，不被官方例外放开。
- 既有已准入量化发布的匿名受管下载、大小/摘要复核和响应头测试保持通过。
- 发布服务器后，真实公开地址在尚无 0.5 工件时返回 `404`；后续正式上传必须再以
  `200`、包名、版本、唯一证书、大小和摘要完成独立验收。
