简单说，做了**两步**修复（都是针对系统层面的小米语音引擎包 `com.xiaomi.mibrain.speech`，不是 app 本身）：

## 修复内容

| 步骤 | 命令 | 解决了什么 |
|------|------|-----------|
| ① 启用包 | `pm enable com.xiaomi.mibrain.speech` | 小米语音引擎原本被禁用（`enabled=0`），重新启用 |
| ② 授权录音 | `pm grant com.xiaomi.mibrain.speech android.permission.RECORD_AUDIO` | 小米语音引擎自己没拿到麦克风权限，给它授权 |

## 为什么会出现这种情况

小米 HyperOS（Android 16）会在某些情况下**自动禁用预装系统应用**或撤销其权限，常见触发场景：
- 用户在"应用管理"里手动停用过
- 系统优化/省电策略把"长期未使用"的系统组件禁用
- 系统升级后部分权限被重置
- 某些"隐私保护"工具（如绿色守护、冰箱）冻结了它

## 调用链回顾

```
你的 app
  └─ SpeechRecognizer.createSpeechRecognizer(context)   ← 标准 Android API
        └─ 系统读 settings.secure.voice_recognition_service
              = com.xiaomi.mibrain.speech/.asr.AsrService   ← 默认值
                    └─ ❌ 这个包被禁用 → 整条链路死
                    └─ ❌ 这个包没录音权限 → 拿不到麦克风
```

修复后：

```
                    └─ ✅ enabled=1
                    └─ ✅ RECORD_AUDIO granted=true
                          → 语音识别正常返回结果
```
