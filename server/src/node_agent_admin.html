注册本地项目（绑定到本 PC 节点）

⚠️ 未配置 NODE_USER_TOKEN，无法注册项目。
解决：从 APK 登录后获取 token，重启 node-agent 前设置：
$env:NODE_USER_TOKEN = "你的 token"

流程：本地校验路径存在 → 调用云端 POST /api/projects/external（附 node_id， 让服务器跳过本地路径校验）→ 项目自动绑定到本节点，owner = 你。注册成功后在 APK『项目广场 / 我的项目』可见。

环境变量参考

NODE_CLOUD_URL       云端 WebSocket 地址（默认 ws://43.139.149.158:8080/agent/ws）
NODE_CLOUD_HTTP_URL  云端 HTTP 地址（默认从 NODE_CLOUD_URL 派生）
NODE_AGENT_ID        本节点唯一 ID（必填）
NODE_AGENT_SECRET    认证密钥 64 字符 hex（必填）
NODE_OWNER_USER_ID   你的 elon 用户 ID（必填）
NODE_USER_TOKEN      你的 elon 登录 token（注册外部项目需要）
NODE_OLLAMA_URL      本地 Ollama 地址（默认 http://localhost:11434）
NODE_LM_STUDIO_URL   LM Studio 地址（可选）
NODE_CUSTOM_LLM_URL  自定义 OpenAI 兼容地址（可选）
NODE_PRICE_PER_1K    每 1k tokens 收取的积分（默认 0.1）
NODE_ADMIN_PORT      本管理页端口（默认 7799）
