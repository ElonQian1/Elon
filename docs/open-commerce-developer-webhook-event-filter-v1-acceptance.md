# 开放商业开发者 Webhook 终态事件筛选 V1 验收

## 当前状态

`verified_local_store_subset`

Rust 服务端已编译；全新 SQLite 数据库上的专项测试验证成功专用订阅接收本 App 的成功终态，失败专用订阅不接收成功终态，其他 App 的事件不串入。失败终态正向入队、历史库迁移、真实 HTTP 投递和 PC 页面仍未验证。

## 已形成代码

- V149 保存成功与失败事件筛选，并为既有订阅默认开启两项。
- 终态触发器只为订阅选中的事件创建投递记录。
- 服务端拒绝两个筛选项都关闭的订阅。
- PC 创建表单提供两个复选项，并在订阅列表显示固定筛选范围。

## 统一回归必须验证

- V148 到 V149 历史库升级、重复迁移和既有订阅行为兼容。
- 失败专用订阅的失败终态正向入队，以及全部事件订阅的完整组合。
- 两项都关闭的 HTTP 请求失败且不创建订阅或一次性密钥。
- 多订阅、App 停用、订阅启停、密钥轮换和终态事件并发时的触发器行为。
- PC 类型、复选框、禁用状态和小屏布局。

## 仍未完成

- 原地修改筛选、更多事件类型、条件表达式、动态路由和批量历史回放。
