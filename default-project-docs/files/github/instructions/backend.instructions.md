# 后端与 API 任务

本文件用于后端服务、API、数据库、鉴权、队列、文件系统和部署相关任务。

## 修改前

- 确认入口路由、请求模型、响应模型、持久化位置和调用方。
- 检查是否涉及用户隔离、项目隔离、节点隔离或权限边界。
- 先读已有错误处理和日志风格，保持一致。

## 实现规则

- API 响应要稳定、可解析，避免只返回给人看的临时字符串。
- 写入文件、数据库或远程节点前，要确认路径、归属和失败回滚策略。
- 后台任务要有可观测日志，避免静默失败。
- 外部命令、路径和用户输入必须做边界处理。

## 验证

- 优先运行相关单测、集成测试或最小接口检查。
- 修改协议或数据模型时，同步更新调用方和兼容逻辑。
- 涉及部署时，必须先提交代码，再走项目指定发布脚本。
