# 开放商业消费者来源筛选建议 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- 独立服务端来源选项聚合模块。
- 当前候选窗口、非穷尽声明和公开能力数量响应。
- 厂商与数据域稳定去重排序。
- PC 独立来源筛选字段组件和可编辑建议列表。

## 已验证

- 无效绑定不进入建议；多个有效内部来源按厂商与数据域去重、稳定排序并按公开能力数量计数。
- 能力 Key 会缩小聚合范围，厂商、数据域和年龄条件不会遮蔽同一候选窗口中的其他建议值。
- 响应固定声明当前运营方候选窗口且非穷尽；建议对象不包含商户 ID、回执 ID、游标摘要或授权范围。
- 来源筛选专项与现有 100 个商户候选上限回归共同验证聚合使用发现阶段的有界目录候选。

## 统一回归必须验证

- 无回执来源、单值、重复值和多个值的聚合结果。
- 能力 Key 对聚合范围的限制。
- 厂商、数据域和年龄筛选不会遮蔽建议值。
- 候选上限、能力数量、稳定排序和非穷尽字段。
- PC 空列表、选择建议、手输列表外值和再次查询。
- 窄屏布局、键盘操作和可访问标签。
