# 币安合约网格创建动态参考接口

量化 APK 创建页面需要按当前合约、区间、方向、网格类型、数量、杠杆、触发和追踪参数展示动态数量范围及最低保证金。页面归量化；主 APK 只托管会话和固定业务接口，不能要求打开旧主创建页。

通过已授权同机调用方使用的版本化只读合同提供参考。请求与操作、账号、页面代次和输入绑定；异步结果不能覆盖后来的输入或换号结果，过期或失败不能继续标记可用。不得接收任意 URL、脚本、请求头，或把网站 Cookie/令牌返回量化。

从已取证币安代码还原计算：公开 grid/coef 中的 minGridCount、maxGridCount、maxTrailingGridCount、priceDiffBuffer、adjustCoef、trailingCoef、windowCount；对应合约的价格和数量精度、最小数量及名义金额；最新标记价格；账号 makerCommission。缺失字段不代入截图或代码默认值。最低保证金不同于单笔最小名义金额。

数学模块只计算，不联网、不读账号、不发送交易；以同一代已捕获前端计算器的向量检验舍入、等差/等比、大网格数、方向、触发和追踪。通过固定名单读取输入，再做参数校验和结构化返回；失败原因及来源明确，最终准备与本人确认合同不变。

## 验收

- 请求参数、调用方、账号、文档、代次、过期、取消及迟到结果边界通过测试；只读接口不具备提交或改变仓位路径。
- 数量范围和最低投入与捕获源计算向量一致；不同参数确实改变对应结果。
- 原账号登录环境与官网同参数对比单独记录，缺少实测不能称接通。
- 编译、测试、原签名发布、量化兼容、装机和实际页面验证独立记录。

修改范围：新增独立计算资产、创建参考状态/服务；在现有创建适配器注入固定读取依赖，在 WebView 和 Provider 增加小量接线。保留原创建和管理语义，不扩建旧主创建 UI。
