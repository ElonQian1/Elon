# Android 主 APK 托管币安本人网格只读会话 V1

## 已接受方向与完成条件

主 APK 承载币安官方 WebView、保留本站登录资料；量化 APK 使用自己的网格 UI，经同机正式授权读取。Win 是接口发现、源码索引与证据研究工具，不是手机日常使用的必经节点。两个 APK 不传递网站 Cookie、密码或主账号凭据。

本批仅本人 USD-M 网格只读。列表来自当前官方页面真实响应，详情通过已观察的 GET 合同读取；不伪造列表分页参数、不以缓存替代当前账号验证。未经确认的空列表账号身份、未观察分页与未知字段必须显式报告。创建、修改、结束和仓位操作不属于本批。

用户已选择 Win 登录币安子账户进行研究、手机登录币安主账户用于产品验收。两端复用接口适配定义，业务响应、授权和验收证据按实际账号区分；主账号下的测试预算或交易授权不自动转移到子账号。

## 运行合同

- 主应用包为 `com.elon.app`，消费者为已核验签名的 `com.elon.quant`。包名声明不是调用者身份，入口和每次 IPC 必须校验 Android 提供的调用者及安装签名。
- 新的本机授权独立于 `grid.snapshot.read` 云端授权，不扩大旧 grant。授权绑定当前主账号会话、币安观察账号、消费者及随机连接，使用单调时钟，最多十五分钟，可主动撤销；进程退出不恢复旧授权。
- 官方登录只在主 APK 页面完成。网站会话保留不等于永久登录，也不意味着不同主账号可以继承先前的授权。
- 页面数据只进入原生内存，经固定字段解析后输出 `yilong.binance_host_read.v1`。来源明确为 `android_webview`，返回观察时间、可用状态和覆盖边界；不得包装成 Win 云端投影。
- 本机接口仅提供状态、读取、受限详情、刷新与撤销；无任意 URL、脚本、文件或交易透传。
- 主账号变更、币安账号变化、页面导航失效、进程重建或超时必须使旧授权失效或清除可见数据。重新连接不得静默选另一个账户。
- 列表和详情须与当前认证账号信息中的精确 UID 相符；父子关系不能替代 UID 相等。允许已验证身份的空列表；身份接口不可用时停止接受新列表，不沿用旧身份猜测。
- 详情读取必须绑定当前列表代次，迟到响应和迟到失败不得改写新列表。用户撤销后先清除本地显示，再依据主应用的明确回执显示成功；未取得确认不得伪称已撤销。
- 官方 WebView 与量化公共网页保持权限边界，账号数据不进入公共 HTTP 页面、团队资产展示或普通 MCP 日志。

## 模块与兼容

主仓新增 `android/.../grid/host` 和币安只读页面适配器，复用主账号捕获与网站桥接的既有基础；不复制 ChatGPT 业务控制器，不修改 ChatGPT 专用协议。量化仓新增本机客户端并复用原生网格展示，保留旧 Win 快照入口。

研究资料继续使用 `docs/win-browser-research-mcp.md` 的哈希、定向源码和结构化回执工作流。Win 发现合同不等于 Android 验收；手机只在登录兼容、会话恢复和双 APK 端到端阶段集中验证。

## 验收

1. 主 APK 官方页完成登录，普通重开不清除登录资料；失效能回到官方验证。
2. 真实列表、已选详情从手机会话进入量化原生 UI，来源和时间正确，无 Win 依赖。
3. 错消费者、错主账号、错币安账号、过期授权、重复或乱序响应、超大正文失败关闭。
4. 主动撤销、消费者退出和主进程恢复不继续显示旧私人内容；交易操作不存在。
5. 离线协议、页面适配、Android 编译与真实设备分别留证，未完成登录验收不得宣称手机直连成功。
