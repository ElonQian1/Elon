# 开放商业开发者 Webhook 有界历史补发 V1 验收

`implementation_uncompiled`

本批次只形成代码、执行格式化及仓库源码和文档门禁，尚未编译、迁移或验证真实历史补发。

## 已形成代码

- V150 记录实时入队与历史补发来源，以及补发请求时间。
- 按 App 所有者、`app_id`、终态序号和订阅事件筛选查询唯一终态事件真源。
- 单批最多 100 条，以确定性投递 ID 幂等入队，并返回补发进度摘要。
- PC 门户可输入起始序号和单批数量，展示序号与历史补发来源。

## 统一回归必须验证

- V149 到 V150 升级、重复迁移和既有投递默认来源。
- 不同 App、不同所有者和不同订阅之间无法读取或补发对方事件。
- 成功/失败筛选、0/1/100/101 边界、空页、分页和重复请求计数。
- 补发与实时触发器并发时只保留一个确定性投递。
- 订阅停用、验证失效、App 停用、密钥轮换和历史补发之间的失败关闭行为。
- PC 类型、数字输入、按钮状态、结果提示和小屏布局。
