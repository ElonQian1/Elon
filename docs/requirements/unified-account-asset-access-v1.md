# 统一账号与只读资产授权 V1

## 用户结果

用户于 2026-09-05 要求优先实现：明确授权量化读取本人资产后，在授权有效期内
刷新和翻页无需逐页返回主 APK；可以查看及撤销授权。Android、Web 与量化 AI
客户端消费同一版本化正式资产投影，各自持有独立凭据。统一的是主身份和数据真源，
不是共享登录 token 或建立第二份余额。

当前正式 ESK 原生进度 V1 保持其已有约束，作为迁移期间入口。旧 Paper 原生版本
仍按既有决定退役，不恢复兼容。原任务继续当前 0.5 APK 发布，本任务拥有新增授权
模块与合同；共同入口切换、数据库迁移编号及后续发布必须协调。

## 真实来源与边界

- 身份复用主项目 users/sessions。客户端不得传用户 ID、邮箱或余额来认领身份。
- 正式总量、占用、可申请量和申请进度复用主项目同一事务内的正式账本扫描。
- 原 Paper grant/投影和正式资产授权使用不同版本、路由和凭据空间。
- 新权限只允许最小身份、正式资产摘要与申请进度读取；不授权登记、卖回提交/取消、
  支付、申购、交易、签名、管理员操作或改变用户角色。
- 原主会话退出/撤销/到期、用户停用、应用授权撤销或到期后，后续读取失败。
  读取快照建立时为线性化边界；已经合法发出的数据不能被远程追回。
  此处会话退出指服务器结束该会话；现有 APK 仅清本机登录的旧退出行为不等于服务器撤销。
  该共享退出入口的迁移须另行协调并验收，不能用本批服务器测试宣称已覆盖本机换号。

## 授权与兑换

- 仅注册的官方量化客户端可请求 V1，区分 Android、Web 和 AI；client_id 不是秘密，
  不能单独作为调用者身份或权限证明。
- 首次同意界面显示当前主账号、客户端、只读范围、期限和撤销入口。
- 主项目真实有效会话确认后签发短期一次性授权码；不接受静态 admin/owner 或虚拟用户。
- 授权码绑定 client_id、精确回调地址、随机 state、PKCE S256 challenge、原会话哈希
  和绝对过期。兑换原子消费，校验 verifier 和全部绑定；错误不能换成更宽权限。
- 原主 token 不导出、不进入授权记录；code/token 只保存哈希。禁止把主 token 或
  委托 token 放入 URL、日志、浏览器持久存储、截图或模型上下文。
- V1 不提供 refresh token。授权及读取凭据最多一小时，并受原登录会话剩余期限限制；
  到期重新明确授权，不能由客户端续期。后续延长须单独设计轮换与撤销。
- 凭据验证只发生于新只读资源路由。不得修改全局 authenticate_token 或原写接口，
  使受限凭据成为主登录会话。

## 统一读模型

- schema 为独立版本，包含当前应用内稳定 subject、client_id、授权期限、来源和
  数据快照标识。不同主用户不得因姓名或邮箱相似合并。
- ESK 金额使用六位精度的整数字符串；total = reserved + available，由服务器计算。
- 申请列表只含最小标识、金额、submitted/canceled 状态和时间；不包含付款材料、
  审批人、条款确认、幂等键或原始写请求摘要。
- 摘要与进度来自同一已验证快照；游标绑定账号和完整快照，不能决定查询对象。
  变化返回明确的 snapshot_changed，客户端从第一页重新读取，不跨快照累加。
- profile、摘要与进度按枚举 scope 控制；未知 scope、查询字段与版本拒绝。
- GET 不更新授权、延长会话或生成账本事件，响应及错误均 no-store。

## 客户端和传输

- Android 使用可信主 APK 的原生同意页或系统浏览器；不导出主凭据到量化 WebView。
- Web/AI 通过明确授权的各自凭据读取。Web 只在内存保存本次受限凭据；关闭会话、
  退出、换号、授权失效时清理；AI 工具在受保护运行时持有凭据，不作为工具文本返回。
- 公网 HTTP 不承载授权码兑换、委托 token 或私人资产。HTTPS 校验保持开启，
  不信任客户端自报 Forwarded 头。开发 loopback 例外须限定在本机连接。
- 当前公开 HTTP Paper 预览保持原样；未配置可信 HTTPS 入口时，新功能显式不可用，
  不用同源、PKCE 或签名 APK 冒充传输加密。
- 请求失败、过期或换号清空旧资产；网络错误不能显示成零余额。

## 验收

1. 有效主用户明确同意、正确 PKCE 兑换一次，连续刷新/翻页仍为同一主账号。
2. 错 verifier/client/redirect/state、旧码、重复与并发兑换均拒绝；不接受权限扩张。
3. 应用授权撤销、原会话撤销/过期/换属、用户停用、授权到期及服务器重启后均正确失效。
4. 授权和正式账本在同一 SQLite 读取事务复核；覆盖先鉴权后撤销的竞态，不能只检查 HTTP。
5. 两个用户/客户端、分页摘要变化、合法零额和大整数、页外账本损坏分别验证。
6. 受限 token 不能调用原主会话、管理、卖回提交或取消路由。
7. Android/Web/AI 共用固定 JSON 向量，拒绝版本漂移和不一致金额；客户端能清理失效数据。
8. 合成测试、本机 HTTP、浏览器、APK 构建、生产 HTTPS、发布与本人验收分别留证。

## 交付与迁移

先新增合同与授权服务，保留旧入口；新客户端通过验证后再协调切换。新增表不迁移资产、
不改用户归属、不回填 Paper；不能把本批授权功能验收描述为真实余额入账或资金操作。
Feature Registry 通过工具登记；工具不可用记录待登记，禁止手改注册表。
状态以当前代码和测试证据为准，本需求不表示功能已经实现或部署。
