# 创建准备动态规则检查交付

需求：[动态准备检查](../requirements/android-binance-create-validation-v1.md)。原创建只检查合约基础过滤器、身份和windowCount，未把动态格数/最低保证金用于准备；新`BinanceCreateRuleCheck`复用上一批参考服务，在原准备前完成精确校验。主服务不持有新的产品UI。

检查绑定账号、请求、合约、当前文档和观察时间；数量超界、区间过窄、保证金不足或动态结果缺失时不给准备资格。30秒有界轮询不重启读取，取消和替换请求使迟到回执失效。原会话在结果返回时再核对账号/文档，准备还不能超过参考有效期。原用户确认、持久化幂等及未知结果查询保持；没有修改交易适配器请求体。

主Debug编译及77项创建/宿主测试通过，其中10项新增覆盖精确最低额相等/不足、动态数量边界、异常结果、过期、取消、替换、超时及准备参考有效期。计算公式/JS适配器未修改，复用上批336个官网源码向量、52项JS回归证据；不能称本批已在本人账号运行。

量化0.7.28(45)配套修复idle阶段隐藏服务错误信息的问题，330项Debug、官方Android合同和完整仓库验证通过。双方保持V2/V1消息格式；需要一起更新以获得可见的失败提示。正式发布身份随后由发布脚本及服务器回执记录，构建与实际装机分开。

当前ADB清单为空，设备、原账号动态数据和官网同参数结果仍未验收。下一步原签名覆盖安装双包，验证数量越界、最低额不足/相等、检查中编辑、过期恢复与确认摘要；这些准备检查不需要提交交易。真实创建仍按用户H02最终确认后回读，不由AI代点。
