# 开放商业消费者内部回执来源筛选 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- 默认关闭的来源要求请求字段和稳定响应枚举。
- 能力候选层对 `integration_sync_receipt` 的精确筛选。
- 匹配原因、PC 复选框和结果条件标志。
- 请求指纹与排序凭证中的来源要求。
- 现有 Rust 直接请求夹具的默认兼容字段。

## 已验证

- 字段省略、显式关闭和显式开启保持稳定默认值；默认发现继续返回普通声明和内部回执来源。
- 同一商户同时存在普通声明、有效内部回执和能力版本失效绑定时，来源条件在能力选择前生效；接入停用和版本失效来源不会误命中。
- `require_current_declaration` 与内部回执要求四种组合得到独立结果，五种内置排序器均不改变来源资格。
- 来源要求进入响应、匹配原因、请求输入摘要和排序凭证规范负载；发现过程不写入业务表或审计表。

## 统一回归必须验证

- 字段省略、显式 `false` 和显式 `true` 的反序列化与旧结果兼容。
- 同一商户同时存在普通声明、有效内部回执和已失效绑定能力时的候选选择。
- 来源筛选与 `require_current_declaration` 四种组合的结果。
- 五种排序器、能力键、价格上限和候选数量边界不被改变。
- 筛选条件进入输入摘要和凭证负载，切换后摘要不同。
- PC 开关、结果标志、空结果和窄屏布局。
