# Windows 采集约束

最后更新：2026-07-09

## 一句话结论

Windows 采集必须显式、可见、可暂停、可退出，不能做隐蔽监控。

## 采集内容

MVP 允许采集：

- 当前屏幕截图。
- 前台应用名称。
- 前台窗口标题。
- 采集时间。

MVP 禁止采集：

- 键盘输入。
- 鼠标轨迹。
- 麦克风。
- 摄像头。
- 剪贴板内容。
- 浏览器历史。
- 文件内容扫描。

## 状态显示

应用必须清楚显示：

- 正在记录。
- 已暂停。
- AI 分析开启/关闭。
- 当前采集间隔。
- 最近一次采集时间。

## 暂停和退出

必须支持：

- 一键暂停。
- 一键恢复。
- 从托盘退出。
- 退出后停止所有后台任务。

## 多屏策略

MVP 推荐：

- 先支持主屏幕。
- 多屏用户显示提示。
- 后续再支持选择屏幕。

## 失败处理

- 截图失败不应导致应用崩溃。
- 连续失败应暂停采集并提示用户。
- 锁屏、远程桌面、权限不足都应给出可理解错误。
