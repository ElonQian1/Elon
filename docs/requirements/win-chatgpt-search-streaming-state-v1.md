# Win ChatGPT 搜索流状态同步 V1

## 用户问题

ChatGPT 官方页在搜索或工具调用阶段会显示“正在搜索 …”，随后通过紧凑增量流追加最终正文。
Win 原生聊天没有重建这组增量操作，又会把回合里的无障碍标题“ChatGPT 说：”序列化为正文，
因此生成中出现空回答或错误标题，最终正文只能等待 DOM 兜底。

## 范围

- 只交付 Win/Tauri ChatGPT 原生聊天链路；不修改 PWA UI，不新增独立聊天窗口。
- 复用现有官方 WebView、私有流观察、消息快照、富内容 AST 和原生消息组件。
- 重建官方紧凑流中有界的 `append`、`patch`、`replace`、`add`、`remove` 操作，仍只公开
  助手可见正文、公开引用和有界生成状态；工具代码、凭证和请求头不得进入 UI。
- 搜索、思考和工具调用作为流式进度状态显示；正文到达后在同一助手消息原位替换。
- DOM 兜底必须排除“ChatGPT 说：”等无障碍说话人标题和纯光标占位。

## 验收标准

1. 官方页显示“正在搜索 …”时，原生聊天显示对应的有界搜索状态，不显示“ChatGPT 说：”或空方块正文。
2. 紧凑流的连续文本增量在同一助手消息内逐步显示，完成补丁将消息推进为 `completed`。
3. 工具调用、思考内容和未知补丁失败关闭，不作为可见回答；公开引用继续通过既有清洗链路关联。
4. DOM 回退、普通完整帧、Google AI、历史快照、富内容卡和用户主动打开官网入口保持兼容。
5. 合成流测试、消息提取测试、TypeScript、PC 生产构建、Tauri 定向测试和 Win Web AI 门禁通过。

## 非目标

- 不复制 ChatGPT 官方 CSS 或整页 DOM。
- 不重放用户请求，不绕过登录、验证、地区或额度限制。
- 不发布 Android 或移动 PWA。
