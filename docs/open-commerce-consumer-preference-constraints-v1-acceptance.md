# 开放商业消费者偏好硬约束 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- 独立服务端硬约束验证与评估模块。
- 三个默认关闭的请求开关和响应回显。
- 城市、任一类别与全部标签候选过滤。
- 匹配原因、请求指纹和排序凭证载荷。
- PC 独立硬约束复选组件和结果标志。

## 已验证

- 三个开关默认关闭时，城市、类别和标签继续只参与软偏好排序，资料不完整商户不会被默认隐藏。
- 启用开关但对应偏好为空时失败关闭；字段缺失、类型错误或不匹配时排除商户。
- 城市、类别和标签忽略 ASCII 大小写；类别列表任一命中，标签列表必须全部命中。
- 三个约束可独立或组合启用，并与能力、价格、可信来源、声明期和排序器组合；完整组合只保留全部满足的商户。
- 条件进入响应、匹配原因、请求输入摘要和排序凭证，切换开关会改变输入摘要且发现无业务写入。

## 统一回归必须验证

- 未启用约束时保持原软偏好排序结果。
- 启用约束但对应偏好为空时失败关闭。
- 字段缺失、字段类型错误、大小写差异、部分匹配和完整匹配。
- 类别列表任一命中与标签列表全部命中的差异。
- 三个约束互相组合，并与能力、价格、来源和排序器组合。
- 条件进入输入摘要与排序凭证，切换后摘要改变。
- PC 复选项、服务端错误、结果标志和窄屏布局。
