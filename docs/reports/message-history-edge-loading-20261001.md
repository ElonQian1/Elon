# 聊天历史上翻修复

## 根因与改动

APK、PWA、Win 的好友/群聊已有游标分页和手动按钮，但没有上翻触边自动读取。
因此当前窗口到顶不会自动显示更早消息；这不证明服务端消息缺失。

三端增加用户手势触发的顶部预取，仍每页 50 条，APK/PWA 保留最多 150 条，
Win 保留最多 300 条。程序布局和阅读锚点恢复不触发全量扫描，手动按钮继续可用。
历史请求与同步串行；同步结束后保留用户排队的历史方向，不被下一轮同步覆盖。
重复手势在读取中合并，失败保留内容并允许重试；前插后按消息 ID 与相对位置恢复。
会话关闭取消触边监听的待执行动作，各客户端保留原有账号/会话响应隔离。
