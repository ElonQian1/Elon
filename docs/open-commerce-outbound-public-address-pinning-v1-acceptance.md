# 开放商业 HTTPS 出站公网地址固定 V1/V2 验收

## 当前状态

`implementation_compiled_offline_policy_verified_v2`

V2 已取代 V1 的单地址固定实现。2026-08-15 完整 `elon-server` 测试目标编译通过，
离线回归验证了统一公网地址分类、DNS 超时失败关闭、原始答案数量上限、全部安全答案
固定、禁用环境代理和禁止重定向。当前证据不解析真实公网 DNS，不建立真实公网 TLS，
也不执行真实 Webhook 投递。

## 已形成代码

- 共享模块依据 V2 策略检查全部原始地址，并拒绝任一私网、转换或特殊用途结果。
- DNS 查询固定三秒超时、最多接收 32 个原始答案；空结果、第 33 个答案和端口漂移
  均失败关闭，去重不能绕过原始数量限制。
- 全部地址验证后按 IPv4 优先确定性排序并交给 `resolve_to_addrs`；客户端禁用环境代理
  和重定向，原始域名继续承担 URL、Host、TLS SNI 和证书身份。
- App 域名 challenge、Webhook challenge 和每笔真实 Webhook 投递共用相同边界。
- 实际 Webhook 投递每次重新解析；不安全目标记为稳定错误并停用订阅。

## 统一回归必须验证

- IPv4、IPv6、IPv4-mapped IPv6、混合公网/私网、多公网地址和空解析结果。
- 回环、RFC1918、链路本地、共享地址、文档网段、基准测试、组播、保留、ULA、6to4 和 NAT64 边界。
- DNS 检查与连接地址确实一致，TLS SNI 和证书主机校验仍使用原始域名。
- 禁用代理、禁用重定向、连接超时和总请求超时。
- Webhook challenge、实际投递、重试、死信和自动停用状态。
- 域名验证白名单与 Webhook 白名单继续独立生效。

## 仍未完成

- 多公网地址故障切换的真实网络行为和经过限制的业务重试策略。
- DNSSEC、DoH、解析结果缓存、网络级 egress 防火墙和独立出站代理。
- 真实公网 DNS、TLS、Webhook 投递、网络变化与并发压力验证。
