# 开放商业消费者内部回执年龄筛选 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- 可选最大内部回执年龄秒数字段和有界服务端校验。
- 基于单次发现时刻与 RFC 3339 回执完成时间的候选过滤。
- 缺失、非法和未来时间失败关闭。
- 来源要求派生、条件回显、匹配原因、请求指纹和排序凭证载荷。
- PC 分钟输入与结果标志。

## 已验证

- 服务端接受 1 秒和 365 天，拒绝 0、负数及超过 365 天；省略时不派生内部回执要求。
- 动态 SQLite 夹具验证近期、过期和未来回执；固定时钟领域测试验证刚好命中、刚好超时、缺失和非法时间失败关闭。
- 普通声明、能力版本失效来源和接入停用来源不会命中年龄条件；厂商、数据域、声明期、能力 Key、价格与五种排序器可组合。
- 最大年龄进入响应、匹配原因、请求输入摘要和排序凭证规范负载，改变阈值会改变输入摘要。

## 统一回归必须验证

- 省略、1 秒、365 天、0、负数和超过 365 天的边界。
- 刚好命中、刚好超时、未来时间、非法时间和缺失时间。
- 普通商户声明、有效内部回执和失效来源绑定。
- 与厂商、数据域、声明期、能力键、价格上限和五种排序器组合。
- 条件进入输入摘要和凭证载荷，切换条件后摘要改变。
- PC 分钟换算、错误提示、结果标志和窄屏布局。
