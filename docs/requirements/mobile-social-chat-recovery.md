# APK 与移动 PWA 社交聊天缓存及恢复

## 现状与范围

前轮 Windows 的持久缓存、超时与前台恢复已经交付；APK 和移动 PWA 使用独立代码，不能把 PC 修复当作三端完成。此次仅修 APK/PWA 的群聊及好友聊天读取、缓存和生命周期恢复，保留发送、修订历史、文章、群 AI、通知和媒体能力，不自动重发消息。

已定位：APK 消息仅有内存 Map，待发状态阻断轮询，发送回执在切换后被丢弃，读取可重叠且超时长；PWA 仅有网络加载，每次轮询重建整个消息 DOM，无 visibility/pageshow/online 恢复，WebSocket OPEN 不代表连接仍有效，列表等待全部请求才更新。

## 完成条件

1. 已访问会话和目录按服务器、账号持久化为有界缓存；再次打开先展示缓存，同时后台核对服务器。首次无缓存有明确加载、空状态或错误，不能无期限白屏。
2. 读取使用有界超时、同作用域请求合并，旧请求不能覆盖新会话、新账号或新版本。临时失败保留缓存，权限拒绝清除对应可见缓存；退出清理本任务缓存。
3. APK 恢复前台立即核对消息，暂停时取消旧读取；待发不阻断接收，切换会话后发送回执仍正确结束旧会话待发状态。
4. PWA 前台、pageshow 与联网恢复触发消息/目录刷新并更换失效推送连接；后台读取不能标记未读。WebSocket 失败时轮询仍能独立工作。
5. 未变化消息不重建 DOM，新增/编辑/撤回正确呈现；缓存不让旧修订覆盖新修订；阅读位置保持，媒体不因无变化轮询反复加载。
6. 编写隔离场景回归，包含超时、迟到响应、待发、进程/页面重载、账号切换、存储异常；完成 APK 构建与正式发布、PWA 正式发布和线上只读身份核对。真实用户设备网络场景未实测时明确报告。

## 所有权与恢复

Android 新增独立缓存和读取调度模块，改动聊天/列表入口及认证退出清理；PWA 新增恢复模块，缩减巨型模板中的旧读取编排。前轮 PC 社交能力、并行文章系统和后台通知发送策略保持原所有权。

无服务端消息协议或数据库迁移；缓存只是加速展示，服务器仍为权限及消息内容真源。网络不明时不自动重放发送、编辑、撤回或 AI 请求。
