# 开放商业消费者声明期筛选 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 默认关闭的请求字段及稳定响应枚举。
- 能力候选层的 `current` 精确筛选。
- 匹配原因、结果页筛选标志和 PC 复选框。
- 请求指纹与排序凭证中的筛选条件。
- 三处现有 Rust 直接请求夹具的默认兼容字段。

## 统一回归必须验证

- 字段省略、显式 `false` 和显式 `true` 的反序列化及结果兼容性。
- 同商户多能力分别为 `current/stale/unknown` 时的候选选择。
- 指定能力键与未指定能力键时的筛选顺序和空结果。
- 五种排序器、50 条返回上限和 100 个目录候选上限不被改变。
- 筛选开关进入输入摘要和凭证负载，切换后摘要不同。
- PC 勾选、结果标志、空结果和窄屏布局。

## 未完成

- 本批所有编译、接口、凭证、兼容性、浏览器和 UI 验证。
- 基于真实外部同步回执的来源筛选。
- 商户过期提醒、自动暂停、消费者自定义时间阈值和联邦策略。
