# UI 与交互任务

本文件用于界面、交互、样式、布局、移动端页面和可视状态相关任务。

## 设计原则

- 先服务用户的主要工作流，不把功能藏在难发现的位置。
- 页面要有清楚的信息层级，常用操作可直接触达。
- 文字必须适配移动端宽度，避免按钮、标签、卡片和列表项溢出。
- 视觉风格优先跟随项目现有设计系统。

## 状态覆盖

UI 改动至少考虑：

- 加载中
- 空数据
- 成功
- 失败或无权限
- 离线或服务器不可用

## 实现注意

- 图标、按钮、输入框、开关、标签、列表、弹窗等控件优先使用项目已有组件。
- 不为了装饰新增难维护的布局层级。
- 改动前后检查关键页面在小屏和常见宽屏下是否可读、可点、不卡住。
