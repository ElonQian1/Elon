# UI 产品约束

最后更新：2026-07-09

## 一句话结论

UI 要让用户掌控记录行为，不能让用户猜工具是否正在截图或上传。

## 必须有的页面

- 今日时间线。
- 日报预览。
- 设置页。
- 隐私与数据页。
- AI Provider 状态。

## 必须有的控件

- 开始记录。
- 暂停记录。
- 退出应用。
- 删除当天数据。
- 排除应用管理。
- AI 分析开关。
- 截图间隔设置。

## 时间线规则

每条时间线至少显示：

- 时间段。
- 应用。
- 分类。
- 摘要。
- 置信度状态。
- 是否计入日报。

用户必须能：

- 编辑摘要。
- 改分类。
- 删除记录。
- 不计入日报。

## 日报规则

生成日报前必须预览。

日报支持：

- 编辑。
- 复制 Markdown。
- 保存 `.md`。

不能默认自动发送给第三方平台。
