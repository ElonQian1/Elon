# Win ChatGPT 客户端图表组件 V1

## 目标

ChatGPT 同一个行情问题可能返回压缩金融组件，也可能返回
`client_defined_widget / charts_widget_v2 / recharts-json` 图表。Windows 原生聊天必须同时承接两种
上游结构，并在一龙消息流中显示真实折线图，不再把后一种退化成标题、坐标文字或“交互内容”。

## 范围

- 仅修改 Windows 共用 ChatGPT Web 适配资产、Tauri 清洗边界和 PC 原生渲染器；不改变 PWA。
- 被动解析当前官方回答流中已经返回的结构化图表记录，不重放或增加生成请求。
- 将上游图表转换为 `yilong.rich-content.v1` 的 `chart` AST；React 不直接依赖上游私有字段。
- 仅接受折线图、最多 4 条序列、256 个点以及有界标题、说明、标签和数值。
- 保留现有压缩金融卡片、正文、引用、缓存、官方页回退和同轮回答去重。

## 验收标准

1. 分段到达的 `charts_widget_v2` 在数据完整后生成一个 `chart` 富卡，图表标记 JSON 不进入正文。
2. Win 原生 UI 显示标题、说明、图例、坐标范围、首末时间和真实 SVG 折线；未知图表类型失败关闭。
3. 同一用户问题仍只有一条助手消息；金融组件和客户端图表两条上游路线均可用。
4. 图表生产授权、Rust 清洗、TypeScript 运行时守卫和渲染器兼容清单一致。
5. 私有流测试、富内容合同、Tauri 定向测试、PC 生产构建和 Win Web AI 全量验证通过。

## 边界

- 不复制 ChatGPT 官方 React 组件、CSS 或脚本；只复现被授权结构的可见语义。
- 不读取或持久化 Cookie、Authorization、密码或请求头，不把原始响应上传或提交 Git。
- 正式官网标签仍保留完整交互；一龙缓存保存的是清洗后的稳定 AST。
