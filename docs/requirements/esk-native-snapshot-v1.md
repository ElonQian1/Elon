# ESK Android 本机只读快照授权 V1

状态：实施中。范围：主项目与量化正式 APK，不改变服务器、支付或发行状态。
承接：[首批用户路线图](esk-first-user-delivery-roadmap-v1.md)。

## 用户结果与限制

量化 APK 提供独立原生“我的 ESK”入口，用户在主 APK 确认当前登录账户后，
查看该账户的 ESK 总量、可用、量化占用、卖回占用及修订号。
当前服务只支持 Paper 平台记录；不得标成真实已付款权益、链上币、可兑付现金或实时余额。
未授权、取消、未安装、身份不符、HTTP、失效和协议错误都显示原因及重试路径，不填零冒充成功。

## 信任与数据边界

- 使用 Android 显式 Activity result；双方核对正式包名、当前单一签名和最低版本，拒绝别名、调试包和缺失调用者。
- 量化发起随机 256 位 nonce；只在当前实例内保留一次待处理请求，最长 120 秒，不恢复到磁盘或 saved state。
- 主 APK 确认前后以及响应时核对调用者与当前登录会话；离开或重建确认页即撤销，不后台签发。
- 主 APK 仅向编译配置的 HTTPS 主服务执行一次只读 GET，默认 TLS 验证、禁止重定向、缓存、备用地址及任意 URL；HTTP 在读取凭据和发送前拒绝。
- 当前服务器没有该受保护入口时显示暂不可用，不改服务器配置，不回退 HTTP，不要求用户重新提供密钥。
- 返回固定版本的纯字符串字段 Bundle：协议、nonce、Paper/未上链标识、五个精确金额、修订、同机单调时钟采集/过期值。无 bearer、cookie、用户 ID、邮箱、授权 URL、URI 权限或动态错误详情。
- 金额为规范 6 位小数，使用整数检查总量=可用+占用、占用=卖回+量化；未知字段、错误类型、错 nonce、失效、超长和非法状态拒绝。
- 快照最多显示 60 秒，切后台、离开、刷新和实例重建立即清空；不写日志、磁盘、剪贴板、WebView、saved state。FLAG_SECURE 保护原生资产与确认页。
- 公共 HTTP 行情保持原样；网页无法模拟 Android 签名认证 IPC，仅说明原生入口的边界，不建立 JS bridge。

## 验收

1. 两仓库合同字段和验证向量一致；合法、负值、指数、舍入、双计、溢出、未知状态/字段/类型都测试。
2. 未安装/错误签名/旧版本/非预期 Activity 无法取得快照；消费 nonce 后重复回调无效。
3. HTTP 私有请求发送次数为零；HTTPS 不重定向，响应限制与会话变化失败关闭。
4. 原生入口编译与生命周期测试；公共行情原行为不变；无 WebView 凭据与数据接线。
5. 发布与真实设备两端验收单独报告；静态/单元/构建通过不冒充真实用户资产已开通。

## 不在本批

真实付款入账、发行/转账、兑换/卖回执行、QSHARE、币安交易、收益承诺、Sui 发布、服务器 HTTPS 部署。
本次只传余额快照；流水、来源逐笔展示及卖回申请明细留待独立版本，不用缺失数据伪造完成。
