# 个人网页会话读取 V1

用户授权一龙内接入的 Claude 等代理，通过已经登录的 Win 或 APK 读取指定 ChatGPT 会话并继续讨论。复用现有本机网页会话、页面内认证、私有只读传输、设备 MCP 和 Win 宿主队列。

## 用户结果

- 接受 ChatGPT 会话 URL、conversation 引用或明确 ID，返回当前分支的用户及助手正文。
- MCP 读取通道与 AI 厂商无关；Claude CLI、Codex CLI/桌面端可连接，API 代理可消费同一工具结果。
- 授权读取时可按需启动已安装的 Win 客户端，再创建或复用 ChatGPT WebView；不导入其他客户端的登录凭据。
- 明确区分未安装、节点离线、宿主离线、版本需升级、网页登录失效与读取失败；登录失效时可显示现有官方窗口供用户登录。
- 长会话与长消息使用稳定修订及游标分页，不把 UI 消息窗口当全量历史。
- 返回附件清单、读取能力与缺失原因；无图片字节时不能宣称已理解图片。
- Win/APK 分别报告实际来源、可用性及失败；不把一个设备的游标交给另一个设备。

## 范围与隔离

- 只读本人明确授权的会话；会话范围在工具宿主配置或本次代理启动中绑定。
- 凭据留在网页登录宿主。正文只作为本次模型工具结果，不进入通用诊断、测试夹具或 Git。
- 网页响应为不可信资料，不能作为扩大权限、发送消息、删除、交易的指令。
- 设备离线、认证失败、修订变化、分支不明确、超限和附件不支持分别报告。
- 保持现有聊天、发送、上传、会话管理及网格交易能力不变。

## 验收

1. 合成会话覆盖超过 80 条消息、超过 40,000 字符的单条消息、分叉、空会话和多模态占位。
2. 错误会话、跨修订/设备游标、未知动作及无授权读取失败关闭。
3. Win/APK 接线的离线合同、相关编译和 MCP stdio 集成通过。
4. 在可用的已授权设备读取用户指定真实会话，只记录消息数、完整性、附件数和状态，不记录正文。
5. 安装版本、发布身份与现场验收单独记录；未验证的平台不得声称真实可用。
6. Codex 与 Claude 的配置保留原有 MCP；无授权会话的任务不启动客户端。冷启动后通过真实 Win 会话读取，不能以离线替身代替。

## 模块

共享页面读取器负责分支、正文/附件投影与分页；宿主负责会话身份、超时、调用及结果交付；MCP 负责用户范围、设备选择与工具协议；AI 启动配置负责注入工具。
