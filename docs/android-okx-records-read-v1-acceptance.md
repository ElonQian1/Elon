# 欧易策略记录只读托管验收

范围为固定 records_v1 和 capabilities_v3，旧 V1/V2 不变。主 APK 持有本人仅 Read 授权，量化持有委托、成交委托、持仓产品页面；无交易写入、存储迁移或凭据外传。

2026-09-14 本任务 Android OKX 定向单元测试 31 项全部通过，包含新增 6 项记录测试：固定路径与注入拒绝、空/短页、游标推进、重复/超限、字段规范与原费用符号、策略/合约绑定、请求途中撤销/换号及旧读接口兼容。此证据来自 JVM/网络替身，未冒充真实欧易响应。

订单记录每页 50 条，非空短页继续提供游标；positions 无分页。持仓数量使用合约单位，成交委托只含累计成交信息，不推导逐笔成交、配对收益或净收益。

当前发布、手机安装、实际账号读取与视觉待验。旧无线地址连接超时，ADB 仅发现两台模拟器；保留登录资料，不重启 Win/Chrome。安装后先在量化欧易详情分别读取三类记录及翻页，再验收换号/撤销导致旧记录清除和后台恢复。API 资料仅由本人在主 APK 本机填写。

对应量化需求：docs/requirements/grid-okx-records-read-v1.md；线协议：docs/contracts/okx-host-records-v1.md。最终原签名发布身份补记在本文件，不能以测试通过替代装机与真实账户验收。
