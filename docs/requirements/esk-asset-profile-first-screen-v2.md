# ESK 资产个人中心首屏可见 V2

## 用户结果

登录用户打开一龙主 APK 的“我的”页面后，无需先越过整张 Token 额度卡或猜测隐藏入口，就能在个人资料卡下方看到“我的资产”和本人 ESK 余额。移动 Web 个人页保持相同顺序和语义。

## 本批范围

1. 把 ESK 资产区放在个人资料摘要之后、Token 额度之前，并增加清晰的“我的资产”标题。
2. Android 读取 `yilong.esk.asset_account.v2` 的精确字符串余额，分别显示总额、可用额、卖回申请占用、量化申请占用和全部申请占用。
3. 移动 Web 个人页同步展示同一服务端资产视图，保留登录、加载、失败和 Paper 状态，不把失败显示成零余额。
4. 用户仍可从现有 Android 卡片提交、查看和取消卖回申请；本批不改变服务端账本、定价或结算语义。

## 非目标与安全边界

- 不宣称 ESK 已上链发行，不显示主网合约地址、价格、法币估值或固定收益。
- 不把 Token 用量、节点积分、量化内部份额或客户端缓存当成 ESK 余额。
- 不启用真实购买、真实卖回付款、量化实盘、用户资金移动或收益分配。
- 项目广场的量化 APK 只有在独立正式签名工件上传后才能显示安装；源码、Debug APK 或主 APK 发布不能代替该回执。

## 验收标准

1. Android 布局静态合同证明 ESK 容器位于 Token 额度容器之前，并存在“我的资产”可见标题。
2. Android 数据模型与卡片分别使用 `reserved_for_sellback`、`reserved_for_quant` 和 `reserved_total`，金额继续按六位小数字符串校验。
3. 移动 Web 个人页在资料卡后显示 ESK 资产，使用带当前会话的 `/api/me/assets/esk`，并区分登录、加载、失败与成功状态。
4. Android Kotlin 编译和移动 Web 静态合同通过；发布状态、线上版本与真机截图分别报告，不以代码通过冒充用户已收到更新。
