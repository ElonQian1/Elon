# 开放商业消费者排序凭证 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已验证

- 默认关闭、由消费者显式开启的排序凭证请求字段。
- 只保存输入指纹、候选范围、策略元数据和有序公开结果的规范负载。
- 服务端 SHA-256 摘要及 `signed_by_operator=false` 信任边界。
- 每条有序结果固化当次公开目录的商户来源声明和新鲜度快照；二者均不构成外部平台证明。
- 省略或关闭时不生成，显式开启时生成规范 JSON 与其精确字节 SHA-256。
- 搜索词、App 身份和偏好明文不进入凭证；输入条件只形成 SHA-256 指纹。
- 声明期、来源、价格、能力与偏好条件进入指纹和规范负载，切换条件会改变指纹。
- 有序结果携带公开版本、价格、来源与新鲜度快照；候选范围和计数与普通响应一致。
- 凭证固定为未签名、非付费、非全网穷举，发现读取不持久化凭证或产生业务写入。
