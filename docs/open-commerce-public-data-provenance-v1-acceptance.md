# 开放商业公开数据来源与新鲜度声明 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 公开能力的商户声明来源结构与固定未外部核验标志。
- 依据声明更新时间和有效秒数派生的 `current`、`stale`、`unknown` 状态。
- 商户发布表单的新鲜度声明输入及已发布能力摘要。
- 消费者发现结果的来源、新鲜度和商户声明提示。
- 排序凭证有序结果中的来源与新鲜度快照。
- 无数据库迁移、无真实平台适配器、无外部回执关联。

## 统一回归必须验证

- 有效秒数为零、负数、极大值以及合法短期和长期值的服务端边界。
- 合法 RFC 3339、非法时间、当前边界前后和时区偏移的 `current/stale/unknown` 结果。
- 三种已支持处理器与未知历史处理器的来源映射。
- 目录 HTTP、MCP、消费者发现与 PC TypeScript 对新增字段的兼容性。
- 排序凭证服务端摘要、浏览器摘要和下载负载包含完全相同的来源与新鲜度快照。
- 商户和消费者 PC 在桌面、窄屏及长标签场景不重叠、不溢出。
- 旧调用、授权、计量、排序顺序和目录发布撤回语义不受新增只读字段影响。

## 未完成

- 本批所有编译、接口、时间边界、浏览器和 UI 验证。
- 能力与连接器同步回执、外部平台签名或第三方证明的绑定。
- 过期能力自动降权、下架、告警或调用阻断策略。
- 运营方签名、可信时间戳、跨运营方来源验证和反虚假声明治理。
