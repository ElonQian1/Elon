# Windows、APK 与 PWA 六平台聊天分享卡片完善

用户确认初次截图来自一直未关闭的旧页面；更新后截图已显示上一轮紧凑卡片。继续解决已更新 Windows 页面中币安分享未识别、平台与作者含义混淆、无封面卡片缺乏识别度、时间可读性和菜单留白问题。

## 范围与规则

- 复用此前整卡点击、原文保留和六平台预览。`app.binance.com` 为新增精确允许域，原始分享参数不改写；服务端仍逐跳验证公网 HTTPS、限制大小/时间、不带账号凭证。不给任意子域或自定义协议放行。
- Windows 卡片统一固定上限宽度、最多三行标题、右侧真实封面或明确的平台占位标识，底部平台与作者同时显示。占位标识不能冒充抓取封面；抓取失败仍可打开原文。
- B 站时间使用 `01:20` 等可读格式，并保留原始 `t`/`p` 打开参数。
- 右键卡片提供打开链接、复制链接及已有消息菜单。无编辑标记/通知时，更多按钮不单独撑高消息；鼠标悬停、键盘焦点、触摸仍可找到入口。
- 标题省略有完整标题提示。附加评论、多链接、附件与消息原文/历史不得丢失；复制消息与复制链接含义区分。
- 本轮重点验证实际 React `SocialConversation`，不再用 PWA 模板代替 PC 组件验收。固定数据/原生桥替身只证明组件合同，不能冒充真实 Tauri 或外站播放通过。

## 文件和验证计划

1. 共享呈现与平台适配：共享 `social_links.js` 与后端 `link_previews/policy.rs` 及 Android 对应策略、呈现与测试；三端卡片结构同步提交。
2. Windows 呈现：`SocialLinkCards`、聊天菜单/上下文、消息行及其样式；通过 desktop 选项保持移动卡片布局；共享标题/来源文案允许同步改善。
3. 提交可重放的 React 场景及浏览器验收脚本，覆盖六平台、有/无封面、标题来源、右键打开/复制、键盘、窄窗/缩放、修改后重绘、原文和草稿保留。类型检查、正式构建和线上身份各自留证据。

`pc_frontend_migration.target=pc-frontend`；路由 `/pc`；不触碰或重建旧 PC HTML。当前本机 Win 语义桥没有在线宿主，若仍无法验证真实窗口就明确报告；不发出无人执行的刷新/升级动作，不读取用户凭证，不清理账户数据。新版截图属于当前状态证据，不是像素目标。用户追加 APK 更新后截图：本轮同步 Android 卡片结构、平台标识、平台与作者文案、B 站时间及币安识别；PWA 同步。系统更新逻辑、置顶摘要横幅和原站登录/反爬机制不在本轮范围。Android 保留所有子 View 点击、长按、多选、回收和账号隔离；以 native View 测试与真实 React/PWA 像素分层验收。真机仅在最终候选已提交干净后，按用户反馈触发一次 30 秒准备，失败即延期。
