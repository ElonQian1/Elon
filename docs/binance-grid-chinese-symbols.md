# 币安网格中文合约兼容

量化用户要求先解决中文合约缺失。官方目录确认存在龙虾、币安人生、我踏马来了、牛来、哈基米 USDT 永续合约；主宿主的 ASCII 校验也会拒绝它们，不能只修改量化列表。

本批仅修改 Android 币安适配和主宿主合同：保持官方代码，统一允许 ASCII 大写字母、数字、汉字基本区和扩展 A；仍限制长度、USDT 结尾，拒绝分隔符、控制符、空白。公共行情 URL 按 UTF-8 编码。读取、报告、动态参数、管理草稿使用同一校验；上市不替代账户/目录/网格能力验证。

预计新增标识模块约 20 行、单元和适配器向量约 80 行；现有文件每处修改约 1–12 行。不改会话授权、最终确认、资金执行、Win 客户端和云同步 Rust 投影。真实手机页面由用户验收，代理不导航或截图。
