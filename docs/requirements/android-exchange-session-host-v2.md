# 主 APK 会话服务与量化产品 UI 边界 V2

## 已接受决定

用户 2026-09-09 明确要求按长期架构实现：量化 APK 持有选币、行情、创建/编辑表单、最终用户确认及策略管理界面；主 APK 托管登录和私有 API 运行环境，经正式受授权的业务合同服务量化。私有 API 需要有效会话和就绪文档，不要求用户看到主 APK 创建页。

本决定取代 `android-binance-grid-create-v1.md`、`android-binance-grid-manage-v1.md`、`binance-grid-symbol-picker-v1.md` 中把量化 UI/确认放在主 APK 的长期归属要求。旧要求只描述已发布兼容实现；账户隔离、精确数值、用户确认、幂等及未知结果核对不废弃。不得因为旧文件仍描述主 Activity 而继续在主项目扩建量化 UI。

产品和完整验收真源为[量化网格 UI 与会话服务 V2](https://github.com/ElonQian1/yilong-quant/blob/main/docs/requirements/grid-native-ui-session-host-v2.md)。本文件只定义主项目职责，不复制量化产品规则。

## 当前缺口

`BinanceGridCreateActivity` 持有表单及提交入口；`BinanceCreateSession` 经 WebView 内 `binance_grid_create_adapter.js` 请求固定私有接口。现有跨 APK Provider 主要提供读取，尚无已交付 V2 创建/修改/结束命令。跳页是现有耦合，不是私有 API 的固有限制。1.1.1612选币仍属待迁移实现，不能声称量化已拥有独立原生创建流程。

## 主项目范围

- 唯一登录存储、实际账号识别和会话运行环境；只在需交互登录/验证或用户主动请求时展示官网。
- 独立于产品 Activity 的会话服务：初始化主账号上下文、恢复绑定和授权、加载文档、确认适配器就绪并返回状态。不依赖手动打开主首页/创建页，也不承诺 Android 杀进程、网络故障或网站失效后常驻可用。
- 版本化能力、会话状态、读取、草稿准备、用户确认后命令和结果查询。精确 schema/传输与兼容向量须在写入口实现前双方验证；待实现方法不能标为支持。
- 固定业务适配器及可复核操作日志；主服务重新核验来源、账号、权限、精度、规则和准备摘要，不能信任调用端自报通过。
- Win 共用研究成果和合同，手机正常运行不依赖 Win 在线，不混用两端实际账号。

## 约束与复用

系统校验调用 UID、包、签名，授权绑定调用端、账号、交易所、用途、有效期及撤销。读写权限分开；一次操作绑定规范化草稿摘要、准备版本、nonce、一次性操作标识。量化可信可见页面的用户确认与主服务校验共同构成提交边界，不能仅凭 `confirmed=true` 下单。

新服务不输出 Cookie/CSRF/网页令牌，不提供任意 JS/URL/HTTP 代理。账号、文档、授权或参数变化使旧准备失效。写前记录状态，受理不冒充运行，中断/超时保持未知并查询核对，不盲目重发；迁移不清空登录或丢弃在途记录。

会话和网站适配器归主项目；量化 UI 归子项目。领域/校验/schema 按单一版本化真源生成或打包复用，不复制两套业务源码。公开行情和合约目录由量化行情模块复用，不因网页登录托管而搬入主 APK。

不因本次需求扩大交易权限或开放 AI/MCP 无人值守金融操作；无实际下单，Paper/sandbox/live、资金和密钥边界不变。

## 实施与发布约束

先拆服务和 Activity 并交付合同，再迁移量化选币/创建/最终确认，随后迁移管理。旧 Activity 仅兼容与必要修复，不接新增产品 UI；量化新默认入口不静默回退旧页面。退役前验证已支持客户端覆盖、在途恢复及功能等价。

每次编辑前列 UI/会话所有者、合同缺口和所需更新包。纯量化 UI 更新量化包；主服务更新主包；合同变更分别报告双方版本。不能用“主包已发布”代替量化界面交付。

## 验收

1. 主首页/创建/管理 Activity 未打开时量化可检查、准备、用户确认后执行并查询；需要登录/验证时完成交互后恢复原草稿。
2. 覆盖冷启动、进程回收、旧版本、不支持能力、换账号、撤销/过期、重复请求、迟到/未知结果；重连不重发交易。
3. 原参数和真实读取能力不回退，凭据不跨 IPC；主项目不新增量化选币/策略管理产品 UI。
4. 合同测试、主包构建、量化集成、真实只读和用户交易分别取证；内部 WebView 就绪或主 Activity 可提交不等于新架构已打通。

本批仅接受长期需求，服务解耦及新合同未实现，已有能力按原路径保留；不宣称迁移或新 APK 已完成。
