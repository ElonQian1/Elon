Agent 自动化

APK 可以在任意 App 唤起悬浮球，让 AI 自动操作手机完成任务。网页版保留镜像入口和状态说明，不模拟 Android 原生权限。

○
步骤 1：悬浮窗权限
网页不可授权，请在 Android APK 中开启。
○
步骤 2：无障碍服务
网页不可开启，请在 Android APK 中进入系统设置。
开启路径：设置 -> 无障碍 -> 已下载的应用 -> Elon Speed -> 开启
○
步骤 3：悬浮球
请在 Android APK 中启动或关闭。
○
步骤 4：AI 链路（可选）
默认走服务器 CLI；高级配置请使用 APK。
如需自定义 AI（混元 / 通义 / DeepSeek / OpenAI）或备用服务器，进入 APK 的 Agent 高级配置。

悬浮球悬停在屏幕上，单击语音输入任务，双击文字输入。返回本页可随时关闭。
