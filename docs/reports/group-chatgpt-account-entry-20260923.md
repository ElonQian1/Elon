# 群聊 ChatGPT 接入入口

上一批生产群回复恢复证据保留在 [发送恢复验收](group-ai-send-recovery-20260922.md)，本批不重复研究或更改发送链路。

## 用户确认的目标

- 接入入口保留“接入我的 ChatGPT › / 聊天不耗算力，又可训练群聊记忆”。
- 最终群聊架构是每个账号内，每群独立 ChatGPT Project 和长期会话，不是每次临时分析。
- 当前临时执行器是未补齐的实现。生命周期合同与未完成项见 [群聊选区与项目绑定](../group-ai-selected-context.md)。

## 本批代码

- 群聊 ChatGPT 档位右侧增加接入入口，其他 AI 不显示。模式行按内容高度展开，离开群聊恢复原尺寸。
- 点击先展示费用、账号及记忆说明，再由用户确认进入本机官方 WebView 登录；不自动发送、上传群上下文或清空草稿。
- 登录专用页面可随时取消，明确账号证据到达后返回原群，不覆盖个人会话恢复地址。普通官网浏览及语音入口不改变返回行为。
- 状态仅被动订阅已有且通过文档令牌校验的快照。保留本机已知连接提示，不因未读到 DOM 或加载失败误报退出登录，也不为展示入口启动 WebView。
- 新增 `accountConfirmed` 独立于旧 `authenticated` 就绪启发式；输入框可用本身不能让登录流程成功。只接受明确个人账号入口或已有私有发送上下文验证证据，不向原生输出用户身份或令牌。
- 本机偏好只存三态枚举，不存账号、Cookie、会话内容。此状态不是服务端鉴权或一龙账号与厂商账号的绑定凭据；发送沿用现有实际鉴权。
- 接入说明明确长期群聊记忆尚待接通，记忆是上下文积累而非训练模型。“不耗算力”指不扣一龙工作 AI 算力，不承诺厂商所有功能无限。
- 入口保留用户指定原文，并直接显示“群聊记忆待接通”，避免只看到入口的用户误解当前能力。
- 移动 PWA 账号说明同步边界，浏览器与 APK 不共享登录状态。

## 验证

- Android 定向 41 项通过，XML 核验零失败、零错误、零跳过：账号与协议证据 7、群入口 3、Logo 2、官方入口 3、原协议 26。覆盖无输入框的已登录状态、游客输入框、旧协议、外域与缓存快照、明确登出、单次登录返回、取消保留草稿和 320/360dp 屏幕可用宽度。
- JavaScript 登录策略测试及适配器语法检查通过；源码规模与文档模块化门禁通过。登录证据测试曾发现仅凭旧就绪提示不能确认账号，已独立增加明确证据字段，不改变原聊天启发式。
- 真机官方登录未执行，不以单测替代用户账号登录验收。
- 本批不创建项目、不切换群分析至持久会话，不宣称长期群聊记忆完成。
