# Win 网页 AI 上线前原始响应研究 V1

## 阶段决定

一龙尚未正式上线，当前 Win 使用者均属于开发实测人员。本阶段 ChatGPT 与 Google AI 官方
WebView2 默认开启本机响应研究，不再维护单独的研究安装包。正式公开发布前必须重新评审默认值、
保留期限、用户告知和生产授权边界。

## 目标

旁路观察用户本来就发出的官方网页请求，保存原始 JSON、NDJSON 或 SSE 响应正文，帮助开发人员
复现流式组装、识别厂商富内容结构和编写版本化映射。研究采样不得为了取得样本重复发送生成消息，
也不得阻塞官网原请求或一龙聊天 UI。

## 范围

- 仅修改 Win/Tauri 官方 WebView2、PC 研究状态入口和对应测试；不修改 PWA。
- ChatGPT 观察当前会话生成流和会话详情；Google AI 观察同源 AI RPC 的文本、JSON 或流式响应。
- 使用 `Response.clone()` / XHR 完成事件旁路读取原请求的响应；生成类 POST 不主动重放，只有无副作用
  的 GET 才可在后续研究工具中显式重放。
- 原始响应以当前 Windows 用户本机文件保存到厂商 Profile 下的 `research-captures`，不上传云端、
  不写 Git、不进入普通日志；请求头、Cookie、Authorization 和请求正文不采集。
- 每条正文有大小上限，目录有数量、总量和 30 天保留上限；清除厂商本机会话时同步删除研究样本。
- 原始样本和 `yilong.rich-content.v1` 同时保留：前者用于研究与回放，后者仍是稳定、安全的原生
  渲染合同。原始厂商对象不得直接作为 React props 执行或渲染。

## 验收标准

1. ChatGPT 生成 SSE/JSON、会话详情以及 Google AI 同源 AI RPC 原响应可在不重复请求的情况下旁路采样。
2. 采样只接受受控 WebView 标签、固定厂商、固定 endpoint family、GET/POST、允许的响应格式与有界正文；
   任意路径、请求头、Cookie、Authorization、请求体和主窗口伪造调用失败关闭。
3. 原请求即使采样失败、超限、取消或宿主写盘失败也正常返回，不改变官网会话与流式消费。
4. 研究目录使用内容 SHA-256 去重，保存原始正文和不含正文的元数据；超过 30 天、256 MiB 或 256 个
   样本时从最旧样本开始回收。
5. PC 厂商选择器明确显示“上线前研究采样已开启”，并提供打开本机研究目录的入口；清除本机会话
   同步删除样本。
6. JS 契约、Rust 单元测试、Tauri 权限、用户浏览器回归、PC 构建和源码体积门禁通过。

## 非目标

- 不主动重放发送消息、生成回答、上传附件、登录、付款或其他有副作用的请求。
- 不把原始响应上传服务器、提交仓库、发送给模型或当作长期生产缓存。
- 不移除内部富内容 AST、Rust sanitizer 或 React 运行时门禁。
