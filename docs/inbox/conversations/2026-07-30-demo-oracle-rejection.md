# 跨设备文档测试与预言家 AI 议案状态修正

## 1. 测试发现

用户让另一台设备上的 Codex Desktop 读取项目文档。该代理把旧的“预言家 AI”功能议案理解成主要产品功能，说明静态入口没有准确表达当前决定。

## 2. 用户决定

用户明确说明：“预言家 AI”功能议案已经否决。项目不应继续把独立预言家角色、固定 Demo 预演阶段或专用路由描述为现行能力。

## 3. 文档治理要求

删除现行入口中的错误描述，同时保留一份权威否决决定。后续任何 AI 查询相关关键词时，应优先看到否决状态，不得从旧讨论、缓存或历史提交中恢复该功能。
