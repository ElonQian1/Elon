# 网格规则目录接纳 TradFi 永续合约

量化选币新增 TradFi。主 APK 的 BinanceGridMarket.parseRules 必须同时读取 `PERPETUAL` 和官方 `TRADIFI_PERPETUAL`，保留 TRADING、USDT 保证金/计价、有效价格和数量过滤。未知类型、交割和下架不得接纳。

保持精确价格校验、账号授权、私有参数检查及最终用户确认；目录出现不代表所有账号获准交易。本批不新增主产品 UI，不自动执行交易。

当前官方公开档位已有 BTC/ETH 150 倍。用户要求量化草稿默认实际最大档位，创建草稿、动态参考与 JS 适配器通用解析上界统一至 200；真实可用档位及账号限制继续由私有参数检查确认，不放宽金额和确认门禁。

验收：股票/ETF、商品和普通加密合约均可进入规则目录，未知类型/下架/非法 tick 仍拒绝；150 倍可准备而 201 倍拒绝；原签名发布及覆盖安装，用户验收量化入口。
