# 钱包只读授权过期恢复

修复主 APK 钱包授权页在账户确认超过五分钟后，按钮仍可点击却只返回失败提示的问题。量化 APK 继续拥有资产页面；主 APK 只托管会话和独立钱包授权。

## 行为与边界

- 授权页按账户确认的剩余时间设置一次本地到期回调，过期显示重新确认提示；不增加周期网络查询。
- 用户点击后若账户确认已过期，立即显示重新确认进度，并通过现有 WebView 身份接口请求一次更新。等待上限 31 秒，重复点击不续期、不重复请求。
- 只有已显示确认过的同一主应用用户、同一币安账户摘要与账户类型，才可在本次前台人工点击后完成钱包只读授权。
- 换号、错误、超时、后台、失去窗口焦点、重新打开、重建 Activity 或新 Intent 均不得沿用待完成点击。重新打开或只读刷新本身不产生授权。
- 完成前复核可信调用者、窗口焦点、nonce 所属 Activity 和最新账户状态；保留独立用途、撤销、持久恢复及原结果协议。
- 屏幕不导出账户凭据，不修改交易能力、持仓、订单或网格。

## 验收

1. 自动测试覆盖鲜活确认、到期、同账户恢复、主用户/账户/类型变化、重复点击、超时、错误和生命周期取消。
2. 通过钱包及宿主授权/状态回归，正式原签名 APK 构建发布与安装证据分别记录。
3. 手机重新进入授权页，用户最终点击后返回量化；读取各钱包状态与更新时间，并验证再次进入可恢复。未得到真实钱包响应不能宣称已打通。

## 实现范围

`BinanceWalletConsentActivity` 负责页面接线；新增小型 `BinanceWalletConsentGate` 管理单次人工意图；`BinanceWalletState` 暴露同源剩余时间。现有钱包 runtime、固定接口和量化结果合同继续复用。
