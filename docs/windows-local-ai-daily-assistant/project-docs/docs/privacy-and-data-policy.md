# 隐私与数据策略

最后更新：2026-07-09

## 一句话结论

截图是最高风险数据。默认策略是：用户明确开启才采集，分析后删除原图，只保存文字化结果。

## 用户必须知道

首次启动必须说明：

- 工具会在用户开启后定时截图。
- 如果启用云端 AI，截图可能发送给模型服务商分析。
- 用户可以暂停、排除应用、删除数据。
- 工具不是员工监控软件。

## 数据分类

| 数据 | 风险 | MVP 策略 |
|---|---|---|
| 截图原图 | 最高 | 默认临时存在，分析后删除 |
| 缩略图 | 高 | MVP 不保存 |
| 前台应用名 | 中 | 本地保存 |
| 窗口标题 | 中高 | 本地保存，可删除 |
| AI 摘要 | 中 | 本地保存，可编辑 |
| Markdown 日报 | 中 | 本地保存，由用户控制 |
| API key | 高 | 只存本机安全配置，不进日志和 Git |

## 排除应用

默认建议排除：

- 密码管理器。
- 银行、支付、财务软件。
- 私密聊天软件。
- 浏览器隐私窗口。
- 远程桌面。
- 医疗、法律、合同相关应用。

命中排除应用时：

- 不截图。
- 不调用 AI。
- 只记录跳过原因和时间。

## 删除策略

必须支持：

- 删除单条时间线。
- 删除某一天全部记录。
- 删除全部本地数据。

删除必须影响真实 SQLite 数据，不能只做 UI 隐藏。

## 日志策略

日志禁止写入：

- 截图路径的敏感文件名。
- API key。
- 完整窗口标题中的密码、Token、身份证号。
- AI 请求完整 payload。
- AI 原始图片内容。

可以写入：

- 错误类型。
- 时间戳。
- 模块名。
- 是否命中排除应用。
