# 币安命令页面重建交接

承接[会话服务边界](android-exchange-session-host-v2.md)和量化商业 Goal G05/G17/G24。创建、管理 Activity 重建会产生新的 operation；旧页面已失去事件连接，但主服务仍以旧 operation 拒绝新页面，尤其在请求已发送且 close 不释放时，只能等旧租约到期。本批补齐同一服务内的结果接续。

## 行为与不变量

- 只在既有固定 open 命令、同一协议版本、旧 operation 没有活动事件订阅且新 operation 有活动订阅时允许交接。UID/包/签名、账号、授权和业务请求校验继续由既有入口执行；订阅本身不是交易授权。
- 旧页面仍连接、新页面未连接、其他命令或不同管理协议版本均不触发交接。创建和管理继续互斥，不夺取兼容官网页面的独立槽位。
- 交接清除旧准备许可、摘要及未提交准备。正在提交、未知、已受理或待核对结果保留同一 attempt/state、session 回调及原本机日志；不关闭、重建或重发网络请求。
- 新 operation 取得后，旧 operation 的取消、查询、关闭或提交仍按现有身份校验拒绝，不能关闭新页面的会话。新页面对已有在途结果只查询和核对，不能恢复旧最终确认。
- 事件成员变化通知现有订阅者读取状态；旧页面稍后断开时可即时重新尝试 open，不增加周期查询或重载网页。

## 文件与验收

新增小型交接模块；创建/管理 Commands 与宿主事件接线保持组装职责。测试使用本地 Android 测试环境中的实际命令服务、真实事件订阅及实际 attempt/permit 状态，不连接真实交易所；增加仅测试使用的 Robolectric，复用量化已有版本。

验证旧页面仍连接拒绝、旧页面断开恢复、无新订阅拒绝、旧命令失效、旧准备撤销、各未决状态与日志/回调保留、管理版本不混用和成员变化通知。原有创建/管理/事件测试及主 APK 正式发布通过后，量化 0.7.54 可沿用原接口；主 APK 安装和真实双包读取单独验收。手机离线不得宣称实际接续已通过。

不增加新的 UI、MCP 交易动作、网站端点、凭据导出或最终金融操作。缺少 strategyId 的未知创建仍须在官网按原客户编号核对，本批不伪造交易所结果。
