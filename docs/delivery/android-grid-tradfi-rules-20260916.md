# TradFi 目录和最大杠杆兼容

`BinanceGridMarket`过去只接受PERPETUAL，导致量化选择股票或商品后主端找不到规则。现同时接纳官方TRADIFI_PERPETUAL，保留TRADING/USDT/tick/数量过滤。UI仍归量化。

公开brackets存在BTC/ETH150倍，创建草稿、参考和JS适配器旧125上界统一为200；私有规则、测试保证金2000上界、账号绑定和用户最终确认不变。不是按合约一律设200倍，也没有执行真实订单。

原生网格回归和既有JS替身套件通过；新增TradFi解析、150倍准备和201倍拒绝测试。量化目录/百分比工具独立发布，实际账户和像素由用户验收。

正式发布版本、源码SHA及安装身份在发布后追加。
