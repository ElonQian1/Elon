# 通用扫一扫 V1

用户任务：APK 与移动 PWA 能用相机或图片识别二维码；Win 工作台能右键识别图片二维码。
识别在设备本地进行。共用内容语义和验收样本，分别适配原生相机、浏览器相机和图片入口。

## 模块边界

- `shared/scan/`：Web/Win 共用内容分类、浏览器解码与相机生命周期；Android 用相同 fixtures 验证原生解析。
- Android `scan/`：相机预览、权限恢复、图库解码与结果操作。Activity 只编排。
- PC `features/scan/`：图片菜单、文件选择和结果对话框；保留既有消息菜单。
- PWA `scan_*`：移动扫码对话框、权限/HTTPS提示、好友搜索接入。

## 能力与限制

1. 相机默认后置；支持的设备提供手电筒与前后切换。切后台、关闭和选择图片时释放相机。
2. 系统选图无需相册全量授权；解码限制文件大小和像素，区分无结果、解码失败和权限问题。
3. 一张图片最多展示八个不同二维码。一次相机识别后暂停，用户可继续扫，不重复触发业务。
4. 结果覆盖一龙好友码、HTTP(S)网址、文本、电话、短信、邮件、位置、Wi-Fi、联系人。
5. 网址显示目标后由用户打开；电话只进入拨号器，邮件/短信只打开草稿；Wi-Fi/联系人可查看复制内容，不自动改网络或通讯录。
6. 自定义协议、脚本、文件地址及含凭据的 URL 不自动打开，保留为文本供核对。
7. 新好友码采用 `yilong://friend/v1/<account-id>`；兼容历史裸 32 位 ID。扫码只查找注册用户，不自动添加。
8. 游客设备 ID 不作为可添加账号；个人二维码页提示登录，保持已注册用户查找边界。
9. PWA 相机需安全上下文和浏览器授权；不支持、拒绝或无相机时仍可选图。
10. 不保存扫描历史，不上传原图或二维码内容；手动查找好友会发送目标账号 ID，打开链接按用户动作导航。

## 验收

- 三端使用同一内容样本验证分类、旧码兼容、恶意协议和超长输入。
- APK 运行验证相机入口/拒绝权限恢复/相册入口/暂停恢复/结果操作，并构建正式包。
- PWA 运行验证图片扫码、多码、相机释放、迟到权限回调、不安全上下文和失败提示。
- Win 右键图片和已有图片预览均可进入通用结果面板，保留复制/下载/引用等既有菜单。
- 发布分别验证 APK、PWA 静态资源、PC 前端版本；设备安装和用户验收独立记录。
