# 追踪管理 V4 接线验收

主服务已接入固定 V4 读取、准备与提交合同，量化负责编辑和最终确认。仅编辑已开启方向的停止追踪价格；方向开关与追踪网格区间重建仍待取证，不能据此关闭整个 G20。

## 实现

- 主 WebView 加载追踪规则与载荷模块。公开 exchangeInfo、标记价、最新价在有界后台线程读取；保留原始源时间，20 秒过期或规则缺失不能准备。
- 私有详情与固定公共 coef 在同一已授权网页读取。准备和提交重新核对账号、文档、完整基线与范围；只替换指定停止价，保留全部原保护、触发、投入与处理设置。
- 原生快照和草稿校验精确十进制及 tick。规则不可用时普通管理详情仍可显示；未知结果恢复不依赖公开行情可用。
- journal v5 只保存追踪目标指纹；兼容 v1–v4。旧客户端看到新版未决操作会要求升级后恢复，不清除记录。
- 提交前异步核验期间不再次生成确认凭据；取消、换页、文档变化后的回调不能恢复准备状态。主会话服务不打开产品 Activity。
- 未知能力方法返回明确 METHOD_UNSUPPORTED。量化只在这种情况回退；旧主包的通用 HOST_READ_UNAVAILABLE 无法证明方法不存在，须先升级主包，不将鉴权或损坏响应当版本回退。
