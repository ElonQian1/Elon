# 群聊议题拆分规则

## 拆分信号

- 时间间隔明显：连续沉默 45 分钟以上后出现新讨论。
- 关键词突变：上一段讨论产品发布，下一段讨论账单或部署。
- 参与人突变：主要发言人更换，且内容不再回应上一议题。
- 显式提示：成员说“换个话题”“下午说另一个事”等。
- 结论完成：上一议题已经形成结论或行动项，后续开始新事项。

## 合并信号

- 后续消息继续引用同一问题、同一错误、同一任务。
- 成员明确说“接着刚才那个问题”。
- 虽然跨时间段，但目标、参与人和关键词高度一致。

## 输出要求

拆分时给每个候选议题写：

- `topic_title`
- `start_message_id`
- `end_message_id`
- `reason`
- `confidence`
