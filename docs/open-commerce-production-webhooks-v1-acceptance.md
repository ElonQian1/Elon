# 开放商业环境绑定生产 Webhook V1 验收

## 当前状态

`implementation_uncompiled`

本批只形成代码、Rust 格式整理及仓库静态门禁，尚未编译、执行数据库迁移、启动工作器、访问真实回调地址或验证 PC 页面。

## 已形成代码

- V156 为订阅增加不可变环境，旧订阅保守迁移为沙箱，并重建按调用凭据环境过滤的终态事件触发器。
- 生产 Webhook 独立开关默认关闭，并同时依赖生产凭据开关和当前有效生产资格。
- 创建、验证、启用、签名密钥轮换、死信重试和历史补发均在服务层复核生产资格；关键状态转换在数据库事务内再次复核。
- 生产凭据撤销或轮换会原子停用生产订阅并终止未完成投递；凭据过期或 App、资料、域名、准入失效会在工作器领取周期失败关闭。
- 沙箱只接收旧调用与沙箱调用，生产只接收生产调用；自动入队、历史补发、死信重试和工作器结果读取使用同一环境边界。
- challenge 和事件负载 V2 返回环境；PC 可在创建时明确选择测试或生产，并在订阅列表查看固定环境。

## 统一回归必须验证

- V155 到 V156 的空库、历史库、重复迁移、默认值、约束、索引和触发器替换。
- 沙箱、生产、平台和旧调用对两类订阅的全部入队组合，以及跨环境历史补发和死信重试拒绝。
- 两个生产开关的开启、关闭、重启和投递中途变化；关闭时沙箱通知不得回归。
- 凭据签发、轮换、撤销、到期，以及 App 停用、资料修订、域名重验、准入暂停后的事务联动和队列清理。
- 创建、验证、启用、轮换密钥、重试和补发期间发生并发资格变化时的失败关闭。
- V2 challenge、事件 JSON、HMAC 原始字节、Node SDK 兼容、主密钥变化、公网地址固定、DNS 重绑定、TLS 和 HTTP 状态处理。
- PC 类型、环境选择、错误提示、一次性密钥、刷新状态、小屏布局和生产构建。
