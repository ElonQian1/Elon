# 社交外链卡片点击与呈现修复

修复六平台外链交付后的真实反馈：APK 公众号、小红书、抖音卡片嵌在浅色消息气泡内，正文链接重复显示；点击卡片文字无响应，只能点原始链接。微信截图为结构参考，不是本产品整屏像素目标。用户授权只读查询“杀蟑螂”群中的相关外链，不读取无关群聊或修改消息。

## 已确认事实与范围

- Android 消息长按绑定递归设置子控件 longClickable，卡片标题等子控件消耗普通点击；必须通过实际 View 事件验证。
- 独立公众号链接应呈现一张紧凑暗色卡片，含标题、可用封面、底部公众号来源；整卡含标题、封面、空白和来源均可点击。保留长按菜单和多选。
- 单独链接或完整可识别的平台分享口令收起重复 URL/口令及普通气泡背景；带评论、附件或多个链接时保留用户内容；原始消息数据库、编辑历史与复制内容不变。网站通用标题不得覆盖分享文本中已有的具体标题。
- APK、PWA 和 Windows 共享卡片保持布局一致，单独链接与混合消息都有回收/重绘恢复验证。
- 用户所给 `mp.weixin.qq.com/s/Tstly8myjypJzCbNraOUBg` 公开读取返回环境验证页，不可伪造标题封面或绕过验证。APK 阅读器加载文章后仅读取公开页面标题、公众号、封面 URL，回填有界、账号隔离的本机缓存；返回聊天恢复卡片。
- 不上传网页正文、Cookie 或网页凭证，不增加消息数据库字段；其他平台识别、播放器和来源卡能力继续保留。

## 编辑边界

复用 `sociallinks/`、共享 `social_links.js/css` 与既有消息绑定入口。新增小型 Android 卡片 View 和阅读预览模块，入口只接线；需要改变 PC/PWA 单链接气泡样式时只触碰相应社交消息组件。服务端抓取策略与认证边界保持现状。

## 验收

1. Android 实际 View 手势测试覆盖标题、来源、封面及卡片空白点击、长按、多选、退出多选后恢复。
2. 新旧消息绑定验证普通气泡恢复、独立链接无浅色套框，包含额外文字/附件时不丢内容。
3. 微信阅读元数据来源绑定、验证页拒绝、URL/图片校验、账号切换与缓存容量验证。
4. PWA 实际浏览器点击与截图覆盖元数据成功、抓取失败两种状态；PC 构建和共享脚本回归。
5. 用户反馈刚交付不正确，触发一次预算不超过 30 秒的真机准备；不可用如实延期，不反复安装/清理账号，不把固定样例当成真机验收。
6. 定向测试、正式发布、线上来源核验与项目统一收尾分别记证据。
