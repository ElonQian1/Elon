# 开放商业消费者偏好硬约束 V1 验收

## 当前状态

`implementation_uncompiled`

## 已形成代码

- 独立服务端硬约束验证与评估模块。
- 三个默认关闭的请求开关和响应回显。
- 城市、任一类别与全部标签候选过滤。
- 匹配原因、请求指纹和排序凭证载荷。
- PC 独立硬约束复选组件和结果标志。

## 统一回归必须验证

- 未启用约束时保持原软偏好排序结果。
- 启用约束但对应偏好为空时失败关闭。
- 字段缺失、字段类型错误、大小写差异、部分匹配和完整匹配。
- 类别列表任一命中与标签列表全部命中的差异。
- 三个约束互相组合，并与能力、价格、来源和排序器组合。
- 条件进入输入摘要与排序凭证，切换后摘要改变。
- PC 复选项、服务端错误、结果标志和窄屏布局。
