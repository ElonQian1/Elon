codex cli 支持语音识别吗？

支持，但要分清楚：**Codex CLI 现在有“实验性的实时语音模式”，不是一个完全稳定、正式文档主推的普通语音输入功能。**

我查到的情况是：

1. OpenAI 官方 Codex CLI 文档目前仍主要把 CLI 描述为终端里的交互式 TUI：可发送 prompt、代码片段、截图等；官方功能页列出的常用输入里没有把“语音识别”作为主功能列出。([OpenAI开发者][1])
2. 但 Codex 开源仓库的当前代码里确实有语音相关实现：`/realtime` 的说明是 **“toggle realtime voice mode (experimental)”**，`/settings` 是配置实时麦克风/扬声器。([GitHub][2])
3. 代码里还有一个功能开关 `realtime_conversation`，注释写的是 **“Enable experimental realtime voice conversation mode in the TUI”**，也就是 TUI 里的实验性实时语音对话模式。([GitHub][3])
4. Codex CLI 官方文档也说明可以用 `codex features list / enable / disable` 查看和启用功能开关，所以如果你本地版本支持，可能需要启用相关 experimental feature。([OpenAI开发者][1])

所以我的结论是：

**可以用，但更像“实验性实时语音对话 / voice mode”，不是稳定的“按住麦克风，把语音转成一段文字 prompt”的成熟 CLI 功能。**

你可以在 Codex CLI 里试：

```bash
codex features list
codex features enable realtime_conversation
codex
```

进入 TUI 后输入：

```text
/realtime
```

如果你的版本、系统、账号权限都支持，应该会启动实时语音模式；再用：

```text
/settings
```

配置麦克风和扬声器。

另外要注意平台问题：代码里本地麦克风捕获相关逻辑对非 Linux 平台有实现，而 Linux 分支里有一些空实现痕迹，所以 Linux 上可能不如 macOS / Windows 稳定。([GitHub][4])

如果你只是想“说中文，让 Codex CLI 收到文字”，更稳的方案是先用系统听写或第三方语音输入法，把语音转成文本后粘到 Codex CLI；如果你想尝鲜原生语音，就试 `/realtime`。

[1]: https://developers.openai.com/codex/cli/features "Features – Codex CLI | OpenAI Developers"
[2]: https://raw.githubusercontent.com/openai/codex/main/codex-rs/tui/src/slash_command.rs "raw.githubusercontent.com"
[3]: https://raw.githubusercontent.com/openai/codex/main/codex-rs/features/src/lib.rs "raw.githubusercontent.com"
[4]: https://raw.githubusercontent.com/openai/codex/main/codex-rs/tui/src/chatwidget/realtime.rs "raw.githubusercontent.com"

codex cli 支持语音输入， 那我要如何传递语音给 它？ 

可以做，但建议你不要把 Android 的音频直接喂给服务器上的 `codex` TUI `/realtime`。更稳的链路是：

```text
Android APK 麦克风
  ↓ WebSocket 二进制音频流：PCM16 / mono / 24kHz
Rust 服务器
  ↓ OpenAI Realtime Transcription，把语音实时转文字
Rust 服务器
  ↓ codex exec "转好的文字 prompt"
Codex CLI 在服务器项目目录里执行任务
  ↓
Rust 服务器把结果回传给 Android
```

原因是：Codex CLI 的 `/realtime` 目前更像“本机终端里的实验语音模式”。源码里 `/realtime` 的描述是 “toggle realtime voice mode (experimental)”，`/settings` 是配置本地 microphone/speaker；它不是一个公开的“网络音频输入端口”。([GitHub][1]) 代码里也能看到它启动的是本地音频采集 `VoiceCapture::start_realtime`，而不是从外部 socket 收远程音频；Linux 分支里本地音频启动还是空实现，所以服务器 Linux 上更不适合走这个方向。([GitHub][2])

OpenAI 官方文档里，Realtime API 的 WebSocket 方式适合服务器到服务器连接；而 Realtime transcription 正好支持“音频流进来、实时返回 transcript delta”，并且文档要求 `audio/pcm` 时使用 24kHz mono PCM，发送音频块用 `input_audio_buffer.append`，需要开始转写时发 `input_audio_buffer.commit`。([OpenAI开发者][3]) Codex 这一侧，用 `codex exec` 更适合脚本/自动化场景，可以把转好的文字作为 prompt 传进去；它会把进度打到 `stderr`，最终回答打到 `stdout`，并且可以显式设置 sandbox 权限。([OpenAI开发者][4])

下面是一个可落地的最小方案。

## 1. Android 和 Rust 之间的协议

你先不要传 `.mp3`，实时性会差。建议 APK 直接采集：

```text
格式：PCM16 little-endian
采样率：24000 Hz
声道：mono
WebSocket binary frame：每帧 20ms ~ 100ms 音频
WebSocket text frame：{"type":"commit"} 表示一句话结束，开始转文字
```

Android 侧大概这样：

```text
连接：wss://你的服务器/ws/voice
开始录音：不断发送二进制 PCM 数据
松开按钮 / 静音检测结束：发送 {"type":"commit"}
服务器返回：
  {"type":"transcript_delta","text":"..."}
  {"type":"transcript_final","text":"..."}
  {"type":"codex_result","text":"..."}
```

```rust
// src/main.rs

use anyhow::{Context, Result};
use axum::{
    extract::ws::{Message, WebSocket, WebSocketUpgrade},
    response::IntoResponse,
    routing::get,
    Router,
};
use base64::{engine::general_purpose, Engine as _};
use futures_util::{SinkExt, StreamExt};
use serde_json::{json, Value};
use std::{env, net::SocketAddr};
use tokio::{process::Command, sync::mpsc};
use tokio_tungstenite::{
    connect_async,
    tungstenite::{client::IntoClientRequest, protocol::Message as OpenAiWsMessage},
};

/// Android 发给 OpenAI Realtime 的命令。
enum OpenAiCommand {
    /// 一小段 PCM16 音频数据。
    Audio(Vec<u8>),

    /// 一句话结束，提交音频缓冲区，让 Realtime transcription 输出最终文字。
    Commit,

    /// 客户端断开，关闭 OpenAI WebSocket。
    Close,
}

#[tokio::main]
async fn main() -> Result<()> {
    tracing_subscriber::fmt::init();

    let app = Router::new().route("/ws/voice", get(ws_voice_handler));

    let addr: SocketAddr = "0.0.0.0:3000"
        .parse()
        .context("解析监听地址失败")?;

    tracing::info!("voice-codex-gateway listening on {}", addr);

    let listener = tokio::net::TcpListener::bind(addr)
        .await
        .context("绑定 TCP 监听失败")?;

    axum::serve(listener, app)
        .await
        .context("启动 Axum 服务失败")?;

    Ok(())
}

/// WebSocket 升级入口。
async fn ws_voice_handler(ws: WebSocketUpgrade) -> impl IntoResponse {
    ws.on_upgrade(|socket| async move {
        if let Err(err) = handle_android_socket(socket).await {
            tracing::error!("WebSocket 会话出错: {err:?}");
        }
    })
}

/// 处理一个 Android 客户端连接。
async fn handle_android_socket(socket: WebSocket) -> Result<()> {
    let (mut android_sender, mut android_receiver) = socket.split();

    // Android -> OpenAI 的命令通道。
    let (openai_cmd_tx, mut openai_cmd_rx) = mpsc::unbounded_channel::<OpenAiCommand>();

    // 后台任务 -> Android 的消息通道。
    let (android_out_tx, mut android_out_rx) = mpsc::unbounded_channel::<Message>();

    // 连接 OpenAI Realtime WebSocket。
    let (openai_ws, _) = connect_openai_realtime()
        .await
        .context("连接 OpenAI Realtime WebSocket 失败")?;

    let (mut openai_write, mut openai_read) = openai_ws.split();

    // 创建 transcription session。
    // 注意：
    // - Android 必须传 24kHz mono PCM16。
    // - language 默认 zh；可以用环境变量 TRANSCRIPTION_LANGUAGE 改。
    let language = env::var("TRANSCRIPTION_LANGUAGE").unwrap_or_else(|_| "zh".to_string());

    let session_update = json!({
        "type": "session.update",
        "session": {
            "type": "transcription",
            "audio": {
                "input": {
                    "format": {
                        "type": "audio/pcm",
                        "rate": 24000
                    },
                    "transcription": {
                        "model": "gpt-realtime-whisper",
                        "language": language
                    },
                    "turn_detection": null
                }
            }
        }
    });

    openai_write
        .send(OpenAiWsMessage::Text(session_update.to_string().into()))
        .await
        .context("发送 session.update 失败")?;

    // 任务 1：读取 Android 发送的音频和控制消息。
    let read_android_task = {
        let openai_cmd_tx = openai_cmd_tx.clone();

        tokio::spawn(async move {
            while let Some(msg_result) = android_receiver.next().await {
                match msg_result {
                    Ok(Message::Binary(audio_bytes)) => {
                        // Android 发送的二进制数据必须是 PCM16 little-endian mono 24kHz。
                        let _ = openai_cmd_tx.send(OpenAiCommand::Audio(audio_bytes.to_vec()));
                    }

                    Ok(Message::Text(text)) => {
                        // Android 在一句话结束时发送：{"type":"commit"}
                        if let Ok(value) = serde_json::from_str::<Value>(&text) {
                            if value.get("type").and_then(Value::as_str) == Some("commit") {
                                let _ = openai_cmd_tx.send(OpenAiCommand::Commit);
                            }
                        }
                    }

                    Ok(Message::Close(_)) => {
                        let _ = openai_cmd_tx.send(OpenAiCommand::Close);
                        break;
                    }

                    Ok(_) => {
                        // 忽略 ping/pong 等其他消息。
                    }

                    Err(err) => {
                        tracing::warn!("读取 Android WebSocket 失败: {err}");
                        let _ = openai_cmd_tx.send(OpenAiCommand::Close);
                        break;
                    }
                }
            }
        })
    };

    // 任务 2：把 Android 音频转发给 OpenAI Realtime。
    let write_openai_task = tokio::spawn(async move {
        while let Some(cmd) = openai_cmd_rx.recv().await {
            match cmd {
                OpenAiCommand::Audio(pcm_bytes) => {
                    let base64_pcm = general_purpose::STANDARD.encode(pcm_bytes);

                    let event = json!({
                        "type": "input_audio_buffer.append",
                        "audio": base64_pcm
                    });

                    if let Err(err) = openai_write
                        .send(OpenAiWsMessage::Text(event.to_string().into()))
                        .await
                    {
                        tracing::warn!("转发音频到 OpenAI 失败: {err}");
                        break;
                    }
                }

                OpenAiCommand::Commit => {
                    let event = json!({
                        "type": "input_audio_buffer.commit"
                    });

                    if let Err(err) = openai_write
                        .send(OpenAiWsMessage::Text(event.to_string().into()))
                        .await
                    {
                        tracing::warn!("发送 commit 到 OpenAI 失败: {err}");
                        break;
                    }
                }

                OpenAiCommand::Close => {
                    let _ = openai_write.close().await;
                    break;
                }
            }
        }
    });

    // 任务 3：读取 OpenAI Realtime 的转写结果。
    let read_openai_task = {
        let android_out_tx = android_out_tx.clone();

        tokio::spawn(async move {
            while let Some(msg_result) = openai_read.next().await {
                let msg = match msg_result {
                    Ok(msg) => msg,
                    Err(err) => {
                        let _ = android_out_tx.send(json_text(json!({
                            "type": "error",
                            "message": format!("读取 OpenAI 消息失败: {err}")
                        })));
                        break;
                    }
                };

                let text = match msg {
                    OpenAiWsMessage::Text(text) => text.to_string(),
                    OpenAiWsMessage::Binary(bytes) => {
                        String::from_utf8_lossy(&bytes).to_string()
                    }
                    _ => continue,
                };

                let value: Value = match serde_json::from_str(&text) {
                    Ok(value) => value,
                    Err(_) => continue,
                };

                let event_type = value
                    .get("type")
                    .and_then(Value::as_str)
                    .unwrap_or_default();

                match event_type {
                    "conversation.item.input_audio_transcription.delta" => {
                        let delta = value
                            .get("delta")
                            .and_then(Value::as_str)
                            .unwrap_or_default();

                        let _ = android_out_tx.send(json_text(json!({
                            "type": "transcript_delta",
                            "text": delta
                        })));
                    }

                    "conversation.item.input_audio_transcription.completed" => {
                        let transcript = value
                            .get("transcript")
                            .and_then(Value::as_str)
                            .unwrap_or_default()
                            .trim()
                            .to_string();

                        if transcript.is_empty() {
                            continue;
                        }

                        let _ = android_out_tx.send(json_text(json!({
                            "type": "transcript_final",
                            "text": transcript
                        })));

                        // 这里把最终转写文本交给 Codex CLI。
                        // 不要在读取 OpenAI 的循环里同步等待 Codex，避免阻塞后续音频事件。
                        let android_out_tx_for_codex = android_out_tx.clone();

                        tokio::spawn(async move {
                            let result = run_codex_exec(&transcript).await;

                            match result {
                                Ok(output) => {
                                    let _ = android_out_tx_for_codex.send(json_text(json!({
                                        "type": "codex_result",
                                        "text": output
                                    })));
                                }
                                Err(err) => {
                                    let _ = android_out_tx_for_codex.send(json_text(json!({
                                        "type": "error",
                                        "message": format!("Codex 执行失败: {err:?}")
                                    })));
                                }
                            }
                        });
                    }

                    "error" => {
                        let _ = android_out_tx.send(json_text(json!({
                            "type": "error",
                            "message": value
                        })));
                    }

                    _ => {
                        // 其他事件可以按需打印调试。
                        tracing::debug!("OpenAI event: {}", event_type);
                    }
                }
            }
        })
    };

    // 主循环：把后台任务产生的消息发回 Android。
    while let Some(msg) = android_out_rx.recv().await {
        if android_sender.send(msg).await.is_err() {
            break;
        }
    }

    // 客户端断开后，清理后台任务。
    read_android_task.abort();
    write_openai_task.abort();
    read_openai_task.abort();

    Ok(())
}

/// 连接 OpenAI Realtime WebSocket。
async fn connect_openai_realtime(
) -> Result<(
    tokio_tungstenite::WebSocketStream<
        tokio_tungstenite::MaybeTlsStream<tokio::net::TcpStream>,
    >,
    http::Response<Option<Vec<u8>>>,
)> {
    let api_key = env::var("OPENAI_API_KEY")
        .context("缺少环境变量 OPENAI_API_KEY")?;

    // 文档示例使用 gpt-realtime-2 建立 Realtime WebSocket；
    // transcription model 在 session.update 里指定为 gpt-realtime-whisper。
    let realtime_url = env::var("OPENAI_REALTIME_URL")
        .unwrap_or_else(|_| "wss://api.openai.com/v1/realtime?model=gpt-realtime-2".to_string());

    let mut request = realtime_url
        .into_client_request()
        .context("创建 OpenAI WebSocket request 失败")?;

    request.headers_mut().insert(
        "Authorization",
        format!("Bearer {}", api_key)
            .parse()
            .context("设置 Authorization header 失败")?,
    );

    request.headers_mut().insert(
        "OpenAI-Safety-Identifier",
        "voice-codex-gateway-user"
            .parse()
            .context("设置 OpenAI-Safety-Identifier header 失败")?,
    );

    let connected = connect_async(request)
        .await
        .context("connect_async OpenAI Realtime 失败")?;

    Ok(connected)
}

/// 调用服务器本机的 Codex CLI。
async fn run_codex_exec(transcript: &str) -> Result<String> {
    let workdir = env::var("CODEX_WORKDIR").unwrap_or_else(|_| ".".to_string());

    // 建议先用 read-only 测试。
    // 确认安全后再设置：
    // export CODEX_SANDBOX=workspace-write
    let sandbox = env::var("CODEX_SANDBOX").unwrap_or_else(|_| "read-only".to_string());

    let prompt = format!(
        r#"下面是用户从 Android 语音输入转写出来的文字，请你作为 Codex 在当前项目目录中执行。

要求：
1. 用中文回复。
2. 如果需要修改代码，请先说明计划。
3. 不要执行危险命令。
4. 用户语音转文字可能有错别字，请结合项目上下文理解。

用户语音内容：
{}"#,
        transcript
    );

    let output = Command::new("codex")
        .arg("exec")
        .arg("--ephemeral")
        .arg("--sandbox")
        .arg(&sandbox)
        .arg(prompt)
        .current_dir(workdir)
        .output()
        .await
        .context("启动 codex exec 失败，请确认服务器已安装 Codex CLI，并且 PATH 可找到 codex")?;

    let stdout = String::from_utf8_lossy(&output.stdout).trim().to_string();
    let stderr = String::from_utf8_lossy(&output.stderr).trim().to_string();

    if output.status.success() {
        Ok(stdout)
    } else {
        anyhow::bail!(
            "codex exec 退出码不是 0。\nstdout:\n{}\n\nstderr:\n{}",
            stdout,
            stderr
        );
    }
}
```

## 4. Android 端最小 Kotlin 思路

这个只是核心伪代码，重点是：**发送 binary PCM 音频，结束一句话时发送 commit**。

```kotlin
// VoiceStreamer.kt

class VoiceStreamer(
    private val webSocket: okhttp3.WebSocket
) {
    private var audioRecord: AudioRecord? = null
    @Volatile
    private var running: Boolean = false

    fun start() {
        val sampleRate = 24_000
        val minBufferSize = AudioRecord.getMinBufferSize(
            sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT
        )

        audioRecord = AudioRecord(
            MediaRecorder.AudioSource.MIC,
            sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT,
            minBufferSize * 2
        )

        running = true
        audioRecord?.startRecording()

        Thread {
            val buffer = ByteArray(minBufferSize)

            while (running) {
                val readSize = audioRecord?.read(buffer, 0, buffer.size) ?: 0

                if (readSize > 0) {
                    // 只发送实际读到的字节。
                    val chunk = buffer.copyOf(readSize)

                    // OkHttp WebSocket binary frame。
                    webSocket.send(okio.ByteString.of(*chunk))
                }
            }
        }.start()
    }

    fun stopAndCommit() {
        running = false

        audioRecord?.stop()
        audioRecord?.release()
        audioRecord = null

        // 告诉 Rust 服务：这一句话结束，可以提交给 Realtime transcription。
        webSocket.send("""{"type":"commit"}""")
    }
}
```

## 5. 什么时候不该用 `codex exec`

上面的方案是“一句话 → 一次 Codex 任务”。它简单、稳定，但每次都是一次新的 Codex 执行。要是你想做成长期会话，比如 Android 连上后一直和同一个 Codex thread 对话，应该考虑 Codex App Server 或 Codex SDK。官方说明 Codex SDK 适合把 Codex 集成到内部工具或应用里；App Server 提供 JSON-RPC 协议和 stdio / Unix socket / WebSocket 等传输，但 WebSocket 传输目前标注为 experimental/unsupported，远程暴露前必须配置认证。([OpenAI开发者][5])

我的建议是：

```text
第一版：Android 音频 → Rust → Realtime transcription → codex exec
第二版：把 codex exec 换成 Codex App Server / SDK，保留同一个会话
不要走：Android 音频 → 服务器虚拟麦克风 → Codex CLI /realtime
```

服务器虚拟麦克风那条路理论上能折腾，但在 Linux 服务器上很脆弱，而且 Codex CLI 的 realtime 语音本来就是本地 TUI 实验功能，不适合作为生产接口。

我想做的是 ，用安卓设备 实时语音发给 rust 代码 然后 通过rust代码 做成 本地音频采集 的方式 投喂给 codex cli

可以。你这个方向更靠谱：**Rust 自己采集本机麦克风音频，然后把 PCM 音频块实时发给服务器 / Realtime / 你自己的 Codex 网关**。

Rust 里建议用 `cpal` 做跨平台音频采集。`cpal` 的核心模型就是：`Host` 找设备，`Device` 创建输入流，`Stream` 在回调里持续给你麦克风采集到的音频数据；而且官方文档提醒，音频回调通常运行在专门的高优先级线程里，所以不要在回调里直接做网络请求，应该通过 channel 把音频块丢出去。([Docs.rs][1])

下面这个 demo 做的是：

```text
本机麦克风
  ↓ cpal 采集
转 mono
  ↓
线性重采样到 24000 Hz
  ↓
转 PCM16 little-endian
  ↓
每 100ms 切一块
  ↓
可选：保存 capture.wav
  ↓
可选：通过 WebSocket binary frame 发给服务器
```

默认输出格式我设成了：

```text
PCM16 little-endian
mono
24000 Hz
```

这个格式正好适合接你前面那个语音网关；OpenAI Realtime transcription 的 `audio/pcm` 也要求 24 kHz mono PCM，音频块通过 `input_audio_buffer.append` 发，结束一句话时可以用 `input_audio_buffer.commit`。([OpenAI平台][2])

## 1. 创建项目

```bash
cargo new local-audio-capture
cd local-audio-capture
```

Linux 上如果编译 `cpal` 报 ALSA 相关错误，先装：

```bash
sudo apt update
sudo apt install -y libasound2-dev pkg-config
```

macOS 第一次运行时，系统可能会弹出麦克风权限；如果没弹，可以去：

```text
系统设置 → 隐私与安全性 → 麦克风 → 允许你的 Terminal / iTerm
```

## 3. `src/main.rs`

```rust
// src/main.rs

use anyhow::{bail, ensure, Context, Result};
use clap::Parser;
use cpal::traits::{DeviceTrait, HostTrait, StreamTrait};
use cpal::{SampleFormat, StreamConfig, SupportedStreamConfig};
use futures_util::{SinkExt, StreamExt};
use std::{
    fs::File,
    io::BufWriter,
    path::PathBuf,
    time::{Duration, Instant},
};
use tokio::{
    io::{AsyncBufReadExt, BufReader},
    sync::{mpsc, watch},
};
use tokio_tungstenite::{connect_async, tungstenite::Message as WsMessage};

/// WAV 写入器类型别名，减少后面函数签名的复杂度。
type WavWriter = hound::WavWriter<BufWriter<File>>;

/// 命令行参数。
#[derive(Debug, Parser)]
#[command(
    name = "local-audio-capture",
    about = "用 Rust/CPAL 采集本机麦克风，并输出 24kHz mono PCM16 音频块"
)]
struct Cli {
    /// 列出当前机器上的输入设备，然后退出。
    #[arg(long)]
    list_devices: bool,

    /// 选择输入设备。可以填设备名字的一部分，例如：USB、MacBook、Microphone。
    /// 不填时使用系统默认输入设备。
    #[arg(long)]
    device: Option<String>,

    /// 把音频实时推送到 WebSocket 服务器。
    ///
    /// 协议：
    /// - binary frame: PCM16 little-endian mono 24kHz 音频块
    /// - text frame: {"type":"commit"} 表示一句话结束
    ///
    /// 例如：
    /// ws://127.0.0.1:3000/ws/voice
    #[arg(long)]
    ws: Option<String>,

    /// 同时把采集到的音频保存成 WAV 文件。
    ///
    /// 如果既没有 --ws，也没有 --wav，默认保存到 capture.wav。
    #[arg(long)]
    wav: Option<PathBuf>,

    /// 录制多少秒后自动退出。
    ///
    /// 不填则一直录，按 Ctrl+C 退出。
    #[arg(long)]
    seconds: Option<u64>,

    /// 输出采样率。
    ///
    /// 为了接 OpenAI Realtime transcription / 你前面的语音网关，
    /// 默认使用 24000 Hz。
    #[arg(long, default_value_t = 24_000)]
    target_rate: u32,

    /// 每个音频块多少毫秒。
    ///
    /// 100ms 是比较稳的测试值：
    /// - 延迟不会太大
    /// - WebSocket 包数量也不会太夸张
    #[arg(long, default_value_t = 100)]
    chunk_ms: u32,
}

#[tokio::main]
async fn main() -> Result<()> {
    let cli = Cli::parse();

    if cli.list_devices {
        list_input_devices()?;
        return Ok(());
    }

    ensure!(cli.target_rate > 0, "--target-rate 必须大于 0");
    ensure!(
        cli.chunk_ms > 0 && cli.chunk_ms <= 1000,
        "--chunk-ms 建议在 1 到 1000 之间"
    );

    // 如果用户没有指定 --ws，也没有指定 --wav，就默认保存一个 capture.wav，方便先验证麦克风是否正常。
    let wav_path = match (&cli.wav, &cli.ws) {
        (Some(path), _) => Some(path.clone()),
        (None, None) => Some(PathBuf::from("capture.wav")),
        (None, Some(_)) => None,
    };

    // 选择输入设备。
    let device = select_input_device(cli.device.as_deref())?;
    let device_name = device_label(&device);

    // 查询设备默认输入格式。
    let supported_config = device
        .default_input_config()
        .with_context(|| format!("读取输入设备默认配置失败：{device_name}"))?;

    println!("使用输入设备：{device_name}");
    println!(
        "设备默认格式：sample_format={:?}, sample_rate={} Hz, channels={}",
        supported_config.sample_format(),
        supported_config.sample_rate().0,
        supported_config.channels()
    );
    println!(
        "程序输出格式：PCM16 little-endian, mono, {} Hz, 每块 {} ms",
        cli.target_rate, cli.chunk_ms
    );

    if let Some(path) = wav_path.as_ref() {
        println!("WAV 保存路径：{}", path.display());
    }

    if let Some(ws_url) = cli.ws.as_ref() {
        println!("WebSocket 推流地址：{ws_url}");
        println!("运行中按 Enter 会发送一次 commit：{{\"type\":\"commit\"}}");
    }

    // cpal 的音频回调线程不能直接 await，所以用 channel 把音频块送到 Tokio 主循环。
    let (audio_tx, mut audio_rx) = mpsc::unbounded_channel::<Vec<u8>>();

    // 创建音频输入流。
    let stream = build_audio_capture_stream(
        &device,
        supported_config,
        cli.target_rate,
        cli.chunk_ms,
        audio_tx,
    )?;

    // cpal 文档里说明，不是所有平台创建 stream 后都会自动启动，所以要显式 play。
    stream.play().context("启动麦克风输入流失败")?;

    // 可选：创建 WAV 写入器。
    let mut wav_writer = if let Some(path) = wav_path.as_ref() {
        Some(create_wav_writer(path, cli.target_rate)?)
    } else {
        None
    };

    // 可选：连接 WebSocket 服务器。
    let mut ws_write_opt = if let Some(ws_url) = cli.ws.as_deref() {
        let (ws_stream, _response) = connect_async(ws_url)
            .await
            .with_context(|| format!("连接 WebSocket 失败：{ws_url}"))?;

        let (ws_write, mut ws_read) = ws_stream.split();

        // 后台读取服务器返回的消息。
        tokio::spawn(async move {
            while let Some(message_result) = ws_read.next().await {
                match message_result {
                    Ok(WsMessage::Text(text)) => {
                        println!("\n[服务器文本消息] {text}");
                    }
                    Ok(WsMessage::Binary(bytes)) => {
                        println!("\n[服务器二进制消息] {} bytes", bytes.len());
                    }
                    Ok(WsMessage::Close(frame)) => {
                        println!("\n[服务器关闭连接] {frame:?}");
                        break;
                    }
                    Ok(_) => {}
                    Err(err) => {
                        eprintln!("\n[读取服务器消息失败] {err}");
                        break;
                    }
                }
            }
        });

        Some(ws_write)
    } else {
        None
    };

    // 用 watch channel 统一处理 Ctrl+C 和 --seconds 自动退出。
    let (stop_tx, mut stop_rx) = watch::channel(false);

    // Ctrl+C 退出。
    {
        let stop_tx = stop_tx.clone();
        tokio::spawn(async move {
            if tokio::signal::ctrl_c().await.is_ok() {
                let _ = stop_tx.send(true);
            }
        });
    }

    // 如果用户指定了 --seconds，到时间后退出。
    if let Some(seconds) = cli.seconds {
        let stop_tx = stop_tx.clone();
        tokio::spawn(async move {
            tokio::time::sleep(Duration::from_secs(seconds)).await;
            let _ = stop_tx.send(true);
        });
    }

    // 按 Enter 发送 commit。
    let (commit_tx, mut commit_rx) = mpsc::unbounded_channel::<()>();
    tokio::spawn(async move {
        let stdin = tokio::io::stdin();
        let mut reader = BufReader::new(stdin);
        let mut line = String::new();

        loop {
            line.clear();

            match reader.read_line(&mut line).await {
                Ok(0) => break,
                Ok(_) => {
                    let _ = commit_tx.send(());
                }
                Err(err) => {
                    eprintln!("读取 stdin 失败：{err}");
                    break;
                }
            }
        }
    });

    println!("开始采集。按 Ctrl+C 结束。");

    let mut total_bytes: u64 = 0;
    let mut last_report = Instant::now();

    loop {
        tokio::select! {
            changed = stop_rx.changed() => {
                if changed.is_ok() {
                    println!("\n收到停止信号，准备退出。");
                }
                break;
            }

            maybe_commit = commit_rx.recv(), if ws_write_opt.is_some() => {
                if maybe_commit.is_some() {
                    if let Some(ws_write) = ws_write_opt.as_mut() {
                        ws_write
                            .send(WsMessage::Text(r#"{"type":"commit"}"#.into()))
                            .await
                            .context("发送 commit 到 WebSocket 失败")?;

                        println!("已发送 commit。");
                    }
                }
            }

            maybe_chunk = audio_rx.recv() => {
                let chunk = match maybe_chunk {
                    Some(chunk) => chunk,
                    None => {
                        println!("音频 channel 已关闭。");
                        break;
                    }
                };

                let chunk_len = chunk.len();
                total_bytes += chunk_len as u64;

                // 可选：写入 WAV。
                if let Some(writer) = wav_writer.as_mut() {
                    write_pcm16_le_to_wav(writer, &chunk)?;
                }

                // 可选：推送到 WebSocket。
                if let Some(ws_write) = ws_write_opt.as_mut() {
                    ws_write
                        .send(WsMessage::Binary(chunk.into()))
                        .await
                        .context("发送音频块到 WebSocket 失败")?;
                }

                // 每秒打印一次采集进度。
                if last_report.elapsed() >= Duration::from_secs(1) {
                    let audio_seconds = total_bytes as f64 / (cli.target_rate as f64 * 2.0);
                    println!(
                        "已采集约 {:.1} 秒音频，累计 {} KB",
                        audio_seconds,
                        total_bytes / 1024
                    );
                    last_report = Instant::now();
                }
            }
        }
    }

    // 停止麦克风输入流。
    drop(stream);

    // 退出前，如果连接了 WebSocket，再发送一次 commit，避免最后一小段音频没有提交。
    if let Some(ws_write) = ws_write_opt.as_mut() {
        let _ = ws_write
            .send(WsMessage::Text(r#"{"type":"commit"}"#.into()))
            .await;
    }

    // 关闭 WAV 文件，写入完整 header。
    if let Some(writer) = wav_writer.take() {
        writer.finalize().context("finalize WAV 文件失败")?;
    }

    // 关闭 WebSocket。
    if let Some(mut ws_write) = ws_write_opt.take() {
        let _ = ws_write.close().await;
    }

    println!("完成。");
    Ok(())
}

/// 列出所有输入设备。
fn list_input_devices() -> Result<()> {
    let host = cpal::default_host();

    println!("可用输入设备：");

    let mut count = 0usize;

    for (index, device) in host
        .input_devices()
        .context("枚举输入设备失败")?
        .enumerate()
    {
        count += 1;

        let label = device_label(&device);

        let default_config_text = match device.default_input_config() {
            Ok(config) => format!(
                "sample_format={:?}, sample_rate={} Hz, channels={}",
                config.sample_format(),
                config.sample_rate().0,
                config.channels()
            ),
            Err(err) => format!("无法读取默认配置：{err}"),
        };

        println!("[{index}] {label}");
        println!("    默认输入格式：{default_config_text}");
    }

    if count == 0 {
        println!("没有找到输入设备。");
    }

    Ok(())
}

/// 按名字选择输入设备；没有指定名字时使用默认输入设备。
fn select_input_device(name_part: Option<&str>) -> Result<cpal::Device> {
    let host = cpal::default_host();

    if let Some(name_part) = name_part {
        let name_part = name_part.to_lowercase();

        for device in host.input_devices().context("枚举输入设备失败")? {
            let label = device_label(&device);

            if label.to_lowercase().contains(&name_part) {
                return Ok(device);
            }
        }

        bail!("没有找到名字包含 `{name_part}` 的输入设备。可以先运行 --list-devices 查看设备名。");
    }

    host.default_input_device()
        .context("没有默认输入设备。请检查麦克风权限，或运行 --list-devices 查看设备。")
}

/// 获取设备名称。
fn device_label(device: &cpal::Device) -> String {
    device
        .description()
        .map(|description| description.to_string())
        .unwrap_or_else(|_| "<unknown input device>".to_string())
}

/// 创建音频输入流。
fn build_audio_capture_stream(
    device: &cpal::Device,
    supported_config: SupportedStreamConfig,
    target_rate: u32,
    chunk_ms: u32,
    audio_tx: mpsc::UnboundedSender<Vec<u8>>,
) -> Result<cpal::Stream> {
    let sample_format = supported_config.sample_format();
    let input_rate = supported_config.sample_rate().0;
    let channels = supported_config.channels() as usize;
    let stream_config = supported_config.config();

    ensure!(channels > 0, "输入设备声道数不能为 0");

    match sample_format {
        SampleFormat::F32 => build_input_stream_for_type::<f32>(
            device,
            &stream_config,
            channels,
            input_rate,
            target_rate,
            chunk_ms,
            audio_tx,
            f32_sample_to_f32,
        ),

        SampleFormat::I16 => build_input_stream_for_type::<i16>(
            device,
            &stream_config,
            channels,
            input_rate,
            target_rate,
            chunk_ms,
            audio_tx,
            i16_sample_to_f32,
        ),

        SampleFormat::U16 => build_input_stream_for_type::<u16>(
            device,
            &stream_config,
            channels,
            input_rate,
            target_rate,
            chunk_ms,
            audio_tx,
            u16_sample_to_f32,
        ),

        other => {
            bail!(
                "当前 demo 暂时只处理 F32/I16/U16 输入格式，当前设备格式是：{other:?}"
            );
        }
    }
}

/// 为具体 sample 类型创建 cpal 输入流。
fn build_input_stream_for_type<T>(
    device: &cpal::Device,
    stream_config: &StreamConfig,
    channels: usize,
    input_rate: u32,
    target_rate: u32,
    chunk_ms: u32,
    audio_tx: mpsc::UnboundedSender<Vec<u8>>,
    sample_to_f32: fn(T) -> f32,
) -> Result<cpal::Stream>
where
    T: cpal::SizedSample + Copy + Send + 'static,
{
    let samples_per_chunk = ((target_rate as u64 * chunk_ms as u64) / 1000) as usize;
    ensure!(samples_per_chunk > 0, "每个音频块的 sample 数不能为 0");

    // 重采样器：把设备默认采样率转成 target_rate。
    let mut resampler = LinearResampler::new(input_rate, target_rate);

    // 切块器：把 i16 sample 切成固定大小的 PCM16 little-endian bytes。
    let mut chunker = Pcm16LeChunker::new(samples_per_chunk);

    let error_callback = move |err| {
        eprintln!("音频输入流错误：{err}");
    };

    let stream = device
        .build_input_stream(
            stream_config,
            move |data: &[T], _info: &cpal::InputCallbackInfo| {
                // 1. 多声道转 mono f32。
                let mono_f32 = interleaved_to_mono(data, channels, sample_to_f32);

                if mono_f32.is_empty() {
                    return;
                }

                // 2. 重采样到 target_rate，并转成 i16。
                let mut resampled_i16 = Vec::new();
                resampler.process(&mono_f32, &mut resampled_i16);

                if resampled_i16.is_empty() {
                    return;
                }

                // 3. 切成固定大小的 PCM bytes，通过 channel 发给 Tokio 主循环。
                chunker.push_samples(&resampled_i16, &audio_tx);
            },
            error_callback,
            None,
        )
        .context("创建 cpal 输入流失败")?;

    Ok(stream)
}

/// interleaved 多声道数据转 mono。
///
/// 例如 stereo 输入排列通常是：
/// L R L R L R ...
///
/// 这里简单地对每一帧的所有声道取平均。
fn interleaved_to_mono<T>(
    data: &[T],
    channels: usize,
    sample_to_f32: fn(T) -> f32,
) -> Vec<f32>
where
    T: Copy,
{
    if data.is_empty() || channels == 0 {
        return Vec::new();
    }

    let frame_count = data.len() / channels;
    let mut mono = Vec::with_capacity(frame_count);

    for frame in data.chunks_exact(channels) {
        let mut sum = 0.0f32;

        for sample in frame {
            sum += sample_to_f32(*sample);
        }

        mono.push(sum / channels as f32);
    }

    mono
}

/// f32 sample 转 f32，范围尽量限制在 [-1.0, 1.0]。
fn f32_sample_to_f32(sample: f32) -> f32 {
    sample.clamp(-1.0, 1.0)
}

/// i16 sample 转 f32。
fn i16_sample_to_f32(sample: i16) -> f32 {
    (sample as f32 / i16::MAX as f32).clamp(-1.0, 1.0)
}

/// u16 sample 转 f32。
///
/// u16 音频通常以 32768 为中点：
/// - 0 接近 -1.0
/// - 32768 接近 0.0
/// - 65535 接近 1.0
fn u16_sample_to_f32(sample: u16) -> f32 {
    ((sample as f32 - 32768.0) / 32768.0).clamp(-1.0, 1.0)
}

/// f32 转 i16。
fn f32_to_i16(sample: f32) -> i16 {
    let clamped = sample.clamp(-1.0, 1.0);
    (clamped * i16::MAX as f32).round() as i16
}

/// 简单线性重采样器。
///
/// 说明：
/// - 这个实现足够用于语音识别测试。
/// - 如果后面追求更高音质，可以换成专业重采样库，例如 rubato。
struct LinearResampler {
    /// 输入采样率 / 输出采样率。
    step: f64,

    /// 当前在 input_buffer 里的浮点位置。
    position: f64,

    /// 暂存跨 callback 的 mono f32 输入样本。
    input_buffer: Vec<f32>,
}

impl LinearResampler {
    fn new(input_rate: u32, output_rate: u32) -> Self {
        let step = input_rate as f64 / output_rate as f64;

        Self {
            step,
            position: 0.0,
            input_buffer: Vec::new(),
        }
    }

    /// 输入 mono f32 samples，输出 i16 samples。
    fn process(&mut self, input: &[f32], output: &mut Vec<i16>) {
        if input.is_empty() {
            return;
        }

        self.input_buffer.extend_from_slice(input);

        // 线性插值至少需要当前位置和下一个位置两个点。
        if self.input_buffer.len() < 2 {
            return;
        }

        while self.position + 1.0 < self.input_buffer.len() as f64 {
            let index = self.position.floor() as usize;
            let frac = self.position - index as f64;

            let left = self.input_buffer[index];
            let right = self.input_buffer[index + 1];

            let interpolated = left * (1.0 - frac as f32) + right * frac as f32;

            output.push(f32_to_i16(interpolated));

            self.position += self.step;
        }

        // 删除已经用过的输入样本，保留 position 附近的数据用于下次插值。
        let removable = self.position.floor() as usize;

        if removable > 0 {
            self.input_buffer.drain(0..removable);
            self.position -= removable as f64;
        }
    }
}

/// 把 i16 samples 切成固定大小的 PCM16 little-endian bytes。
struct Pcm16LeChunker {
    samples_per_chunk: usize,
    pending_samples: Vec<i16>,
}

impl Pcm16LeChunker {
    fn new(samples_per_chunk: usize) -> Self {
        Self {
            samples_per_chunk,
            pending_samples: Vec::with_capacity(samples_per_chunk * 2),
        }
    }

    fn push_samples(
        &mut self,
        samples: &[i16],
        audio_tx: &mpsc::UnboundedSender<Vec<u8>>,
    ) {
        self.pending_samples.extend_from_slice(samples);

        while self.pending_samples.len() >= self.samples_per_chunk {
            let chunk_samples: Vec<i16> = self
                .pending_samples
                .drain(0..self.samples_per_chunk)
                .collect();

            let mut bytes = Vec::with_capacity(chunk_samples.len() * 2);

            for sample in chunk_samples {
                bytes.extend_from_slice(&sample.to_le_bytes());
            }

            // 如果接收端已经关闭，忽略错误即可；主循环会退出。
            let _ = audio_tx.send(bytes);
        }
    }
}

/// 创建 WAV 文件。
fn create_wav_writer(path: &PathBuf, sample_rate: u32) -> Result<WavWriter> {
    let spec = hound::WavSpec {
        channels: 1,
        sample_rate,
        bits_per_sample: 16,
        sample_format: hound::SampleFormat::Int,
    };

    hound::WavWriter::create(path, spec)
        .with_context(|| format!("创建 WAV 文件失败：{}", path.display()))
}

/// 把 PCM16 little-endian bytes 写进 WAV。
fn write_pcm16_le_to_wav(writer: &mut WavWriter, bytes: &[u8]) -> Result<()> {
    ensure!(
        bytes.len() % 2 == 0,
        "PCM16 byte 长度必须是 2 的倍数，当前是 {}",
        bytes.len()
    );

    for pair in bytes.chunks_exact(2) {
        let sample = i16::from_le_bytes([pair[0], pair[1]]);
        writer.write_sample(sample).context("写入 WAV sample 失败")?;
    }

    Ok(())
}
```

## 7. 两个重要提醒

第一，这个程序必须运行在**有麦克风的机器上**。如果你在远程 Linux 服务器上运行它，而服务器没有 USB 麦克风 / 虚拟声卡，它是采不到你笔记本麦克风的。远程 SSH 不会自动把你本机麦克风带过去。

第二，音频回调里不要直接做 WebSocket send、HTTP 请求、文件大量写入。这个 demo 的结构是正确的：`cpal callback → channel → Tokio 主循环`。`cpal` 文档也说明音频 callback 会周期性收到输入数据，并且通常由专门的高优先级线程负责按时交付音频数据。([Docs.rs][1])

[1]: https://docs.rs/cpal/latest/cpal/ "cpal - Rust"
[2]: https://platform.openai.com/docs/guides/realtime-transcription "Realtime transcription | OpenAI API"
[3]: https://docs.rs/tokio-tungstenite/latest/tokio_tungstenite/ "tokio_tungstenite - Rust"


可以按你这个思路做：**Android 实时采集语音 → WebSocket 发给 Rust 服务 → Rust 把音频写进服务器的“虚拟麦克风” → Codex CLI 以为自己正在从本机麦克风收音。**

但是这里有一个非常重要的现实限制：

**如果你的服务器是 Linux，当前 Codex CLI 官方源码里 `/realtime` 的本地音频采集在 Linux 下是空实现。**源码里 `/realtime` 是实验性语音模式，`/settings` 是配置麦克风/扬声器；但 `start_realtime_local_audio()` 在 `target_os = "linux"` 时函数体是空的，非 Linux 才会调用 `VoiceCapture::start_realtime()`。([GitHub][1]) 
另外 Codex 的 WebRTC realtime crate 目前也只在 macOS target 引入 `libwebrtc`，非 macOS 会返回 unsupported。 

所以结论是：

```text
Android → Rust → 虚拟麦克风 → Codex CLI
```

这个架构本身是对的，但在 **Linux 服务器 + 未修改的官方 Codex CLI** 上，大概率喂不进去。你需要满足下面三种情况之一：

```text
方案 A：Codex CLI 运行在 macOS / Windows 上，用虚拟声卡喂它
方案 B：你自己 patch / rebuild Codex CLI，让 Linux 也启用 VoiceCapture
方案 C：不要伪装麦克风，Rust 直接走 Codex/Reatime 协议或 codex exec
```

你现在想做的是方案 B 或方案 A。我下面按“虚拟麦克风投喂”的方式给你完整链路。

## 1. 总体架构

推荐音频格式统一成：

```text
PCM16 little-endian
24000 Hz
mono
每帧 20ms 或 40ms
```

原因是 Codex CLI 的 `VoiceCapture` 内部目标格式也是 **24kHz、单声道**；源码里常量是 `MODEL_AUDIO_SAMPLE_RATE = 24_000` 和 `MODEL_AUDIO_CHANNELS = 1`。

链路如下：

```text
Android AudioRecord
  ↓ WebSocket binary frame
Rust WebSocket Server
  ↓ 写入 pw-cat stdin
PipeWire / PulseAudio 虚拟播放设备 codex_sink
  ↓ monitor source
虚拟麦克风 codex_mic
  ↓ Codex CLI /settings 选择这个麦克风
Codex CLI /realtime
```

你可以把它理解成：

```text
Rust 不是直接控制 Codex CLI
Rust 是把 Android 声音“播放”到一个虚拟音箱
这个虚拟音箱的 monitor 被伪装成麦克风
Codex CLI 从这个虚拟麦克风录音
```

PipeWire 的 `pw-cat` 支持从 stdin 播放 raw PCM，并且可以指定 target、rate、channels、format；文档说明 `-` 表示 stdin/stdout，`--raw` 配合 `--rate / --channels / --format` 指定裸 PCM 格式。([PipeWire][2])

## 4. Rust 服务：接收 Android 音频并写入虚拟麦克风

下面这个 Rust 服务做的事情是：

```text
1. 开一个 WebSocket：/ws/audio
2. Android 发送 binary PCM16 数据
3. Rust 启动 pw-cat
4. Rust 把收到的 PCM bytes 写进 pw-cat stdin
5. pw-cat 把音频播放到 codex_sink
6. CodexMic 就能收到这段声音
```

### `Cargo.toml`

```toml

name = "android-to-codex-mic"
version = "0.1.0"
edition = "2021"

[dependencies]

axum = { version = "0.8", features = ["ws"] }
futures-util = "0.3"
serde_json = "1.0"

```

### `src/main.rs`

```rust
// src/main.rs

use anyhow::{Context, Result};
use axum::{
    extract::{
        ws::{Message, WebSocket, WebSocketUpgrade},
        State,
    },
    response::IntoResponse,
    routing::get,
    Router,
};
use futures_util::{SinkExt, StreamExt};
use serde_json::{json, Value};
use std::{env, net::SocketAddr, process::Stdio, sync::Arc};
use tokio::{
    io::AsyncWriteExt,
    process::{Child, ChildStdin, Command},
};
use tracing::{error, info, warn};

/// 服务配置。
///
/// Android 端建议直接发送：
/// - PCM16 little-endian
/// - 24000 Hz
/// - mono
/// - 不要带 WAV header
#[derive(Clone, Debug)]
struct AppConfig {
    /// Rust 服务监听地址。
    listen_addr: String,

    /// pw-cat 命令路径。
    pwcat_path: String,

    /// PipeWire / PulseAudio 虚拟 sink 名称。
    ///
    /// 注意：Rust 写入的是 sink，不是 source。
    /// Codex CLI 读取的是这个 sink 的 monitor / remap source。
    target_sink: String,

    /// 音频采样率。
    sample_rate: u32,

    /// 声道数。
    channels: u16,

    /// 每次 Android 发送一段话结束后，Rust 补多少毫秒静音。
    ///
    /// 这样可以帮助 Codex 的语音活动检测判断“用户说完了”。
    end_silence_ms: u64,
}

impl AppConfig {
    fn from_env() -> Self {
        Self {
            listen_addr: env::var("LISTEN_ADDR")
                .unwrap_or_else(|_| "0.0.0.0:3000".to_string()),

            pwcat_path: env::var("PWCAT_PATH")
                .unwrap_or_else(|_| "pw-cat".to_string()),

            target_sink: env::var("CODEX_AUDIO_TARGET_SINK")
                .unwrap_or_else(|_| "codex_sink".to_string()),

            sample_rate: env::var("AUDIO_SAMPLE_RATE")
                .ok()
                .and_then(|v| v.parse::<u32>().ok())
                .unwrap_or(24_000),

            channels: env::var("AUDIO_CHANNELS")
                .ok()
                .and_then(|v| v.parse::<u16>().ok())
                .unwrap_or(1),

            end_silence_ms: env::var("END_SILENCE_MS")
                .ok()
                .and_then(|v| v.parse::<u64>().ok())
                .unwrap_or(700),
        }
    }
}

#[tokio::main]
async fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(
            env::var("RUST_LOG")
                .unwrap_or_else(|_| "android_to_codex_mic=info,tower_http=info,axum=info".to_string()),
        )
        .init();

    let config = Arc::new(AppConfig::from_env());

    let app = Router::new()
        .route("/ws/audio", get(ws_audio_handler))
        .with_state(config.clone());

    let addr: SocketAddr = config
        .listen_addr
        .parse()
        .context("LISTEN_ADDR 格式错误，例如 0.0.0.0:3000")?;

    info!("Android -> Codex Mic gateway listening on {}", addr);
    info!("Target PipeWire/PulseAudio sink: {}", config.target_sink);
    info!(
        "Expected audio format: PCM16 little-endian, {} Hz, {} channel(s)",
        config.sample_rate, config.channels
    );

    let listener = tokio::net::TcpListener::bind(addr)
        .await
        .context("绑定监听端口失败")?;

    axum::serve(listener, app)
        .await
        .context("启动 Axum 服务失败")?;

    Ok(())
}

/// WebSocket 升级入口。
async fn ws_audio_handler(
    State(config): State<Arc<AppConfig>>,
    ws: WebSocketUpgrade,
) -> impl IntoResponse {
    ws.on_upgrade(move |socket| async move {
        if let Err(err) = handle_audio_socket(socket, config).await {
            error!("WebSocket 会话失败: {err:?}");
        }
    })
}

/// 处理单个 Android WebSocket 连接。
async fn handle_audio_socket(socket: WebSocket, config: Arc<AppConfig>) -> Result<()> {
    let (mut ws_sender, mut ws_receiver) = socket.split();

    let mut pwcat = spawn_pwcat(&config)
        .await
        .context("启动 pw-cat 失败")?;

    let mut pwcat_stdin = pwcat
        .stdin
        .take()
        .context("无法获取 pw-cat stdin")?;

    ws_sender
        .send(json_message(json!({
            "type": "ready",
            "message": "Rust server is ready. Send binary PCM16 audio frames.",
            "sample_rate": config.sample_rate,
            "channels": config.channels,
            "target_sink": config.target_sink,
        })))
        .await
        .context("发送 ready 消息失败")?;

    while let Some(msg_result) = ws_receiver.next().await {
        let msg = match msg_result {
            Ok(msg) => msg,
            Err(err) => {
                warn!("读取 WebSocket 消息失败: {err}");
                break;
            }
        };

        match msg {
            Message::Binary(bytes) => {
                // Android 发来的必须是裸 PCM16 little-endian。
                // PCM16 每个 sample 2 字节，所以长度必须是偶数。
                if bytes.len() % 2 != 0 {
                    ws_sender
                        .send(json_message(json!({
                            "type": "error",
                            "message": "binary frame length is not even; PCM16 data must be 2-byte aligned"
                        })))
                        .await
                        .ok();
                    continue;
                }

                // 写入 pw-cat stdin。
                //
                // pw-cat 会把这些 bytes 播放到 codex_sink；
                // codex_sink.monitor / codex_mic 会把它暴露成“麦克风输入”。
                if let Err(err) = pwcat_stdin.write_all(&bytes).await {
                    warn!("写入 pw-cat stdin 失败: {err}");
                    ws_sender
                        .send(json_message(json!({
                            "type": "error",
                            "message": format!("failed to write audio to pw-cat: {err}")
                        })))
                        .await
                        .ok();
                    break;
                }
            }

            Message::Text(text) => {
                let text = text.to_string();

                let value: Value = match serde_json::from_str(&text) {
                    Ok(value) => value,
                    Err(_) => {
                        ws_sender
                            .send(json_message(json!({
                                "type": "error",
                                "message": "text message must be JSON"
                            })))
                            .await
                            .ok();
                        continue;
                    }
                };

                let msg_type = value
                    .get("type")
                    .and_then(Value::as_str)
                    .unwrap_or_default();

                match msg_type {
                    // Android 一句话结束时发送：
                    // {"type":"end"}
                    //
                    // Rust 补一段静音，帮助 Codex 判断说话结束。
                    "end" | "commit" | "stop_speaking" => {
                        write_silence(
                            &mut pwcat_stdin,
                            config.sample_rate,
                            config.channels,
                            config.end_silence_ms,
                        )
                        .await
                        .context("写入结束静音失败")?;

                        ws_sender
                            .send(json_message(json!({
                                "type": "ok",
                                "message": "end silence injected"
                            })))
                            .await
                            .ok();
                    }

                    // Android 想主动断开。
                    // {"type":"close"}
                    "close" => {
                        ws_sender
                            .send(json_message(json!({
                                "type": "ok",
                                "message": "closing"
                            })))
                            .await
                            .ok();
                        break;
                    }

                    // 可选：Android 可以要求 Rust 插入指定毫秒静音。
                    // {"type":"silence","ms":1000}
                    "silence" => {
                        let ms = value
                            .get("ms")
                            .and_then(Value::as_u64)
                            .unwrap_or(config.end_silence_ms);

                        write_silence(
                            &mut pwcat_stdin,
                            config.sample_rate,
                            config.channels,
                            ms,
                        )
                        .await
                        .context("写入指定静音失败")?;

                        ws_sender
                            .send(json_message(json!({
                                "type": "ok",
                                "message": "silence injected",
                                "ms": ms
                            })))
                            .await
                            .ok();
                    }

                    _ => {
                        ws_sender
                            .send(json_message(json!({
                                "type": "error",
                                "message": format!("unknown text message type: {msg_type}")
                            })))
                            .await
                            .ok();
                    }
                }
            }

            Message::Ping(payload) => {
                ws_sender.send(Message::Pong(payload)).await.ok();
            }

            Message::Pong(_) => {}

            Message::Close(_) => {
                break;
            }
        }
    }

    // 尽量优雅关闭 pw-cat。
    drop(pwcat_stdin);

    match pwcat.wait().await {
        Ok(status) => {
            info!("pw-cat exited with status: {}", status);
        }
        Err(err) => {
            warn!("等待 pw-cat 退出失败: {err}");
        }
    }

    Ok(())
}

/// 启动 pw-cat，把 stdin 的 raw PCM 播放到虚拟 sink。
async fn spawn_pwcat(config: &AppConfig) -> Result<Child> {
    let mut command = Command::new(&config.pwcat_path);

    command
        .arg("--playback")
        .arg("--raw")
        .arg(format!("--rate={}", config.sample_rate))
        .arg(format!("--channels={}", config.channels))
        .arg("--format=s16")
        .arg(format!("--target={}", config.target_sink))
        .arg("-")
        .stdin(Stdio::piped())
        .stdout(Stdio::null())
        .stderr(Stdio::inherit());

    let child = command
        .spawn()
        .with_context(|| {
            format!(
                "无法启动 {}，请确认已安装 pipewire-bin，并且命令可用",
                config.pwcat_path
            )
        })?;

    Ok(child)
}

/// 写入一段 PCM16 静音。
async fn write_silence(
    stdin: &mut ChildStdin,
    sample_rate: u32,
    channels: u16,
    ms: u64,
) -> Result<()> {
    let bytes_per_sample = 2usize;
    let total_samples = (sample_rate as u64)
        .saturating_mul(ms)
        .saturating_div(1000)
        .saturating_mul(channels as u64);

    let total_bytes = total_samples as usize * bytes_per_sample;

    // 一次最多写 20ms，避免一次分配太大。
    let chunk_ms = 20u64;
    let chunk_samples = (sample_rate as u64)
        .saturating_mul(chunk_ms)
        .saturating_div(1000)
        .saturating_mul(channels as u64);

    let chunk_bytes = (chunk_samples as usize * bytes_per_sample).max(2);
    let silence_chunk = vec![0u8; chunk_bytes];

    let mut remaining = total_bytes;

    while remaining > 0 {
        let write_len = remaining.min(silence_chunk.len());
        stdin
            .write_all(&silence_chunk[..write_len])
            .await
            .context("写入静音 chunk 到 pw-cat 失败")?;

        remaining -= write_len;
    }

    stdin.flush().await.context("flush pw-cat stdin 失败")?;

    Ok(())
}

/// 构造 WebSocket JSON 文本消息。
fn json_message(value: Value) -> Message {
    Message::Text(value.to_string().into())
}
```

## 6. Android 端要注意的音频格式

Android 端最好用：

```kotlin
AudioFormat.ENCODING_PCM_16BIT
AudioFormat.CHANNEL_IN_MONO
sampleRate = 24000
```

每次发送 20ms 音频：

```text
24000 samples/s * 0.02s * 1 channel * 2 bytes = 960 bytes
```

所以 20ms 一帧大概是：

```text
960 bytes
```

40ms 一帧是：

```text
1920 bytes
```

不要发送 WAV header，不要发送 AAC，不要发送 AMR，不要发送 MP3。
如果你想用 Opus 节省带宽，那 Rust 服务器需要先解码 Opus，再把 PCM 写入 `pw-cat`。

## 7. Linux Codex CLI 的关键问题怎么解决

如果你服务器是 Linux，并且你坚持用：

```text
虚拟麦克风 → Codex CLI /realtime
```

那你大概率需要自己 patch Codex CLI。

源码里其实已经有通用的 `VoiceCapture`，它用 `cpal` 枚举输入设备、选择配置、采集音频，然后转换成 24kHz mono PCM。 
但在 TUI realtime glue 层，Linux 被 `#[cfg(target_os = "linux")] fn start_realtime_local_audio(&mut self) {}` 空实现挡住了。

你要 patch 的方向是：

```text
1. 让 Linux 也保留 capture_stop_flag / capture / audio_player 字段
2. 让 Linux 也调用 crate::voice::VoiceCapture::start_realtime()
3. 删除 Linux 下空的 start_realtime_local_audio()
4. 删除 Linux 下空的 stop_realtime_local_audio()
5. 重新 cargo build / cargo install 自己的 codex
```

换句话说，不是 Rust 网关难，真正的卡点是：

```text
官方 Codex CLI Linux TUI 当前没有启用本地麦克风采集
```

## 8. 我更推荐的工程路线

你的目标如果是“Android 语音控制服务器上的 Codex 做代码任务”，最稳定的路线其实不是虚拟麦克风，而是：

```text
Android 语音
  ↓
Rust 服务器
  ↓
OpenAI Realtime / Whisper 转文字
  ↓
codex exec "转写后的文本"
  ↓
把 Codex 输出回传 Android
```

`codex exec` 官方就是给脚本和自动化用的；它会把最终 agent message 输出到 stdout，适合 Rust 捕获结果再发回 Android。官方文档也说明 `codex exec` 用于 non-interactive/script 场景，并且默认 read-only sandbox，可显式改成 `workspace-write`。([OpenAI开发者][4])

但如果你现在的实验目标就是“把 Android 声音伪装成本地麦克风喂给 Codex CLI”，那上面的 PipeWire + Rust `pw-cat` 方案就是最直接的实现。关键前提是：**Codex CLI 那端必须真的支持从当前系统采集麦克风；Linux 下需要你 patch。**

[1]: https://raw.githubusercontent.com/openai/codex/main/codex-rs/tui/src/slash_command.rs "raw.githubusercontent.com"
[2]: https://docs.pipewire.org/page_man_pw-cat_1.html "PipeWire: pw-cat"
[3]: https://man.archlinux.org/man/extra/pulseaudio/pulse-cli-syntax.5.en "pulse-cli-syntax(5) — Arch manual pages"
[4]: https://developers.openai.com/codex/noninteractive "Non-interactive mode – Codex | OpenAI Developers"

我想做的是 ，用安卓设备 实时语音发给 rust 代码 然后 通过rust代码 做成 本地音频采集 的方式 投喂给 codex cli


可以，这个目标的正确实现方式就是：

```text
Android APK 麦克风
  ↓ WebSocket 实时发送 PCM 音频
Rust 服务端
  ↓ 写入服务器系统里的“虚拟播放设备”
虚拟播放设备的 monitor / remap source
  ↓ 伪装成“本地麦克风”
Codex CLI /settings 选择这个虚拟麦克风
  ↓
Codex CLI /realtime 从“本地音频采集”里拿到 Android 的声音
```

重点是：**Rust 不能直接把音频塞进 Codex CLI 的 stdin**。Codex CLI 的 stdin 是文字输入，不是音频输入。你要做的是在操作系统层面创建一个“虚拟麦克风”，让 Codex CLI 以为它正在采集本机麦克风。

不过要先说清楚一个坑：Codex CLI 的 `/realtime` 目前是实验语音模式，源码里 `/realtime` 的说明是 “toggle realtime voice mode (experimental)”，`/settings` 是配置 realtime microphone/speaker。([GitHub][1]) 它内部确实有 `VoiceCapture::start_realtime()`，会用本地音频输入流采集，并把音频转换成 24kHz、单声道 PCM 后发给 realtime conversation。([GitHub][2]) 但是当前源码里 Linux 的 `start_realtime_local_audio()` 是空函数，而非 Linux 才会真正调用 `VoiceCapture::start_realtime()`。([GitHub][3])

所以如果你的服务器是 Linux：

```text
Android → Rust → 虚拟麦克风
```

这半边可以做。

但：

```text
虚拟麦克风 → 官方未修改的 Linux Codex CLI /realtime
```

这一半可能不会工作，因为 Codex CLI 当前 Linux TUI 里本地音频采集被空实现挡住了。你需要二选一：

```text
方案 1：Codex CLI 跑在 macOS / Windows，Rust 把音频写进虚拟声卡。
方案 2：Linux 上自己 patch / rebuild Codex CLI，让 Linux 也调用 VoiceCapture。
```

下面我按你想要的“Rust 投喂本地音频采集”给出 Linux PipeWire 版本。

```rust
// src/main.rs

use anyhow::{Context, Result};
use axum::{
    extract::{
        ws::{Message, WebSocket, WebSocketUpgrade},
        State,
    },
    response::IntoResponse,
    routing::get,

/// 服务配置。
///
/// 这个服务假设 Android 发来的音频已经是：
///
/// PCM16 little-endian
/// 24000 Hz
/// mono
///
/// Rust 不做解码，不做转码，只负责把音频写进 PipeWire 虚拟声卡。
#[derive(Debug, Clone)]
struct AppConfig {
    /// Rust 服务监听地址。
    listen_addr: String,

    /// pw-cat 命令路径。
    pwcat_path: String,

    /// PipeWire 目标 sink 名字。

    channels: u16,

    /// Android 一句话结束后，往虚拟麦克风补多少毫秒静音。
    ///
    /// 这个很重要，否则 Codex 可能以为用户还没说完。
    end_silence_ms: u64,
}

impl AppConfig {
    fn from_env() -> Self {
        Self {
            listen_addr: env::var("LISTEN_ADDR")
                .unwrap_or_else(|_| "0.0.0.0:3000".to_string()),

            pwcat_path: env::var("PWCAT_PATH")
                .unwrap_or_else(|_| "pw-cat".to_string()),

            target_sink: env::var("CODEX_AUDIO_TARGET_SINK")
                .unwrap_or_else(|_| "codex_sink".to_string()),

            sample_rate: env::var("AUDIO_SAMPLE_RATE")
                .ok()
                .and_then(|v| v.parse::<u32>().ok())
                .unwrap_or(24_000),

            channels: env::var("AUDIO_CHANNELS")
                .ok()
                .and_then(|v| v.parse::<u16>().ok())
                .unwrap_or(1),

            end_silence_ms: env::var("END_SILENCE_MS")
                .ok()
                .and_then(|v| v.parse::<u64>().ok())
                .unwrap_or(700),
        }
    }
}

#[tokio::main]
async fn main() -> Result<()> {

/// WebSocket 升级入口。
async fn ws_audio_handler(
    State(config): State<Arc<AppConfig>>,
    ws: WebSocketUpgrade,
) -> impl IntoResponse {
    ws.on_upgrade(move |socket| async move {
        if let Err(err) = handle_android_audio_socket(socket, config).await {
            error!("WebSocket 会话失败: {err:?}");
        }
    })
}

/// 处理 Android 发来的音频流。
async fn handle_android_audio_socket(
    socket: WebSocket,
    config: Arc<AppConfig>,
) -> Result<()> {
    let (mut ws_sender, mut ws_receiver) = socket.split();

    // 每个 Android 连接启动一个 pw-cat 进程。
    // Android 发来的音频会写入 pw-cat stdin。
    // pw-cat 再把这些音频播放到 codex_sink。
    let mut pwcat_child = spawn_pwcat(&config)
        .await
        .context("启动 pw-cat 失败")?;

    let mut pwcat_stdin = pwcat_child
        .stdin
        .take()
        .context("无法获取 pw-cat stdin")?;

    ws_sender
        .send(json_text(json!({
            "type": "ready",
            "message": "send binary PCM16 audio frames",
            "format": "pcm16le",
            "sample_rate": config.sample_rate,
            "channels": config.channels,
            "target_sink": config.target_sink
        })))
        .await
        .ok();

    while let Some(msg_result) = ws_receiver.next().await {
        let msg = match msg_result {
            Ok(msg) => msg,
            Err(err) => {
                warn!("读取 Android WebSocket 失败: {err}");
                break;
            }
        };

        match msg {
            Message::Binary(bytes) => {
                // PCM16 每个 sample 是 2 字节。
                // 如果不是偶数字节，说明 Android 发来的数据不对。
                if bytes.len() % 2 != 0 {
                    ws_sender
                        .send(json_text(json!({
                            "type": "error",
                            "message": "PCM16 binary frame length must be even"
                        })))
                        .await
                        .ok();
                    continue;
                }

                // 这里就是核心：
                // Android 的实时语音 bytes → pw-cat stdin → codex_sink → codex_mic。
                if let Err(err) = pwcat_stdin.write_all(&bytes).await {
                    ws_sender
                        .send(json_text(json!({
                            "type": "error",
                            "message": format!("write audio to pw-cat failed: {err}")
                        })))
                        .await
                        .ok();
                    break;
                }
            }

            Message::Text(text) => {
                let value: Value = match serde_json::from_str(&text) {
                    Ok(v) => v,
                    Err(_) => {
                        ws_sender
                            .send(json_text(json!({
                                "type": "error",
                                "message": "text message must be JSON"
                            })))
                            .await
                            .ok();
                        continue;
                    }
                };

                let msg_type = value
                    .get("type")
                    .and_then(Value::as_str)
                    .unwrap_or_default();

                match msg_type {
                    // Android 一句话说完时发：
                    // {"type":"end"}
                    //
                    // Rust 补一段静音给虚拟麦克风，帮助 Codex 的语音检测判断用户已经停顿。
                    "end" | "commit" | "stop_speaking" => {
                        write_silence(
                            &mut pwcat_stdin,
                            config.sample_rate,
                            config.channels,
                            config.end_silence_ms,
                        )
                        .await
                        .context("写入静音失败")?;

                        ws_sender
                            .send(json_text(json!({
                                "type": "ok",
                                "message": "end silence injected",
                                "silence_ms": config.end_silence_ms
                            })))
                            .await
                            .ok();
                    }

                    // Android 主动关闭。
                    "close" => {
                        ws_sender
                            .send(json_text(json!({
                                "type": "ok",
                                "message": "closing"
                            })))
                            .await
                            .ok();
                        break;
                    }

                    // Android 要求插入指定时长静音。
                    // 例如：
                    // {"type":"silence","ms":1000}
                    "silence" => {
                        let ms = value
                            .get("ms")
                            .and_then(Value::as_u64)
                            .unwrap_or(config.end_silence_ms);

                        write_silence(
                            &mut pwcat_stdin,
                            config.sample_rate,
                            config.channels,
                            ms,
                        )
                        .await
                        .context("写入指定静音失败")?;

                        ws_sender
                            .send(json_text(json!({
                                "type": "ok",
                                "message": "silence injected",
                                "silence_ms": ms
                            })))
                            .await
                            .ok();
                    }

                    _ => {
                        ws_sender
                            .send(json_text(json!({
                                "type": "error",
                                "message": format!("unknown message type: {msg_type}")
                            })))
                            .await
                            .ok();
                    }
                }
            }

            Message::Ping(payload) => {
                ws_sender.send(Message::Pong(payload)).await.ok();
            }

            Message::Pong(_) => {}

            Message::Close(_) => {
                break;
            }
        }
    }

    // 关闭 pw-cat stdin，等待 pw-cat 退出。
    drop(pwcat_stdin);

    match pwcat_child.wait().await {
        Ok(status) => {
            info!("pw-cat exited: {}", status);
        }
        Err(err) => {
            warn!("等待 pw-cat 退出失败: {err}");
        }
    }

    Ok(())
}

/// 启动 pw-cat。
///
/// 等价命令大概是：
///
/// pw-cat --playback --raw --rate=24000 --channels=1 --format=s16 --target=codex_sink -
async fn spawn_pwcat(config: &AppConfig) -> Result<Child> {
    let child = Command::new(&config.pwcat_path)
        .arg("--playback")
        .arg("--raw")
        .arg(format!("--rate={}", config.sample_rate))
        .arg(format!("--channels={}", config.channels))
        .arg("--format=s16")
        .arg(format!("--target={}", config.target_sink))
        .arg("-")
        .stdin(Stdio::piped())
        .stdout(Stdio::null())
        .stderr(Stdio::inherit())
        .spawn()
        .with_context(|| {
            format!(
                "无法启动 {}，请确认已安装 pipewire-bin",
                config.pwcat_path
            )
        })?;

    Ok(child)
}

/// 往虚拟麦克风补一段 PCM16 静音。
async fn write_silence(
    stdin: &mut ChildStdin,
    sample_rate: u32,
    channels: u16,
    ms: u64,
) -> Result<()> {
    let bytes_per_sample = 2usize;

    let total_samples = sample_rate as u64
        * ms
        / 1000
        * channels as u64;

    let total_bytes = total_samples as usize * bytes_per_sample;

    // 分块写入，避免一次分配太大。
    let chunk_ms = 20u64;

    let chunk_samples = sample_rate as u64
        * chunk_ms
        / 1000
        * channels as u64;

    let chunk_bytes = (chunk_samples as usize * bytes_per_sample).max(2);

    let silence_chunk = vec![0u8; chunk_bytes];

    let mut remaining = total_bytes;

    while remaining > 0 {
        let write_len = remaining.min(silence_chunk.len());

        stdin
            .write_all(&silence_chunk[..write_len])
            .await
            .context("写入静音 chunk 失败")?;

        remaining -= write_len;
    }

    stdin.flush().await.context("flush pw-cat stdin 失败")?;

    Ok(())
}

/// 构造 JSON 文本消息。
fn json_text(value: Value) -> Message {
    Message::Text(value.to_string().into())
}
```

## 5. Android 端核心发送逻辑

下面是最小 Kotlin 思路。重点是 **binary frame 直接发送 PCM16 bytes**。

```kotlin
// VoiceStreamer.kt

import android.media.AudioFormat
import android.media.AudioRecord
import android.media.MediaRecorder
import okhttp3.WebSocket
import okio.ByteString

class VoiceStreamer(
    private val webSocket: WebSocket
) {
    private var audioRecord: AudioRecord? = null

    @Volatile
    private var running: Boolean = false

    fun start() {
        val sampleRate = 24_000

        val minBufferSize = AudioRecord.getMinBufferSize(
            sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT
        )

        val bufferSize = minBufferSize.coerceAtLeast(960 * 4)

        audioRecord = AudioRecord(
            MediaRecorder.AudioSource.MIC,
            sampleRate,
            AudioFormat.CHANNEL_IN_MONO,
            AudioFormat.ENCODING_PCM_16BIT,
            bufferSize
        )

        running = true

        val recorder = audioRecord ?: return
        recorder.startRecording()

        Thread {
            // 20ms 一帧：24000 * 0.02 * 2 = 960 bytes
            val chunk = ByteArray(960)

            while (running) {
                val readSize = recorder.read(chunk, 0, chunk.size)

                if (readSize > 0) {
                    val bytes = if (readSize == chunk.size) {
                        chunk
                    } else {
                        chunk.copyOf(readSize)
                    }

                    // 发送 WebSocket binary frame。
                    webSocket.send(ByteString.of(*bytes))
                }
            }
        }.start()
    }

    fun stopOneSentence() {
        // 不一定要停止录音；这里表示“一句话结束”。
        // Rust 收到后会补静音给 Codex。
        webSocket.send("""{"type":"end"}""")
    }

    fun close() {
        running = false

        audioRecord?.stop()
        audioRecord?.release()
        audioRecord = null

        webSocket.send("""{"type":"close"}""")
    }
}
```

## 7. 你这个方案的真正难点

你的 Rust 网关并不难，核心代码就是：

```rust
pwcat_stdin.write_all(&android_pcm_bytes).await?;
```

真正难点是：

```text
Codex CLI 是否真的会从当前系统的“虚拟麦克风”采集音频。
```

如果是 macOS / Windows，通常可以通过虚拟声卡做。

如果是 Linux 服务器，当前 Codex CLI 源码里 Linux 的本地 realtime 音频采集是空实现，所以光创建 `codex_mic` 可能不够。你需要 patch Codex CLI，让 Linux 也走 `VoiceCapture::start_realtime()`；Codex 的 `VoiceCapture` 内部目标格式就是 24kHz、单声道，后面会编码成 realtime audio chunk。([GitHub][2])

所以最终判断是：

```text
可以做。
实现方式 = Android PCM → Rust WebSocket → pw-cat → codex_sink → codex_mic → Codex CLI /realtime。

但如果服务器是 Linux + 官方未修改 Codex CLI，最后一步可能不工作；
需要 patch Codex CLI，或者把 Codex CLI 放到支持本地语音采集的平台上跑。
```
