# 开放商业消费者能力类型与访问级别筛选 V1 验收

## 当前状态

`verified_rust_sqlite`

## 已形成代码

- 两个可选请求字段和核心值域复用。
- 公开发现中对 `owner_only` 的失败关闭。
- 候选能力精确过滤。
- 条件响应回显、匹配原因、请求指纹和排序凭证载荷。
- PC 独立固定选项组件和结果标志。

## 已验证

- 空白值按未设置处理，带前后空白的合法值规范化；大小写变化、未知值和 `owner_only` 失败关闭。
- `query/action` 与 `public/authorized` 四种合法组合均精确返回对应能力，无结果组合保持空响应。
- `authorized` 结果只显示当前应用授权状态，不自动申请授权；`action` 结果只被发现，不创建动作确认或 Invocation。
- 能力条件可与能力 Key、价格、来源、声明期、城市、类别、标签和五种排序器组合。
- 条件进入响应、匹配原因、请求输入摘要和排序凭证，发现读取保持无业务写入。

## 统一回归必须验证

- 空白、query、action、public、authorized 和非法值。
- owner_only、大小写变化和前后空白。
- 四种合法组合及无结果场景。
- 与能力 Key、价格、来源、声明期和五种排序器组合。
- authorized 结果仍按应用显示申请、待审批或已授权状态。
- action 结果仍必须经过动作确认后才能调用。
- PC 菜单、结果标志、键盘操作和窄屏布局。
