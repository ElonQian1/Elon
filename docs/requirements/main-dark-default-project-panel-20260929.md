# 主 APK 默认暗色与项目查看面板

用户要求默认暗色，用户自行切换浅色；故障截图中第四导航入口黑色背景与浅色主题文字混用，项目名难以辨认。

## 范围与兼容

- 未保存或无效的外观选择默认深色；已保存的浅色、深色、跟随系统不得覆盖。设置 → 外观继续保留三种选择。
- 项目查看面板、搜索框、标题、占位图与导航使用同一主题语义；真实项目图标不染色。浅深主题均可读。
- 保留个人/群体分组、搜索、两行折叠、展开、关闭与项目原索引跳转。字体放大后名称不得被固定高度裁剪。
- 不改账号、项目数据、会话、权限和消息发送。模拟器使用离线合成项目。
- PWA 已用主题表面覆盖旧黑色背景，此批仅验证共同的浏览/搜索语义；主 APK 默认偏好属于平台产品选择，不修改 PWA 和量化偏好。

## 验收

1. 默认、无效值、已保存三种主题和切换后的恢复均验证。
2. 真实项目面板组件浅深主题正文与提示对比度至少 4.5:1，交互图标至少 3:1。
3. 320/411dp、100%/150%/200% 字体布局不裁剪名称；折叠、搜索、无结果、打开/关闭使用原逻辑。
4. 内部原生运行证据先于正式发布；证据绑定源码与构建。无干净目标，不使用故障截图作拟合目标。
5. 正式版本、服务器工件、白名单手机覆盖安装与版本回读分别报告；离线设备或真机视觉未验收明确标记。

## 实施边界

主题偏好、项目面板与其资源是生产改动；离线预览和定向测试验证生产组件。旧位图文件为兼容保留，固定黑底/搜索框退出当前面板渲染；旧像素和固定高度断言改为语义及运行检查。
