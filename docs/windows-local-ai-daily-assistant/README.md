# Windows 本地 AI 工作日报助手 MVP

最后更新：2026-07-09

## 一句话定位

这是一个参考“小黑日报助手”方向的新独立 MVP 项目：在 Windows 本机自动记录工作轨迹，用 AI 生成时间线和 Markdown 日报。

## 项目目标

先做一个个人可用的本地工具，不先做团队管理、不做云端同步、不接入一龙现有 APK/服务器发布链路。

MVP 需要验证四件事：

1. Windows 本机能稳定采集定时截图和前台应用信息。
2. AI 能把截图和窗口标题理解成可信的工作事项。
3. 用户能看到一天的工作时间线，并手动修正明显错误。
4. 用户能导出一份可直接提交或二次编辑的 Markdown 日报。

## 本目录文件

| 文件 | 用途 |
|---|---|
| `PRD.md` | 产品需求、用户场景、MVP 范围、验收标准 |
| `TECHNICAL_PLAN.md` | 技术方案、数据流、隐私设计、工程量评估 |
| `project-docs/` | 未来独立项目仓库应放到根目录的 AI 入口、约束、架构和任务模板 |

## 推荐开发顺序

这个项目必须先补文档和约束，再写代码：

1. 先确认 `PRD.md`、`TECHNICAL_PLAN.md` 和 `project-docs/` 中的规则。
2. 再创建独立仓库或独立项目目录。
3. 把 `project-docs/` 里的文件复制到新项目根目录。
4. 按 `AGENTS.md` 的顺序让 AI 读取规则。
5. 先做假数据 UI 原型，再接 Windows 采集，再接 AI Vision。

不要一上来直接写截图、上传、AI 分析或后台常驻代码。这个项目涉及屏幕截图和隐私，必须先把边界写清楚。
