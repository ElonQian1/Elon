# 欧易手机只读授权服务交付

对应[正式需求](../requirements/android-okx-read-host-v1.md)。本批已实现主 APK 凭据输入与持续读取同意、AndroidKeyStore AES-GCM 本机保管、固定 Provider、实际账号核验以及合约网格列表/详情读取。量化界面、创建和管理不迁入主 APK。

## 当前证据

- 新增 18 项离线回归通过；连同既有币安托管和正式量化调用方边界，74 项测试通过。覆盖权限仅 Read、实际主/子账户、换号和迟到结果、撤销、短页继续、重复页/后续失败/超限不返回部分成功、共同规范化样本、HMAC 签名及密文篡改/错误密钥/不同 owner 或环境拒绝。
- 量化侧严格解析同一 `grid-center.v1` 测试样本，默认币安入口继续拒绝欧易源。共享样本还与原 Rust 欧易转换结果相等。
- 全球两个官方公开 time 地址可返回成功；这只证明公开地址连通，不证明实际 API 账号可用。服务固定使用全球正式域名，不重定向，不写交易。
- UI 工作台已登记授权表单；两个模拟器资源均被占用，没有创建新的渲染任务。真实视觉、AndroidKeyStore 在用户设备上的业务保存/恢复，以及真实 API 账户仍待验收。
- 正式发布、版本及安装记录将在工件生成后补充；不得把 Debug 编译或测试替身当作正式账号验收。

## 仍需完成

发布并安装双包后，从量化选择“欧易 · 只读网格”，在主 APK 由用户填写仅 Read 的 API Key、Secret、Passphrase，核验后同意返回。AI 随后读取列表、详情、账户类型与恢复结果；测试空账号时应显示已连接但无网格。撤销应删除本机授权，旧代次不得读取。资料不在聊天或证据文件中传递。

当前不含欧易创建、交易修改、结束、历史/成交/持仓和私有推送。主服务不会把未核验收益映射为 USDT；超出请求/响应边界时明确失败。网格工具整体 Goal 保持进行中。
