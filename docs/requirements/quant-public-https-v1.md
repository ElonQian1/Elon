# 量化公开页面与行情的原生 HTTPS 接入

承接用户已授权的量化商业 Goal G18/G30 和正式运行环境需求。量化网格工具的网页行情不再依赖公网明文 HTTP；复用主服务已部署的原生 TLS、有效 IP 证书及自动重载，不占用 ACME TLS-ALPN 续期使用的 443，不启动第二套代理，不重启 Win/Chrome。

## 边界

- 新增 `QUANT_PUBLIC_HTTPS_ENABLED`，默认关闭，仅明确 `true` 开启。非法值或未启用账户 TLS 时请求开启应拒绝启动，不能静默退回 HTTP。
- 在同一 TLS listener 下独立挂载已有量化公开路由；不把账户路由的 query、方法、体积和权限限制放宽。公开内容的 HTTP 兼容入口仍存在，旧 APK 可继续使用。
- 静态页面、指纹资源、公开运行状态、市场 overview、研究及已批准团队资产摘要复用唯一实现；不开放一般 API、个人资产、网格执行、运营或数据库接口，不透传 Cookie/Authorization。
- 公开页仍使用无凭据的受限产品构建。HTTPS 只证明传输与部署，不自动解锁 Paper 个人授权、交易、团队资金或商业运营权限。
- 公共请求采用有界路径/query、准确方法、体积限制、来源不变的代理与原有安全头。TLS 接口的身份不得由伪造转发头启用。

## 验收

1. 开关关闭保持旧 TLS 表面；开启后同一 listener 提供量化首页/指纹资源和公开行情。非法开关及缺少 TLS 时失败关闭。
2. 私有量化路径、通用主站 API、路径穿越、未知方法与超长查询拒绝；原账户带 query 拒绝、身份与体积限制回归通过。
3. 新网页公开路由不向上游传递凭据，匿名数据仍走已有字段合同，不扩展读写能力。
4. 后端按正式发布入口构建部署；部署后核对源码、TLS 信任/身份/有效期、页面/资源/行情与私有路径拒绝。只有运行环境通过后才切换量化 APK 编译 origin，原签名发布与装机另行验收。
5. 保留现有续期与证书重载；配置回滚为关闭新开关，不影响账户 TLS 或旧公开入口。未经实测不宣称浏览器/手机或续期已验证。

## 实现计划

新增独立 TLS 公开挂载及测试模块；原 TLS 入口仅配置校验和组装，已有公开路由仅调整可见性。配置启用与线上只读验收脚本独立交付，版本和工件由正式发布入口绑定。量化侧另行登记消费端 origin、界面说明和证据，不复制业务代理。
