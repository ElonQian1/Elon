# 开放商业开发者 App 限权生产凭据 V1 验收

## 当前状态

`implementation_local_tcp_runtime_subset_verified`

Rust `elon-server` 测试目标已编译；全新 SQLite 专项测试已验证一次性 `oc_live_` 明文不进入列表或数据库、数据库只保存 64 字符十六进制 SHA-256 摘要、再次签发撤销旧凭据，以及资料修订和准入暂停的撤销联动。2 项进程内 Axum 专项已验证登录、项目与 App 管理隔离、平台管理员签发边界、默认关闭、列表脱敏、撤销原因校验和幂等撤销。另有 1 项隔离子进程纵向专项显式开启生产功能开关，由服务层为已准入 App 签发 `oc_live_`，经完整生产 Router 的开发者 TCP 入口完成动作确认并调用签名商户运行时，随后由独立 ERP 机器凭据领取并完成同一个 Invocation；同一生产凭据可读取该 Invocation 的终态摘要和结果详情。相同请求重放返回同一 Invocation 和结果，不再次调用商户运行时或生成第二条事件；同一 App 的沙箱凭据无法读取生产事件或使用生产游标。最新验证指纹为 `2a04d5a3e23894a0b7097d0bf9573151e60180910d097bc7f942b6c0543b9b3d`，验证收据为 `8c53c53122bc05740cafe7b6d6f2c31cf893db77b969e295df1c4118c581acd3`。

## 已形成代码

- V154 新增独立生产凭据表、活动凭据唯一约束、到期索引和准入外键。
- 平台管理员可为当前有效 App 签发或轮换范围受限、限时、只显示一次的 `oc_live_` 密钥；数据库只保存 SHA-256。
- 功能默认关闭；关闭时签发和生产鉴权失败，紧急撤销不受开关阻断。
- 测试和生产凭据共用开发者调用入口，但生产凭据会复核能力范围和全部当前准入条件；调用账本、幂等重放和终态事件已经按凭据环境隔离，沙箱不得触达真实商户运行时。
- 资料修改、域名重新验证、App 停用和准入暂停会原子撤销活动生产凭据。
- PC 管理员审查区可签发并一次性显示密钥，项目管理区可查看元数据和紧急撤销；完整密钥不写入本地持久状态。
- 准入暂停已验证会撤销当前凭据，并以 `production_credential_revoked` 停用活动生产 Webhook。
- 项目成员身份不自动获得 App 凭据访问权；项目 owner 可查看和撤销，普通成员、非 App 所有者编辑者、项目外用户及未加入项目的平台管理员统一在 HTTP 入口失败关闭。
- 撤销接口按当前存储契约幂等成功；重复请求返回同一已撤销状态并保留首次撤销原因，列表和撤销响应都不会返回完整 `oc_live_` 明文。
- 显式开启生产开关的本机 TCP 专项确认生产凭据身份、App ID、凭据环境、凭据 ID 和动作确认 ID 进入商户运行信封；沙箱凭据不能借此获得生产权限，测试结束后不保留生产开关。

## 统一回归必须验证

- V153 到 V154 升级、空表、重复迁移、活动凭据部分唯一索引、外键和历史数据库兼容。
- 默认关闭和显式开启已验证；进程重启、开关关闭后的既有凭据失败关闭和撤销入口可用仍需统一回归。
- Token 摘要碰撞处理、格式拒绝和并发签发原子性；明文不落库和串行轮换已通过专项测试。
- 资料、域名、准入和 App 状态的全部组合；资料修订与准入暂停的撤销联动已通过专项测试。
- `low`、`standard`、`enhanced` 有效期上限、边界日期、过期和时钟处理。
- 请求范围为空、重复、非法、超过 32 项、超出审核范围及合法子集。
- 动作准备、动作确认、生产商户运行调用、幂等重放、生产终态事件读取及同 App 沙箱/生产事件交叉隔离已通过本机 TCP 专项；查询调用和不同生产 App 之间的交叉隔离仍需统一回归。
- 项目 owner、普通成员、其他编辑者、非项目成员和平台管理员的签发、查看与撤销权限已通过进程内 HTTP 专项；独立 App 所有者编辑者和项目 admin 仍待补充验证。
- PC 一次性密钥复制/清除、页面刷新不恢复、列表状态、撤销原因、小屏布局和错误提示。
