# Writing Block 与代码块 ID 隔离

## 现状与本批范围

- 既有结构化读取、原生编辑、撤销/重做、复制、文本/代码/Word/PDF 导出继续复用，已验收边界见 [能力说明](../chatgpt-writing-blocks-native.md)。
- 本批只修一个读取缺陷：代码块使用本地编号 `code-0`，typed Writing Block 使用官网 ID；两者相同不表示是同一个块。旧去重会漏掉后者，使其无法进入原生编辑/导出。
- 去重现在只比较写作块之间的 ID。真正重复的 Writing Block 仍不取得消息写回身份，也不允许生成保存源；代码块不会因此取得云保存权限。
- 不改编辑器、文件存储、导出格式、官网保存协议或现有验收范围。
